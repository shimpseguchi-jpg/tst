# 執筆工程（第七区）

一章を書くたびに、この順でやる。

## 0. 書く前に読む

1. `第七区設定.md`
2. `開示台帳.md`（**この作で開く資料はどれか**を確認する）
3. 当該作品の `プロット.md`
4. 当該作品の `あらすじ記録.md`（前章までの要約と既出の表現）

**設定ファイルがこの工程と矛盾する場合、設定ファイルを優先する。**

## 1. 初稿

- **一発目から目標字数で書く。**短く書いて後から足さない
- 前章末尾の動作を受けて始める
- 一度描写したものを、以後の章で再説明しない
- 設定にないディテールは補ってよい。**補ったら設定ファイルに追記する**
- 予測可能な展開を避ける。ただしプロットの骨は動かさない

## 2. 形式

- セリフは独立行。叙述と同じ行に畳み込まない
- 人物ごとのセクション分けをしない。ひと続きに統合する
- **戦闘の過程を書かない。**結果と、装備の減り方で書く
- **世界の説明をしない。**登場人物は、知っていることを言わない
- 章の終わりは、感慨ではなく物か動作で閉じる

## 3. 測る

```
python3 tools/字数.py <章>.md     # 目標の±10%
python3 tools/読点.py <章>.md     # 本文二十四字に一つ。二十字を切ったら多い
```

読点が増える原因は、ほぼ「〜は、」である。
**主語が短く、述部も短く、対比もないとき、その読点は要らない。**

残してよいのは、主語が長いとき／間を置きたいとき（一章に数回まで）／対比があるとき。

## 4. 忌避表現（生成段階で使わない）

`めっちゃ` `何！？` `ヤバい` `〜すぎる` `ぶっちゃけ` `的な` `てゆうか`
自問自答型の言い直し／`まるで〜のような`／感情の既製品／擬音の多用／感情の直接説明

## 5. 読者三人に読ませてから最終稿にする

- **A（作者）**　文法の正確さ。展開のパターン化を嫌う。前章との重複を嫌う
- **B（この連作の読者）**　抑制を好む。説明されると冷める。行動から察したい
- **C（前作未読）**　この一冊だけで読めるか。固有名詞に置いていかれないか

**初稿を出力しない。最終稿だけを書き出す。**

## 6. 書き終えたら

1. 字数と読点を測る
2. `あらすじ記録.md` に二百字要約を追記
3. 補ったディテールを設定ファイルに追記
4. **この作で開くはずの資料が書けているか、`開示台帳.md` で確認する**
