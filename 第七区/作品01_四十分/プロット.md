# 作品01『四十分』　プロット

| 項目 | |
|---|---|
| 分量 | **全八章、各章三千四百字（±一〇%）、総計二万七千字前後** |
| 視点 | **奇数章＝羽瀬川いつき、偶数章＝都築なずな。**どちらも一人称「わたし」 |
| 時期 | 十二年目の秋。九月から十一月 |

| 軸 | **入る／入らない** |

## 表のテーマ

　入る人と、外で記録する人が、同じ一枚の紙を挟んで一年ぶんの距離を詰める。

## 裏のテーマ

　**正確に知っている人間が、いちばん行けない。**

---

## 章立て

| 章 | 視点 | 何が起きるか |
|---|---|---|
| 一 | いつき | 九月の申請。B‑14。九十分。帰って、装備を北見に出す。**どの道を通ったかを思い出せない** |
| 二 | なずな | 記録所。**分数を測っている。**頼まれていない。いつきの回は毎回八十分台で、一度も九十分を使い切らない |
| 三 | いつき | 深山が社員を増やさない。四人のまま。**「増やしたら、数えられんようになる」** |
| 四 | なずな | 北見が摩耗から見抜く。**「これ、C 列じゃろ」。**申請は B‑14 で出ている。なずなは書類を直さない |
| 五 | いつき | C‑3 は単独禁止である。単独で入った。**理由は言わない。**由良が絡む |
| 六 | なずな | 小野塚が判を押す場面。**等級と番号でしか人を呼ばない。**なずなの五級の許可証が、引き出しにある |
| 七 | いつき | 十一月。戻るのが遅れる。**八十分が、九十二分になった。**二分の超過は失格に当たる |
| 八 | なずな | 小野塚が、超過を**記録しなかった。**理由を聞かない。なずなは自分の申請書を書きはじめて、**「戻らなかった場合の連絡先」の欄で止まる** |

---

## 決めごと

- **中の描写は、第五章の一章ぶんだけ。**ほかの章は全部、線の外側で書く
- 超常に、地の文が一度も触れない。**第七章の二分だけが、唯一の異常である**
- 二分の説明をしない。**「時計を合わせ直した」で済ませる**
- 最終行は、なずなが欄で止まるところ。**書いた／書かないを、地の文が言わない**

　「三級、B‑14、九十分」
　「はい」
　「戻らなかった場合の連絡先が、空欄です」
　「……それで出します」
　「受けます。保証はしません」
