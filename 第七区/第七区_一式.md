これは連作『第七区』の設定一式である。**この一枚だけで、作品01 が書ける。**

## この一式の使い方（最初に読むこと）

1. **本文は、世界を説明しない。**登場人物は、知っていることをわざわざ言わない
2. **説明するのは資料のほうだけ。**資料は測った結果だけを書き、「なぜ」の欄を作らない
3. **ここに入っている資料は二枚だけ**（等級表・寸法）。**これは作品01 の時点で開いている資料である。**
   先の資料を勝手に作らない。開示の順番は `開示台帳.md` にある
4. 一章ずつ書く。**初稿は出力せず、最終稿だけを書き出す**
5. 章を書き終えるたびに、字数と読点を数えて報告する
   （読点は本文二十四字に一つが目安。二十字を切っていたら多い）

## 5. 表記と文体

- **日本語。数字は漢数字。**ただし**等級・滞在分数・街区番号・料率は、この世界の言語**なので本文に出してよい。出すときも漢数字にする（「四十分」「三級」「B‑14」は例外的に英字と算用数字を使う）
- 三点リーダーは「……」、ダッシュは「――」
- **セリフと叙述文を同一行に混在させない**（単語の引用は除く）
- **読点は本文二十四字に一つ**を目安にする。`python3 tools/読点.py <file>` で測る
- 章の終わりは、感慨ではなく**物か動作**で閉じる
- 字数は `python3 tools/字数.py <file>`

### 使わない表現

`めっちゃ` `何！？` `ヤバい` `〜すぎる` `ぶっちゃけ` `的な` `てゆうか`
自問自答型の言い直し／`まるで〜のような`／`ドキッとした` `胸が締めつけられた` `涙が溢れた`
擬音の多用／`彼女は悲しかった` のような感情の直接説明

### 書かないもの

- **戦闘の過程。**結果と、装備の減り方だけ書く
- **世界の成り立ち。**登場人物に説明させない
- 設定用語の造語は、**一作に三語まで**

# ==================== 執筆工程.md ====================

# 執筆工程（第七区）

一章を書くたびに、この順でやる。

## 0. 書く前に読む

1. `第七区設定.md`
2. `開示台帳.md`（**この作で開く資料はどれか**を確認する）
3. 当該作品の `プロット.md`
4. 当該作品の `あらすじ記録.md`（前章までの要約と既出の表現）

**設定ファイルがこの工程と矛盾する場合、設定ファイルを優先する。**

## 1. 初稿

- **一発目から目標字数で書く。**短く書いて後から足さない
- 前章末尾の動作を受けて始める
- 一度描写したものを、以後の章で再説明しない
- 設定にないディテールは補ってよい。**補ったら設定ファイルに追記する**
- 予測可能な展開を避ける。ただしプロットの骨は動かさない

## 2. 形式

- セリフは独立行。叙述と同じ行に畳み込まない
- 人物ごとのセクション分けをしない。ひと続きに統合する
- **戦闘の過程を書かない。**結果と、装備の減り方で書く
- **世界の説明をしない。**登場人物は、知っていることを言わない
- 章の終わりは、感慨ではなく物か動作で閉じる

## 3. 測る

```
python3 tools/字数.py <章>.md     # 目標の±10%
python3 tools/読点.py <章>.md     # 本文二十四字に一つ。二十字を切ったら多い
```

読点が増える原因は、ほぼ「〜は、」である。
**主語が短く、述部も短く、対比もないとき、その読点は要らない。**

残してよいのは、主語が長いとき／間を置きたいとき（一章に数回まで）／対比があるとき。

## 4. 忌避表現（生成段階で使わない）

`めっちゃ` `何！？` `ヤバい` `〜すぎる` `ぶっちゃけ` `的な` `てゆうか`
自問自答型の言い直し／`まるで〜のような`／感情の既製品／擬音の多用／感情の直接説明

## 5. 読者三人に読ませてから最終稿にする

- **A（作者）**　文法の正確さ。展開のパターン化を嫌う。前章との重複を嫌う
- **B（この連作の読者）**　抑制を好む。説明されると冷める。行動から察したい
- **C（前作未読）**　この一冊だけで読めるか。固有名詞に置いていかれないか

**初稿を出力しない。最終稿だけを書き出す。**

## 6. 書き終えたら

1. 字数と読点を測る
2. `あらすじ記録.md` に二百字要約を追記
3. 補ったディテールを設定ファイルに追記
4. **この作で開くはずの資料が書けているか、`開示台帳.md` で確認する**
