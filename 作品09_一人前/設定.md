# 作品09『一人前』設定

## 0. この作品の位置

連作九作目。**作品07と作品08のあいだの一年**を埋める。

- **時期**　二〇三〇年四月 — 二〇三一年四月
- **視点**　一人称。日下部なつ（18・高校三年）
- **全十章。各章三千四百字。合計およそ三万四千字**

前作との接続。

| | |
|---|---|
| 作品07『赤いバツ』 | 二〇三〇年三月にアーケードを撤去して終わる |
| **本作** | **その翌月から始まる。屋根のない最初の一年** |
| 作品08『十四番地』 | 二〇三一年四月から。第五章（八月）で、二人は「この春に高校を出て、それぞれの店に入っている」 |

**作品08第五章の一行を、本作の結末として書く。**

### 連作の原則に対する例外（意識して破る）

共有設定の原則6は「前の作品の主人公を次の作品の主役にしない」である。
本作はこれを破る。ただし**「次の作品」ではない**。作品04から五年ぶんの作品を挟んでいる。

破ってよいと判断した理由は一つ。
**作品04は、二人が何かを一緒に作る話だった。本作は、それが生活になるかどうかの話である。**
続編ではない。同じ二人の、別の問題を書く。

**作品04を読んでいなくても成立させる。** 七年前の夏祭りの件は、本作では**一度も説明しない**。

## 1. この一年に起きること

### 高校三年という条件

- 二〇三〇年四月、高校三年になる。進路調査票が配られる。
- **なつには書く欄がない。** 就職でも進学でもなく、家である。学校の様式にその選択肢がない。
- **あんずは空欄のまま出す。** 理由を言わない。
- 三年生の一年は、周りが全員どこかへ行く準備をしている一年である。

### 餃子パン

作品04の食べ歩きの日（二〇二八年十一月）から、二年半つづいている。

- いまは**土曜と日曜だけ**。柏尾製パンの店頭で売る。三百円で二個。
- 餃子はあんずが福来軒で包み、なつが柏尾製パンの窯で焼く。**窯は一つしかないので、パンを焼き終えてから焼く。**
- 週に四十個から六十個。売り切れる日と、余る日がある。
- **これは商売ではない。二人とも、まだそう思っていない。**

### 本作の事件——注文が来る

二〇三〇年九月、**市内の道の駅から定期の取引の打診が来る。**
週に百二十個。金曜納品。年内から。

これで、全部が変わる。

- 百二十個は、土日の店頭売りの二倍以上である。**二人だけでは包めない。**
- 定期で出すには**営業許可の確認**が要る。製造は柏尾製パン、餃子は福来軒。**二軒にまたがる。**
- **食品表示**が要る。原材料、アレルゲン、内容量、消費期限、製造者。**製造者は一軒しか書けない。**
- 原価計算が要る。いままでは「材料費は親から出ていた」。
- **どちらの店の売上にするのか。** これを決めないと、先に進まない。

つまり、**父親二人が、事業上の関係を結ぶことになる。**
二人は七年前に夏祭りで言い合っているが、**本作ではそれに一度も触れない。**
娘たちも触れない。もう覚えていない、のではなく、**もっと大きい問題が来たので、その話をしている場合ではない。**

### 屋根がない

二〇三〇年三月に撤去された。本作は、その翌月から始まる。

- **雨の日、五百メートルが濡れる。** 作品04第七章で、二人は夜に八番地から三番地まで天板を運んだ。あれは屋根の下だった。
- 本作でも同じ道を運ぶ。**今度は濡らせない。** 天板にかけるものが要る。
- 夏は暑い。餃子の生地が乾く。運ぶ時間が問題になる。
- 街路灯がないので、夜の納品は暗い。
- **なつは、屋根のあった十八年を覚えている唯一の語り手である。** 作品08のいとは知らない。

## 2. 人物

### 日下部 なつ（くさかべ なつ）18歳・高校三年・語り手

作品04から二年。**声が大きいのは変わらない。決めるのが速いのも変わらない。**
変わったこと——

- **決めてから考える、の「考える」が長くなった。** 二年前は決めた直後に走った。いまは決めてから、一晩置くことがある。置いたことを、本人は気にしている。
- 手が、もっと丈夫になった。熱いものを素手で持つ。指紋はいよいよ薄い。
- **数えるようになった。** あんずの真似である。まだ下手で、途中で分からなくなる。
- 癖は変わらない。考えるとき、粉をはたくように手のひらをこすり合わせる。粉はついていない。
- **父を「お父さん」ではなく「三代目」と呼ぶことが、一度だけある。** 喧嘩のとき。

### 宮地 あんず（みやじ あんず）18歳・高校三年

- 口数が少なく、一言が長い。理屈が先に立つ。数字で答える。
- なつが「やる」と言ったことに、必ず一度「無理でしょ」と言う。言ってから、やる。**これは変わらない。**
- **進路調査票を空欄で出した。** 理由を言わない。
- **十一月に、願書を出している。** なつには言っていない。
- 弟の遼が十四歳。福来軒を継ぐかどうかは、まだ誰にも分からない。
- 癖：包む手つきに無駄がない。階段で手すりを使わない。

### 二人の関係

- 作品04で「組んだ」二人が、二年半たっている。**もう説明のいらない関係になっている。**
  会話の半分が省略される。省略されたところを、地の文で補わない。
- **恋愛として書かない。友情としても固めない。** 名前のつかない関係の強度だけを保つ。
- **喧嘩は一度だけ。第七章。** 名義の話である。仕事の話にして、人格の話にしない。
- **仲直りの場面を作らない。** 翌朝、あんずが普通に包みに来る。

## 3. 文体

- **一人称。現在形と過去形を混ぜる。** 作品04と同じ語り手だが、**二年ぶん、文が長くなっている。**
  作品04は短文の連打だった。本作は、文の途中で一度立ち止まる。
- 会話が速い。二人の会話は、説明を省く。
- 数字を出す。個数、分、円、メートル。**なつが数えようとして失敗する場面を、各幕に一つ。**
- 会話と地の文を同じ行に混ぜない。
- 数字は漢数字。三点リーダーは「……」。ダッシュは「――」。
- 方言：なつ・あんず・父親たち・とし子は備後弁を**薄く**。森岡は標準語。

## 4. 守ること・やらないこと

### 守ること

- **作品04の快活さを殺さない。** 十八歳になっても、この二人は速い。笑う場面を各章に一つ。
- **仕事の手順を書く。** 包む、焼く、冷ます、運ぶ、詰める、貼る。手順が面白いと、生活が面白い。
- **父親二人を悪人にしない。** 娘のためでもなく、意地でもなく、商売として判断させる。
- **第十章は四月である。** 二人が店に立つ。作品08の八月へ、そのままつながる形で終える。

### やらないこと

- **七年前の夏祭りに触れない。** 一行も。
- **「継ぐ／継がない」を感動的にしない。** 誰も泣かない。誰も背中を押さない。
- **あんずが残る理由を、本人に説明させない。** 数字で言わせる。**その数字は、検算すると合わない。**
  なつは第十章で検算して、合わないことに気づく。**気づいて、言わない。**
- **父親に「継いでくれ」と言わせない。** 剛は一度も言わない。**それが本作のいちばん大事な不在である。**
- **餃子パンを成功させすぎない。** 週百二十個は、二人の生活を変えない。変わるのは、二人が商売を知ったことだけである。
