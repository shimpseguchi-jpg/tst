## 幕間11 の続きである

　二月二十日に市の要領が来て、二月二十七日に六人が「水曜の夜　二十時」と決めた。
　五つ目の欄は四行で埋まっている。**残っているのは、何を作るかである。**

## 曜日

　二〇三六年三月六日は木曜（幕間09）。したがって三日は月曜、五日は水曜、十二日は木曜、
　十三日は金曜、十八日は水曜。**申請の締切は三月十三日**である。

| 日 | |
|---|---|
| 三月三日（月） | 森岡が市に確かめる。「これは動画ではありませんが」。機械室の説明書を開く |
| 三月五日（水） | 八番地で録る。二十時。**切らない** |
| 三月十二日（木）十二時 | 通りに流れる。**十七曲の上に三分だけ乗る** |
| 三月十三日（金） | 申請を出す |
| 三月十八日（水） | 紙が返ってくる |

## 動画をやめた理由（作者の判断を本文に落とす）

　**誰も編集ができない。**

　沖田ちさとは「三か月やれば慣れます」と言ったが、**六人に三か月はない。**
　パン屋は四時に起き、中華屋は年に三日しか休まず、看板屋は乾くのを待ち、銭湯は週三日開ける。

　**本文では、この理由を誰にも長く喋らせない。**蓮見すずが一行で出す。

## いちばん大事な発見

　**十七曲は止めない。上に乗せる。**

- 一九九九年四月一日のプログラムは一曲も消さない。五十八分四十秒はそのままである
- **業務用のアンプには、マイクの入力がある。**一九九九年に機械を選んだ人は、使う前提で選んでいる
- **三十七年、誰も挿していない**
- 森岡は六年前、同じ説明書で**止め方**を調べた（作品07 第四章）。
  今度は同じ説明書の、**足し方**のところを読む
- 携帯をつなぐ変換のプラグが要る。**買いに行くのは山根とも。**二十四時間のホームセンターで、
  十年で二回目の買い物になる（作品14 第四章）

　**曲の上に声が乗ると、曲の切れ目が消える。**
　三十七年、誰も曲名を言えなかった（川本青果「聞こえとらんもん」／作品07 第四章）。
　**BGM にした週に、初めて曲が聞こえる。**これは本文で誰にも指摘させない。

## 流す時刻

　**十二時二十分から三分。**

　決めたのは宮地あんずで、理由は「十二時ちょうどは、うちの店がいちばん忙しい」。
　**三分という長さは、乗せられる長さではなく、六人が切らずに喋れる長さで決めた。**

## 誰が聞いていないか

　**三月十二日（木）の十二時、六人は一人も聞いていない。**

| | |
|---|---|
| 宮地あんず | 昼の営業のまんなか |
| 日下部なつ | 三時からの立ち仕事で、十二時は棚を中に入れる時間 |
| 黒江いと・蓮見すず | 銀紷堂。十四番地はスピーカーから遠い |
| 矢部さえ | **柏湯は木曜が掃除の日。**湯を落として床を洗っている（幕間09 の六日後） |
| 山根とも | 寝ている |

　**自分たちが作ったものを、自分たちだけが聞けない。**それでも続ける理由が、五章に要る。

## 沖田ちさとのこと（うっすらとだけ）

- **七年前、この人は紙で「止めてくれ」と頼んだ。**森岡は止めず、スピーカーを一個、
  **北へ四十メートル**動かした（作品10 第六章）。理由は言っていない
- 三月十二日、**ちさとは昼に起きて、その四十メートルを歩く。**
  七年前に遠ざけられた音を、自分で近づきに行く
- **十七曲のうち、一曲だけ知っている。**祖母が家でかけていた曲である

### ここで開けないもの（いちばん大事）

- **曲名を書かない。**「三曲目」のように番号だけにする
- **一九九九年四月一日にプログラムを組んだ人には触れない。**
  名簿は代表者しか載らない（作品12 第二章）。**ちさとの祖母と結びつけない**
- **祖母は市外で健在である。**死なせない。入院もさせない
- **ちさとは祖母に聞かない。**確かめる方法はあって、使わない
- 運命にしない。**同じ時代に、同じ曲が別の家でも鳴っていた。それだけである**

## 森岡佑のこと

- **放送を止めない理由を、この一篇でも言わせない**（作品07 でも作品10 でも言っていない）
- 名簿の八つ目の欄「呼び方」は、理事会を通していないので綴じられていない（幕間08）
- **森岡は自分の呼び方を、自分では書かない。**書くのは外からである

### 五章の落とし方（動かさない）

　返ってきた紙は四枚。

1. **マルヤの丸尾ふみ。**二〇三〇年二月の臨時総会で「屋根、外したら、あの音楽はどうなるん」と
   聞いて、「止まります」と言われた人である（作品07 第十五章）
2. 名前のない一枚
3. 柏湯の忘れ物のことを書いた一枚
4. **森岡の呼び方が書いてある一枚**

　**四枚目に何と書いてあったかは、本文に書く。**書いたのが誰かは、書かない。
