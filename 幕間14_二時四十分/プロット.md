# 幕間14『二時四十分』　プロット

　骨は動かさない。裏切るのは章内のディテールだけにする。

---

## 第一章　十二月十八日　月曜の夜（日下部なつ・一人）　二千百字

**軸を鳴らさない。一人なので、素の声で書く。**

| 場面 | |
|---|---|
| 1 | 二十一時に布団に入る。耳栓をする。**寝られない。**理由は分からない |
| 2 | 下りる。**翌日の粉を先に量る。**量ると寝られる。十二月は三キロ多い |
| 3 | **奥に明かりがついている。**祖母が起きている。テレビは消えている |
| 4 | 「四時に起こして」と言われる。なつは「はい」と言う。理由は聞かない |
| 5 | 量った袋を積む。**二時四十分に起きる体なので、あと五時間ある** |

　閉じ——**積んだ袋の上に、もう一袋のせて、高さが棚に当たる。**ずらす。

- **「四時に起こして」を、この章では一度しか言わせない。**二度目は第二章で分かる
- 祖母の様子を書かない。**言ったことと、していたことだけ書く**
- なつは忘れる。**忘れたとは書かない。**次の章で出てこないことで分かる

## 第二章　十二月十九日　火曜の午後（日下部なつ × 宮地あんず）　二千百字

**ここだけ軸が立つ。前を言う人と、次を言う人。**

| 場面 | |
|---|---|
| 1 | 三時に焼き上がって、売り切れる。なつが八番地へ行く。**用は店の用ではない** |
| 2 | 二時に閉めたあとの福来軒。あんずは洗いものをしている |
| 3 | なつが祖母のことを言う。「四時に起こして言われた」「なんで?」「知らん」 |
| 4 | **あんずが「去年も言ってた」と言う。** |
| 5 | なつは覚えていない。**去年、頼まれて、起こさなかった**ことも覚えていない |
| 6 | 誰から聞いたのか。**とし子本人が八番地で言った。**なつもその場にいた |
| 7 | なつが「明後日の四時、来れる?」と言う。あんずは返事をしない |

　閉じ——**あんずが洗いものを終えて、布巾を二回たたんで、台に置く。**

- **軸の出し方**：あんずの台詞は済んだ日から始まる（「去年」「おととし」「あのとき」）。
  なつの台詞はまだ来ていない日から始まる（「明後日」「来年」「次」）。
  **地の文はそれを指摘しない**
- あんずに「無理でしょ」と言わせない。**作品04 の癖の再演にしない**
- なつを落ち込ませない。**忘れていたことを、本人が気に病まない**

## 第三章　十二月十九日　火曜の夜（宮地あんず・一人）　二千百字

**軸を鳴らさない。あんずが一人でいる章は、連作で二度目である。**

| 場面 | |
|---|---|
| 1 | 二十三時十分すぎ。**この日は数が合っている** |
| 2 | 合っているのに上がらない。理由を自分で言わない |
| 3 | 去年の十二月に、とし子が八番地で喋ったときのことを思い出す |
| 4 | **そのとき、なつは隣で粉の話をしていた。**聞いていなかった |
| 5 | 行くかどうかを決めていない。**決めていないまま、目覚ましを四時に合わせる** |

　閉じ——**合わせたあと、画面を伏せて置く。**

- **「覚えている」と書かない。**思い出した中身だけ書く
- あんずに数を申告させない。**ノートを開かせない**
- 行くと決めたことを書かない。**目覚ましを合わせる動作で足りる**

---

## 第四章　十二月二十一日　木曜　四時（なつ・とし子・あんず）　二千百字

**三人いるので、軸を立てない。誰が喋ったかは、何に口を出したかで分かるように書く。**

| 場面 | |
|---|---|
| 1 | 二時四十分に起きる。四時まで一時間二十分ある。**この時間を数えたのは初めて** |
| 2 | 四時に祖母を起こす。祖母はもう起きている |
| 3 | **祖母が通りへ出る。**連作で初めてである。十二月の通りは暗い |
| 4 | あんずが立っている。来るとは言っていなかった |
| 5 | 三人で、何も言わずに立つ。**祖母は二番地に背を向けて、北の三番地を見ている** |
| 6 | なつが戻って、窯に火を入れる。**路面が戸の幅だけ明るくなり、二人はその中に立っている** |
| 7 | 祖母が戻ってくる。**何も言わない。**あんずが帰る |

　閉じ——**とし子が、奥の椅子に座って、いつもの位置に戻る。なつが粉の袋を開ける。**

- **とし子が四時に何をしに出たのか、誰も言わない。書かない**
- **「昔はここ、明るかった」と言わせない。**説明になる
- 三人の場面で、あんずに「前」を、なつに「次」を言わせない。**軸は切っておく**
- 代わりに、**何に口を出すかで割る**——
  とし子は足もと、あんずは寒さ、なつは時刻。**毎回ちがうものに口を出させる**
- 泣かせない。抱きしめない。手を握らせない
