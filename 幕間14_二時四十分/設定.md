# 幕間14『二時四十分』　設定

| 項目 | |
|---|---|
| 分量 | **全四章、五千九百三十七字。**章の幅は千二百〜千六百字 |
| 視点 | 一章 日下部なつ／二章 日下部なつ／三章 宮地あんず／四章 日下部なつ |
| 時期 | **二〇三四年十二月十八日（月）〜二十一日（木）** |
| 場 | 柏尾・三番地（柏尾製パン）／八番地（福来軒）／通り |
| 題の意味 | **なつが毎日起きる時刻。**四時までの一時間二十分を、この人は数えたことがない |

　年表の空き。作品16 が二〇三四年度を覆っているが、あれは十四番地の二人の一年で、
　**三番地と八番地はこの月、一度も書かれていない。**二人とも二十二歳。

## この一篇が試すもの

**三つとも、二〇三六年十月に決めた新しい規則の実験である。**

| | |
|---|---|
| **軸を組に付ける** | 宮地あんず × 日下部なつ の軸を、ここで初めて作る |
| **役割を剥がす** | 動く理由を定休日から取らない。**店の奥から出ない人を、通りに出す** |
| **速い篇の新しい数** | つなげ方はそのまま、一文ずつを長くする |

## 軸（この組で初めて立てる）

| | |
|---|---|
| **軸** | **前を言うか、次を言うか** |
| 宮地あんず | **前を言う。**「去年も」「三年前に」。済んだ日から話す |
| 日下部なつ | **次を言う。**「明後日」「来年」。まだ来ていない日から話す |

- **二人きりの場面でだけ立てる**（第二章）。第四章は三人いるので立てない
- 一人の章（第一章・第三章）では**鳴らさない**
- この軸は、二人のどちらの性質でもない。**この組でだけ起きる**

　既にある軸との重なりを確かめた。
　あんずは蓮見すずと「聞くか答えるか」、山根ともと「数えるか数えないか」。
　なつは矢部さえと「口が先か手が先か」。**どれとも別である。**

## 動く理由（店から取らない）

**定休日を使わない。**四篇続けて「誰が行けるかを定休日が決める」をやったので、ここでは使わない。

　動かすのは**家族**である。祖母が「四時に起こして」と言う。二度言う。
　**なつは一度目を聞き流し、二度目で気づく。**そして、一度目のことを覚えていない。

- 火曜・木曜を使う。**水曜（福来軒の休み）と日曜（柏尾製パンの休み）には何も起こさない**
- 十二月の通りには福引きの小屋が出ているが、**話には一切からませない**

## 日下部 とし子（としこ）七十四歳・なつの祖母

- 店の奥に座っている。よく喋る。よく間違える。よく当てる（作品04・09で既出）
- **先代（二代目）の妻。**なつの父が三代目である
- **この一篇で、通りに出る。**連作で初めてである
- 四時に何をしに出るのかは、**誰にも言わせない。ただし、読めるようにはする**
  —— 第一章に「四時に起きるのは父で、その前は祖父だった」を事実として一行置く。
  第四章で祖母は**北を向いて三番地の前を見る。**窯に火が入ると、路面が戸の幅だけ明るくなる。
  **二つを置けば足りる。説明はしない**
- **病気にしない。診断を出さない。誰も心配を口に出さない。**
  二度同じことを言う、それだけを書く

## 『一人のとき』から一つ使う

　`資料/一人のとき.md` から、**日下部なつの一つだけ**を使う。

> 　寝られない日は、翌日の粉の量を先に量っておく。量ると寝られる。／耳栓をする。三時に起きるため

- **第一章で使う。説明しない。やっているところだけ書く**
- **量っても寝られない。**そこだけが、いつもと違う
- 宮地あんずの「ノートの後ろの見開き」は**使わない。**一篇に一人ぶんである

## 四時のこと

- 柏尾製パンは**朝四時にドウを仕込み、六時に焼きはじめる**（作品04）
- なつの体は**二時四十分に起きる**（作品13 で確定。日曜も起きる）
- **四時は、この家の時刻である。**二代目が窯に火を入れていた時刻でもある。
  **そうとは書かない。**かわりに、**祖父がいたことだけは事実として置く**（第一章）。
  とし子が北を向いて立ち、中で火が入り、明かりが路面に届いて、その中に二人がいる、まで書く

## この一篇で補ったもの（以後、崩さない）

- **柏尾製パンは十二月に粉を三キロ増やす。**寒いと発酵が遅れるので早く仕込み、
  置くあいだに水が逃げるぶんを最初に足す。**なつが三年目の冬に一人で直した**
- **なつは粉を一袋ずつ量って合わせる。**二回で合う日と四回かかる日がある
- **流しの下に三袋なら棚の下に入る。四袋目は棚の裏板に当たる**
- **三番地の前の側溝の蓋が一枚浮いている。**自転車が通ると鳴る
- **二番地は、なつが生まれるより前から閉まっている**（一九九五年ごろ。十九年と七か月）
- **日下部とし子は立ったまま喋る。**椅子を出しても座らない
- 三年前、なつとあんずは注文の数で言い合って、**なつが負けている**

## 禁止

- **感傷に落とさない。**泣かせない。誰も「大丈夫?」と聞かない
- **地の文で性格を説明しない。**「この人は忘れる人だ」と書かない
- **軸を申告させない。**「あんたはいつも前の話をする」と言わせない
- 十一年前の夏祭りの決定打を出さない（作品04 の封を開けない）
- **二〇三四年十二月より先へ行かない**

## 文体の目標

**`python3 tools/文体.py 幕間14_二時四十分` で測る。**
速い篇。**ただし作品04『餃子パン』より、一文ずつを長くする**（小説執筆スキル §1-2）。

| | 目標 |
|---|---|
| **地の文の文** | **16–19 字** |
| 長文 | 2 %以下（四十字を超える文） |
| **一行の文数** | **1.8–2.3 文** |
| **地の一行** | **32–42 字** |
| 地の連（字） | 90–140 字 |
| 地の連（行） | 4 行以下 |
| 会話字 | 12–22 % |
| 会話行 | 40–60 % |
| 会話一行 | 8–13 字 |
| 会話の連（行） | 2.5 行以上 |
| 読点 | 26 字以上あける |
| 場面 | 5–8 ／章 |

　**四章のうち二章が一人の場面なので、会話字は作品04 より低くなる。**
　目標を二十五％のままにすると、一人の章に台詞を足すことになる。**足さない。**
　——書いたあとで、会話字と会話の連を本文に合わせて下げた。

　**説明している文はつなげる。落とす文は短いまま残す。**
　つなげたぶん、読点を足さない。読点は三文に二つまで。
