# 第七区

封鎖された市街地の一区画と、その外周の町を舞台にした連作。

## 何から読むか

| ファイル | 何 |
|---|---|
| `第七区/第七区設定.md` | **共有設定。**場・街区・人物・表記・年表の骨・原則 |
| `第七区/開示台帳.md` | **資料をどの作で開くか。**開けない三つの管理表もここ |
| `第七区/執筆工程.md` | 一章を書くときの手順。読点と忌避表現の基準 |
| `第七区/資料/` | いま開いている資料（作品01 の時点では二枚） |
| `第七区/作品01_四十分/プロット.md` | 第一作 |

## この連作の一行

　**本文は、世界を説明しない。説明するのは資料だけで、資料は一作ごとに一枚ずつ増える。**

## ほかの環境で使うとき

　AI Studio などへ移す場合は、**四つだけ貼れば足ります。**

1. `第七区/第七区設定.md`
2. `第七区/執筆工程.md`
3. `第七区/開示台帳.md`
4. 書く作品の `プロット.md`

　資料は、**その作で開くものだけ**を渡す。先の資料を渡すと、本文が説明を始めます。

## 測る道具

```
python3 tools/字数.py <file>    # 見出しと空白を除いた本文字数
python3 tools/読点.py <file>    # 本文二十四字に一つが目安
```
