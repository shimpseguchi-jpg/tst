# 商店街連作

新潟の**羽室銀座**と、広島の**柏尾銀天街**。二つのアーケード街を舞台に、
二〇二六年から二〇三六年までを共有する中編小説の連作です。

**本編 三十二篇・二百四十七章・七二八,二五一字。**
どこから読んでも、続けて読んでも成立します。

## 分類

**四つあります。分け方は `分類.md` にあります。**

| | どこ | 正史か | 何を壊しているか |
|---|---|---|---|
| **本編** | `作品NN_…/` 十八篇<br>`幕間NN_…/` 十四篇 | **正史** | 何も壊さない |
| **番外編** | `番外編/` 八篇 | ちがう | **書き方だけ。**正史と矛盾しない |
| **二次創作** | `二次創作/` 九篇 | ちがう | **世界のほう。**正史と矛盾する |
| **資料** | `資料/` 二十一点 | — | 本文ではない |

**作品と幕間は、長さが違うだけで扱いは同じです。**作品はそれ一篇で独立して読める中編、
幕間は本編と本編のあいだを埋める短いもの。どちらも年表に入ります。

**番外編は、書き方を本編に戻して書き直せば本編にできます。**実際に二篇そうなりました
（『一泊二日』→ 作品17『十四分』、『拡大餃子会』→ 幕間07『二十九枚』）。
**二次創作は、書き直してもできません。**壊したのが書き方ではないからです。

| | |
|---|---|
| 番外編 | 八篇・九十一節・八二,一五七字 |
| 二次創作 | 九篇・百三十一節・一〇二,〇五一字 |
| 読むもの | `reader/`（縦書きのリーダー。PWA） |
| 一言 | `資料/一言.md`。**各章の末に、その章の誰か一人の一言**（本文には書かない） |

字数は、見出しと空白を除いた本文の文字数です。

**各章の終わりに、その章に出ている人を一人だけ選んで、一言が置いてあります。**
名前のある人でも、通りすがりでもかまいません。書いてあるのは、
その章の本文が書かなかった一行です。**本文の `.md` には一行も入れていません。**
`資料/一言.md` に置いて、リーダーが章末に出しています。

## この連作の決めごと

- **完成した本文は改稿しない。** 連作との接続は、設定側とこれから書く作品側で処理します
- **人を店で呼ぶ。** 「山根さんとこの」「文林堂さん」。名前は要らないので、誰も聞きません
- **二人組は、軸を一つだけ決めて割る。** 方言／文の長さ／敬語／断定するかどうか
- **語り手を章題に出す。** 章ごとに語り手が替わる十三篇は、章題の末尾に（名前）が入っています。
  一人称が重なるので（作品18 は二人とも「わたし」）、誰が喋っているかを探させません
- **説明しない。** 心理を書かず、行動と、測れるもので書きます
- **封じてあるものは、開けない。** 番外で開けたものも、本編では閉じたままにします

文体の決まりは `商店街連作設定.md`、書く手順は `.claude/skills/小説執筆/` にあります。

## 番外編と二次創作について

本編で自分に課した制限を外して書いたもので、**どちらも正史ではありません。**
年表にも、既刊の数にも、字数の合計にも入れていません。

**十七篇とも、どこか一つだけを壊してあります。**表記を全部外したもの、地の文をなくしたもの、
文体をラノベにしたもの、書き分けの軸を逆にしたもの、地の文が酔うもの、人に点がつくもの。

**壊した場所がどこかで、二つに分かれます。**

> **書き方だけを壊したものは、番外編。書き直せば本編にできる。**
> **世界のほうを壊したものは、二次創作。書き直してもできない。**

「世界を壊した」とは、この世界にないことが起きる（時間が戻る、入れ替わる、薬が効く）、
人から店を剥がす、封じてあるものを開ける——のどれかです。

**番号（一〜十七）は書いた順の通し番号で、二つの区分をまたいでいます。**動かしません。

## 資料

本文に書いていないことだけを置いてあります。**答え合わせではありません。**

身長体重と手の大きさ（`寸法.md`）、鞄に入っているものと入っていないもの（`鞄の中.md`）、
給料と家賃（`お金.md`）、誰が誰をどう呼ぶか（`呼び方.md`）、画面の向こうに何を出しているか
（`SNS.md`）、一人になったとき何をしているか
（`一人のとき.md`）、互いへの第一印象（`互いへの印象_…`）、組合事務員が書いたレポート、
地方紙の紙面四号ぶん。

## リーダー

`reader/index.html` の一ファイルで動きます。一度開いた本文は端末に保存され、圏外でも読めます。

| | |
|---|---|
| **一覧** | **作品と幕間に分かれています。**「時系列順」に切り替えると、作中の年で並びます |
| | 題名・紹介・章題で**探せます** |
| | **つづき**の札が上に出ます。最後に読んだ章の、読んだところから始まります |
| **本文** | 縦書き／横組み、字の大きさ四段、行の間三段、明るさ三通り。**「設定」から** |
| | **画面のはしを押すと送れます。**まんなかを押すと全画面。矢印と空白でも送れます |
| | 章の終わりで「次の篇へ」。**篇をまたいで読み進められます** |
| **目次** | **いま読んでいる一篇だけひらいています。**ほかは題名を押すとひらきます |
| **しおり** | 章だけでなく、**章のどこまで読んだか**も覚えます |

設定は端末に覚えます。**どの端末でも同じにはなりません。**

作品一覧のいちばん下に「？」があります。開くと、番外編と二次創作が区分ごとに分かれて並びます。

```
cd reader && python3 -m http.server 8000
```

### データの作り直し

本文の `.md` から、リーダー用の JSON を作ります。本文を直したら、必ず流し直してください。

```
python3 tools/リーダー用データ.py     # 本編（index.json / NN.json）
python3 tools/本編外データ.py         # 番外編と二次創作（x.json / xN.json）
python3 tools/資料データ.py           # 資料（guide.json / report.json）
python3 tools/紙面データ.py           # 備陽新報の紙面
```

`資料データ.py` の年表と作品一覧は、`商店街連作設定.md` から**生成**しています。
手で二重管理しないでください。

本文を更新したら `reader/sw.js` の `CACHE = "shotengai-vNN"` を上げます。上げないと、
一度読んだ端末に古い本文が残ります。

## 測る

```
python3 tools/字数.py <ファイル>     # 見出しと空白を除いた本文字数
python3 tools/読点.py <ファイル>     # 読点の密度
python3 tools/文体.py <ファイル>     # 一章／一篇の速さを十二の数で
```

**読点は二十字を切ったら多すぎます。**これは全作共通の下限です。
目標そのものは作品ごとに違い、`設定.md` の「文体の目標」に書いてあります。
増える原因はほぼ「〜は、」で、主語が短く述部も短く対比もないとき、その読点は要りません。

### 作品ごとの速さ

**この連作は、作品ごとに速さが違います。**速さは好みではなく、その作品の中身です。

| | 作品04『餃子パン』 | 作品13『重ならない』 |
|---|---|---|
| | **いちばん速い** | **いちばん遅い** |
| 地の文の文 | 14 字 | 17 字 |
| 一行の文数 | 1.8 文 | 1.2 文 |
| 会話（字） | 33 % | 6 % |
| **地の文が続く長さ** | **72 字** | **371 字** |
| 地の文の一行 | 26.4 字 | 21.9 字 |
| 読点 | 29.7 字に一つ | 24.6 字に一つ |

**速い篇でも、本文の三分の二は地の文です。**減るのではなく、切り方が変わります。
『餃子パン』は一行に文を二つ近く入れ、その行を二つ三つ重ねて七十字、
そこで必ず誰かが喋る。『重ならない』は六人が別々の休みにいる話なので、
**声が返ってこない時間の長さが中身です。**

**「地の文が多い」と「遅い」は別です。**多いまま速くできます。

**これから書く速い篇は、つなげ方はそのままに、一文ずつを長くします**
（地の文の文 16–19 字、一行の文数 1.8–2.3、地の一行 32–42 字）。
説明している文をつなげ、落とす文は短いまま残します。工程は `小説執筆` スキルの §1-2 に。

`tools/文体.py` は、`設定.md` に「文体の目標」の表があれば突き合わせて、外れた行に ← をつけます。

## 一章を書く手順

`.claude/skills/小説執筆/SKILL.md` に工程があります。要点だけ。

1. 共有設定 → 作品の設定 → プロット → あらすじ記録、の順に読み直す
2. **一発目から目標字数で書く。**短く書いて後から足さない
3. セリフは独立行。感情を直接説明しない。章の終わりは物か動作で閉じる
4. 字数と読点を測る
5. 読者三人（作者・連作の読者・前作未読）に読ませてから最終稿にする。**初稿は出さない**
6. あらすじ記録に二百字要約を足し、補ったディテールを設定に追記する
