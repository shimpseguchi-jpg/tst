# カルティア想造録

PlayStation『レブス』（アトラス／1998）をモチーフにした、小学生向けの漢字学習ゲーム。
ブラウザだけで動く。ビルド不要、`index.html` をひらけば遊べる。

## モチーフとの対応

原作では、漢字一文字が書かれた札「カルティア」を**意味のつながるように組み合わせる**と法術になる
（「流」＋「水」＝ 攻撃法術「流水」）。最高位のカルティア「オリジナル」は天・地・人・生・死・無の六種、
想造される幻獣には一般体コモン・金属体ドール・精神体シャドウの三種族がある。

このゲームはその仕組みを、**「よみ」と「いみ」から二字熟語を組み立てる**という書き取り学習に置きかえた。

| 原作 | 本作での読みかえ |
| --- | --- |
| カルティア（漢字一文字の札） | 手札の漢字カード |
| 文字と文字を組み合わせる想造 | 二枚を想造盤に置いて熟語をつくる |
| オリジナル 天・地・人・生・死・無 | 六つの層の核。各層が小学1〜6年の配当漢字に対応 |
| 幻獣の三種族 | 出題の手がかりの量（下記）を変える |

### 幻獣の三種族が難易度になっている

- **一般体コモン** — よみと いみの両方が見える。手札8枚。
- **金属体ドール** — 手札が10枚に増え、まぎらわしい札が多くなる。
- **精神体シャドウ** — いみが隠れ、よみだけが手がかり。実質の書き取り。

## 遊びかた

1. 層（学年）をえらぶ。
2. 詠唱書に出る**よみ**と**いみ**を手がかりに、手札から漢字を二枚、順番どおりに想造盤へ置く。
3. 「想造」で判定。正解なら法術が発動して幻獣にダメージ、まちがえると心が一つ減る（5つで力尽きる）。
4. ヒントを使わず3回続けて正解すると**オリジナルが発現**し、次の一撃が倍の威力になる。
5. 幻獣3体を退けると層を踏破。

キーボードでも遊べる（`1`〜`9` で札をえらぶ／`Enter` で想造／`Backspace` で置きなおし）。

## まなびノート

まちがえた熟語は自動でノートにたまり、**正しく想造できると消えていく**。
ノートだけを相手にする復習戦（幻獣「記憶ノ影」）も用意した。
進みぐあい・ノート・音の設定はブラウザの localStorage に保存される。

## 収録語

小学校の学年別漢字配当表にそった二字熟語 186 語。どの語も、その学年までに習う漢字だけでできている。

| 層 | 核 | 学年 | 語数 |
| --- | --- | --- | --- |
| 芽生ノ層 | 生 | 1年 | 28 |
| 大地ノ層 | 地 | 2年 | 30 |
| 人跡ノ層 | 人 | 3年 | 32 |
| 蒼天ノ層 | 天 | 4年 | 32 |
| 幽冥ノ層 | 死 | 5年 | 32 |
| 虚無ノ層 | 無 | 6年 | 32 |

## 語をふやす

`assets/data.js` の該当する層の `words` に `['熟語', 'よみ', 'いみ']` を足すだけ。
まぎらわしい札（ダミー）はその層の熟語から自動で集めるので、他に直す場所はない。
いみの文は、その学年の子が読めるようひらがな主体で書くこと。

## ファイル

```
index.html         画面の骨組み
assets/data.js     熟語と幻獣のデータ
assets/game.js     ゲーム進行
assets/style.css   見た目
```

外部ライブラリなし。効果音は Web Audio API でその場で合成しているので音声ファイルもない。
