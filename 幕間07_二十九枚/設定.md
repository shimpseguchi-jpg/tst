# 幕間07『二十九枚』設定

連作の幕間・七本目。**全九章。およそ一万四千字。**
もとは番外の四本目として書いたものを、そのまま本編に入れた。**落とした行はない。**

- **時期**　**二〇三五年七月二十五日（水）— 八月二十二日（水）**
- **視点**　三人称。**あとから記録した人の距離**で書く（「あとで分かったが、宮地はその場では分からなかった」）
- **場所**　八番地・福来軒。組合事務所。通り

## 0. この幕間で起きること

　**六人の水曜に、通りが二十九軒ぶん入ってくる。**

　仕掛けは作品13 の答えを裏返したものである。
　二十九軒が二十九回、別々に休みを決めたから合わない。二十九軒で重なる日は数える前から〇である。
　**だから重ねるのをやめて、一日だけ全部閉めた。**

## 1. 走らせるもの

1. **森岡が組合の名簿に三十年ぶりに欄を足す。**「定休」の二文字。
   用途の欄には「その他」とだけ書く。**「書くと、理由が残ります」**
2. **石垣理事長が祭りの日を避ける。**「祭りの日にやったら、祭りのぶんになります」
3. **塚本律子が座る。** 幕間04 では戸口で三往復して帰った人である
4. **川本青果の店先に立つ人が名前を言う。**「川本ゆき」。作品12 で藤木かなえが聞けなかった名前
5. **三田村燈子が羽室から柏尾へ来る。** 連作で初めての北から南である。
   来る理由は仕事（食品パッケージ／柏尾製パンの一括表示）
6. **宮地あんずと沖田ちさとが同じ部屋にいる。**（第七章・第九章）

## 2. 開けていないもの

- **塚本律子の月曜の行き先。** 欄に書いたのは曜日だけである。「行き先の欄はないんか」「ありません」
- **文林堂の二階。** 沢渡ふゆが戸の下から紙を入れて、戸の下から返ってくる。「皆さんによろしく」
- **森岡が見てしまったもの。** この夜、森岡は鞄を持っていない。書類にしない
- **山根ともが彫っていること。** 父の吉春が言うのは「あれは、ようできとった」の一行だけで、
  誰が彫ったとは言っていない。**厨房の二十八人のうち二十六人が聞き流す**

## 3. 数

| | |
|---|---|
| 皮 | 五百枚頼んで三百枚しか来ない。残り二百枚は宮地健一が打つ。厚みが〇・七〜一・〇で揃わない |
| 包んだ数 | 道の駅へ百二十、焼いたのが五十八（二十九人×二個） |
| 余った皮 | 三百二十枚のはずが二百九十一枚。**二十九枚足りない。人数と同じ数である（偶然）** |
| 人数 | 三度数えて二十九、三十、二十九。**二度目に一人多いのは矢部タカが立ったからで、本人はその場で気づかない** |
| 冷蔵庫の紙 | **八枚目。『一』の一字と日付だけ。**人数が書けなかったからである |

**作品13 の五枚目（六、四、一、〇）には何も足していない。**
〇の下に書き足すのではなく、別の紙にした。

## 4. 最後の一往復

　「馴染めましたか」——二〇三三年一月三十一日に、あんずが四年で初めて打った一行である。
　沖田ちさとは何千と来るコメントのうち、その一行だけを覚えている。
　**あんずは「はい」と答えない。**かわりに年数を言う。「六年と七か月です」
　題の二十九枚は、足りなかった皮の枚数であり、その夜の人数でもある。
