# 縦書きリーダー

`作品0*/*章.md` から本文を取り出して、縦書きで読むためのページ。

## 更新のしかた

章を書き足したり直したりしたら、リポジトリのルートで

```
python3 tools/リーダー用データ.py   # 本文 → reader/data/0*.json
python3 tools/資料データ.py         # 人物・店・年表 → reader/data/guide.json
```

`資料データ.py` の中身（人物・店・年表）は手書きなので、
新しい作品を書いたらこのファイルに追記する。

人物の詳細（本名・生まれ・見た目・身体・心・喋り方・癖・
ほかの人から見た印象・まだ書いていないこと）は
`tools/人物詳細.py` に分けてある。
店の詳細（看板・創業・店にいる人・営業時間・中のようす・
売れるもの・通りの人の口コミ・まだ書いていないこと）は
`tools/店詳細.py` に分けてある。
どちらも名前をキーにした辞書で、
`資料データ.py` が読み込んで guide.json に混ぜる。
**本文と食い違ったら、本文が優先。人物詳細.py のほうを直す。**

## 中身

- `index.html` — ページ本体。外部ライブラリなし
- `data/index.json` — 作品一覧
- `data/0*.json` — 各作品の本文
- `data/guide.json` — 資料（人物・店・年表）

## ローカルで見る

```
cd reader && python3 -m http.server 8811
```

`fetch` を使うので、ファイルを直接開くのではなくサーバー越しに見る。

## ホーム画面に追加する（Android / iOS）

リーダーはPWAとして動く。`manifest.webmanifest` と `sw.js` と `icons/` がその一式である。

- **Android（Chrome）**　メニュー →「アプリをインストール」または「ホーム画面に追加」。
  インストールできる状態のときは、作品一覧の下に「ホーム画面に追加」ボタンが出る。
- **iOS（Safari）**　共有 →「ホーム画面に追加」。`beforeinstallprompt` は来ないのでボタンは出ない。

`sw.js` は**ネットワーク優先、失敗したらキャッシュ**である。
本文を更新して再公開すれば、オンラインなら次に開いた時点で新しいものが出る。
古い本文がキャッシュに残り続けることはない。圏外のときだけキャッシュが使われる。

キャッシュを作り直したいときは `sw.js` の `CACHE` の版数を上げる。

### 公開URLで使いたい場合

claude.ai のアーティファクトはログインが要る。ログイン不要の常設URLにするなら
GitHub Pages に `reader/` を出す。`.github/workflows/pages.yml` を用意してある。
リポジトリの Settings → Pages → Source を「GitHub Actions」にしてから、
Actions タブで `reader を GitHub Pages に出す` を手動実行する。

## 紙面

`資料/備陽新報_*.md` を `python3 tools/紙面データ.py` にかけると `reader/data/paper.json` になり、
「紙面」タブに一ページぶんの新聞として出る。縦書き、固定寸法（一四〇〇×二〇〇〇）で組み、
表示のときだけ幅に合わせて縮小する。スマホでは全体が小さくなるので、
「記事を大きく読む」で本文だけを読める形にしてある。

紙面は連載四回ぶんある。`資料/備陽新報_2031-11-03.md` から `-11-24.md` まで。
`写真:` に 窯／筆／桶／通り のどれかを書くと、その線画が出る。

**寸法は `資料/備陽新報_紙面規格.md` による。** 作中の記述から割り出してある。
一ページ十五段、一段四十七行、一行十一字、一段五百十七字。主記事は段一〜七（半ページ）。

本文は**段から段へ流す**。入りきらない段落は切って、次の段の頭から続ける。
縦書きの段組みはCSSで組めないので、二分探索で切れ目を出している。

**本文が短い回は、写真の段数が増える。** 二段から五段のあいだで、本文が入る
いちばん大きい写真を選ぶ。最終回は写真二段・題〇・五段・本文四・五段で、
第二十一章の割りつけと一致する。

源のmdの書式は `tools/紙面データ.py` の先頭に書いた。`## 主記事`／`## 記事`／`## 広告`／
`## 天気`／`## おくやみ` の塊に分け、`キー: 値` と、`本文` 以降の本文で書く。
**本文は空行で段落に切れる。** 縦書きでは段落が新しい行を起こすので、
一文ごとに空行を入れると段が増えて入らなくなる。
