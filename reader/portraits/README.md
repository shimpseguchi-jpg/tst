# 人物の一枚絵

ここに置いたものが、リーダーの人物カードと詳細シートに出る。

- **ファイル名**　`tools/人物詳細.py` の `art=` に書いてあるスラッグと合わせる。
  例：`D["藤木 かなえ"]` の `art="portraits/fujiki-kanae.webp"` → `fujiki-kanae.webp`
- **形式**　WebP。鉛筆画のグレースケールなので、品質八十でも十分もつ。
- **大きさ**　長辺九百ピクセル。一枚八十〜百五十キロバイトを目安にする。
- **比率**　自由。カードは上寄りで正方形に近く切り抜かれる（顔が上に来る構図が合う）。
  詳細シートでは原寸の比率のまま、高さだけ画面の五十六パーセントで止まる。

**置いていない人は、名前の一文字が代わりに出る。** 壊れた画像のアイコンは出ない。
ファイル名を間違えた場合も同じで、静かに一文字に戻る。

絵の指定は `資料/一枚絵_指定.md` と `資料/生成プロンプト.md` にある。
**滝沢篤子と橘ひなたは描かない。** 理由は指定書の「描かないこと」に書いた。

## 取り込み方

生成したものをそのまま `_取り込み/` に放り込んで、

```
python3 tools/絵を入れる.py
```

グレースケール化、長辺九百への縮小、WebP変換、名前の付け替えまでやる。
**ファイル名は適当でよい**。『藤木』でも『fujiki』でも『kanae』でも拾う。
拾えなかったものは触らずに残し、最後に一覧で出す。
同じ人に二枚あたった場合も警告が出る。

Pillow が要る。無ければ `pip install Pillow`。

置いたあとは、アーティファクトなら `portraits/*.webp` を同梱して再公開する。
