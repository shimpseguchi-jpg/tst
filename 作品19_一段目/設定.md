連作十九作目。**黒江いとと蓮見すずが、一緒に住む家を決めて、移る話。**
作品16『三段目』の続きにあたる。あちらは近づくまでの一年、こちらは住むまでの五週間。

## 筋

　十一月二十一日の水曜、沖田ちさとが旅行の話をした夜に、蓮見すずが「……黒江さんと相談します」と言った（作品17 第九章）。
　**相談するのは旅館のことだった。**黒江いとは、その夜、一階の部屋がある旅館を探して、条件を紙に書きはじめる。
　書いているうちに、旅館の条件ではなくなる。**「部屋が二つ」は、一泊には要らない。**
　家を決めるのは黒江である。蓮見は、決めたものを測る。

## 封じるもの（一つだけ）

**黒江いとが、条件の三つ目に「踏切から歩いて五分」と書いた理由。**
書いたことは書く。黒江は条件の一つ一つに理由を添える人なのに、三つ目にだけ理由がない。蓮見は聞かない。本人も言わない。
**黒江が月に二回あの踏切を渡っている理由も、書かない**（作品16 第十一章・幕間06 で「月に二回くらい通る」とだけ言っている）。

## 人を芸にしない

| | |
|---|---|
| 黒江の長い説明 | **一章に一回まで。**全部書くのは一章と八章だけ。あとは途中で切る |
| 蓮見の数 | 測るのは物だけ。**自分の字数・歩数・回数は申告しない** |
| 黒江の「順番です」（作品17） | 使わない |
| ちさとの仕返し | 六章で一回だけ。「布団は」。**蓮見が答える** |
| まだ書いていない面 | 矢部さえ「朝が弱い」（八章）。**これだけ使う** |
| 一人のとき | **森岡佑「誰にも出さない書類を作る」**（五章の終わり） |
| 店にいないところで出す | 宮地あんず（八章、引っ越しの午後） |
| 定休日で人を選ばない | 引っ越しの日を日曜にしたのは銀紷堂の二人の都合（土曜は荷造りと鍵の受け取り）。**来られる人が来る** |
| 一人の癖は一回 | 黒江「聞いたことを繰り返す」（作品17）は使わない。蓮見「声を出さずに笑う」は九章で一回だけ |

## 文体の目標

**`python3 tools/文体.py 作品19_一段目` で測る。**作品16 より少し速い。六章と八章は人が多いので速くなってよい。
