# 幕間15『一年と九日』　プロット

---

## 第一章　十一月十二日　月曜の夕方（宮地あんず）　二千字

**二人きり。軸が立つ。あんずは前を言う。**

| 場面 | |
|---|---|
| 1 | 階段を下りる。急なので音が大きい。**出したのはなつで、あんずは出てこないと思っていた** |
| 2 | 外は暗い。十一月の十八時である。アーケードの電球は、切れたまま替えていない |
| 3 | **用がなくなった。**二人とも、そのことに気づいている。口には出さない |
| 3の2 | **九番地の前を通る。**四月末に閉めた時計屋で、貼り紙が残っている |
| 4 | **八番地の前を通る。**十四時に閉まっている。あんずは寄らない |
| 5 | **三番地の前を通る。**十八時半まで開いている。父親が立っている。なつは寄らない |
|  | ——事務所は十番地なので、**南へ行くと八番地が先、三番地があと** |
| 6 | 通りの南の口まで来る。ここで別れるのが普通である |
| 7 | **なつが「駅のほう、行ったことある?」と言う。** |

　閉じ——**あんずが鞄を持ち直す。**返事はまだしていない。

- あんずの台詞は、済んだ日から始まる（「去年の十一月三日」「あのとき」）
- **「用がない」と地の文で言わない。**寄らなかったことだけ書く
- 二人の店の前を二度とも通り過ぎる。**これが用のなさである**

## 第二章　十一月十二日　月曜の夜（日下部なつ）　二千二百字

**二人きり。軸が立つ。一度だけ入れ替わる。**

| 場面 | |
|---|---|
| 1 | 駅に入る。改札は通らない。**自由通路を渡る** |
| 2 | **なつが出口をまちがえる。**西と東。直す。説明しない |
| 3 | 向こう側は明るい。ロータリーがあって、チェーンの店がある |
| 4 | **人がいる。**こちらが寂れていることを、向こうは何も言わない |
| 5 | ゲームセンターの前を通る。入らない。**入る理由がない** |
| 5の2 | **牛丼の店の前を通る。**匂いの話を一度だけして、なつが自分で止める |
| 6 | 自動販売機で二本買う。あんずが先に出す。**一本百六十円。半分で百六十円** |
| 6の2 | **屋根がない。**雨の日の話をする。比べない |
| 7 | **「去年、うちら敵じゃったね」——「来年は」**。ここで軸が入れ替わる |
| 8 | 帰りは踏切のほうへ回る。三百メートル南 |

　閉じ——**踏切が鳴る。二人が止まる。電車が通って、音がやむ。渡る。**

- **比べさせない。**「向こうは人がいる」とは書くが、「こっちは誰もいない」とは書かない
- 「次は何を作る」をなつに一度だけ言わせる。**あんずは答えない**
- 七百八十円を、二人とも一度も口に出さない
- **言葉**：あんずは標準語、なつは広島弁。**どの章でも入れ替えない**

## 第三章　同じ日の夜（宮地あんず）　千八百字

**一人。軸を鳴らさない。素の声。**

| 場面 | |
|---|---|
| 1 | 二十二時すぎ。厨房に下りる。明日のぶんを数える |
| 2 | **合っている。**合った日はそのまま上がる |
| 3 | 上がらずに、丸椅子に座る |
| 3の2 | **レシートの缶を出す。**去年ここから出した。足りなかった一枚はここにない |
| 4 | ノートを出す。表は数である。**後ろの見開きは、まだ白い** |
| 5 | 後ろを開いて、日付を書く。**十一月十二日。七百八十円** |
| 6 | 意味は書かない。**書かないことを、自分でも分かっていない** |

　閉じ——**ノートを閉じて、台の上に伏せて置く。**

- 数を申告させない。**合っている、とだけ書く**
- 「寂しい」「終わった」を書かない。**座ったことと、書いたことだけ**
- 駅の向こう側の話を、ここで思い出させない。**一度も出さない**
