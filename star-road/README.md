# まなびスターロード

小学1年生の **こくご・さんすう・えいご** を、
**ターン制バトル × 分岐マップのローグライク**であそぶブラウザゲームです。
iPad / スマホのタッチ操作前提。外部ライブラリ・通信なしで動きます。

- バトル：『崩壊：スターレイル』がモチーフ（行動順・弱点撃破・スキルポイント・必殺技）
- 進行 ：『Slay the Spire』がモチーフ（分岐マップ・レリック収集・HP持ち越し・全滅で最初から）

`star-road/index.html` を開くだけで遊べます。

---

## いちばん大事なところ

**「こうげきを選ぶ」と、そのキャラの教科の問題が出ます。**
正解なら通常のダメージ、まちがえると 0.3倍のよわい攻撃になります。
つまり *問題を解いた回数 = 戦った回数* です。1回の戦闘でおよそ 8〜16問を解きます。

さらに **速く答えると「かいしん（会心）」が確定**します（制限時間の 60% 以上を残して回答）。
「わかっている問題を、すばやく答える」ことに、ちゃんとごほうびがあります。

## バトル（スターレイル風）

| しくみ | 中身 |
|---|---|
| **こうどうじゅん** | 行動値 `10000 ÷ すばやさ` で順番が決まります。画面上部に次の7手を表示。 |
| **じゃくてん・げきは** | 敵には弱点教科（📖/🔢/🔤）と「じゃくてんバー」があります。弱点の教科のキャラで**正解**すると削れ、0になると**げきは**：追加ダメージ＋敵の行動が大きく遅れる（よろける）＋以後 1.18倍のダメージ。 |
| **スキルポイント (SP)** | 3人共有・最大5。通常攻撃を**正解**すると +1、せんぎで -1。 |
| **ひっさつ** | ゲージ100%で使用可。**ターンを消費せず**、他のキャラのぶんも自分の番に撃てます。 |
| **まちがえたとき** | ダメージ 0.3倍・弱点バーは削れない・通常攻撃でもSPが増えない（レリック「あかペン」で 0.6倍に緩和）。 |

弱点をつく＝「その教科をちゃんと解けた」ということなので、
**3教科をバランスよく解けるほど戦闘が有利になる**設計です。
3教科すべてを使って勝つと、おまけにHPが回復します。

## マップ（Slay the Spire 風）

1ステージは 8フロア＋ボス。分かれ道を選びながら上へ進みます。全3ステージ。

| マス | なにが起きる |
|---|---|
| ⚔️ もぎせん | 制限時間つきの問題を解きながら戦闘。勝つとステータスアップ＋レリック3択 |
| 💀 エリートせん | もぎせんの高難易度版（問題も1段むずかしく、制限時間も短い）。報酬も大きい |
| 🏋️ とっくん | 3つの特訓メニューから選び、**制限時間なし**で3問。正解ぶんだけステータスが上がる |
| ❓ イベント | 10種類のできごと。選択肢で回復・レリック・ステータスなど |
| 🔥 きゅうけい | HP回復／自主べんきょう（2問でステータスアップ）／ゲージ回復 の3択 |
| 👹 ボスせん | 各ステージの最後。倒すと次のステージへ |

HPは次のマスへ持ち越し、倒れた仲間は戦闘に勝てば 25% で復帰します。
3人とも倒れると最初から。進行は**自動セーブ**され、「つづきから」で再開できます。

## 学習の中身

すべて4択です。むずかしさはステージ1→3で上がり、エリート／ボスではさらに+1されます。

| 教科 | レベル1 | レベル2 | レベル3 |
|---|---|---|---|
| 📖 国語 | 1年生の漢字（山・川・花・目・耳…）、はんたいのことば、なかまのことば、かぞえかた、カタカナ | 学校・先生・天気などの熟語、大きい／小さいなどの送りがな、のばす音（おとうさん／こおり） | 一年生・男の子・王さま・右手 など、動きの漢字（出る・入る・立つ） |
| 🔢 算数 | 10までのたしざん・ひきざん、いくつといくつ、かずをかぞえる、かずのならび | くりあがり・くりさがり、10といくつ、3つのかず、ぶんしょうだい、かずくらべ | 100までのかず、とけい（なんじ・なんじはん）、20までの計算、なんばんめ、ちがいはいくつ |
| 🔤 英語 | いろ・どうぶつ・かず（one〜five）・あいさつ・アルファベットの大文字小文字 | たべもの・もちもの・からだ、one〜eight | すこし長い単語、アルファベットの順番、Nice to meet you など |

まちがいの選択肢は、**つまずきやすい値**を選んであります。

- 算数：`8+5` に対して `12`（くり上がり忘れ）や `14`（±1）
- 国語：`体育` に対して `たいく`、`こおり` に対して `こうり`
- 英語：`child` に対して `childs` / `childes`

答えたあとには、かならず**とき方の解説**が出ます（`さくらんぼ計算`のような手順の式、`8 + 5` なら
`8 に 2 たして 10、のこり 3 で 13`）。

## レリック

18種類。戦闘・イベント・宝箱で手に入り、ステージをまたいで持ち越します。

`✏️ きんの えんぴつ`（国語キャラの攻撃+15%）／`⌛ ストップウォッチ`（制限時間+6秒）／
`🖊️ あかペン`（まちがえてもダメージが減りにくい）／`👓 ヒントめがね`（戦闘1回につき1度、選択肢を2つに絞れる）／
`🌸 はなまるシール`（連続正解で会心率アップ）／`🔩 ドリルのおまもり`（弱点をついたダメージ+30%）…

|---|---|

## ファイル

```
star-road/
  index.html          画面の骨組み
  css/style.css       見た目
  js/questions.js     問題の生成（3教科 × 3レベル / 50カテゴリ）
  js/data.js          キャラ・敵・レリック・イベントのデータ
  js/engine.js        マップ生成・ステータス・セーブ
  js/quiz.js          問題オーバーレイ（制限時間・ヒント・解説）
  js/battle.js        バトル（行動順・弱点撃破・SP・必殺技）
  js/ui.js            マップ／とっくん／イベント／きゅうけい／報酬の画面
  js/main.js          起動
  tools/playtest.js   自動プレイテスト（バランス調整・回帰テスト）
```

## 中身をかえる

| したいこと | 場所 |
|---|---|
| 出題を足す・かえる | `js/questions.js` の `KANJI` / `HANTAI` / `WORDS` などの配列、算数は `mathGen` |
| 問題のむずかしさの上がり方 | `js/engine.js` の `difficultyFor()` |
| 制限時間 | `js/engine.js` の `timeLimitFor()`（もぎせん24秒／エリート20／ボス18秒） |
| 「かいしん確定」のライン | `js/battle.js` の `res.speed > 0.6` |
| まちがえたときの弱さ | `js/battle.js` の `wrongMult`（既定 0.3） |
| キャラの性能・技 | `js/data.js` の `CHARS` |
| 敵の強さ・弱点 | `js/data.js` の `ENEMIES`、伸び方は `js/engine.js` の `rollEnemies()` |
| レリック | `js/data.js` の `RELICS`（効果の適用は `engine.js` の `charStats()` と `battle.js`） |
| イベント | `js/data.js` の `EVENTS` |
| マップの長さ・分岐 | `js/engine.js` の `FLOORS` / `COLS` / `PATHS` と `genMap()` の `WEIGHTS` |

## じどう プレイテスト

「せいかいりつが X% の子」を、ほんもののゲームの上で実際に遊ばせて、
どこまで進めるか・何問解くことになるかを測ります。

```
npm i playwright
node tools/playtest.js                     # 90/70/50/30% を 3回ずつ
node tools/playtest.js --acc 0.5 --runs 6  # せいかいりつ 50% を 6回
node tools/playtest.js --acc 0.9 --shots   # スクリーンショットも .shots/ に保存
```

ブラウザの場所を指定したいときは `PW_CHROME=/path/to/chrome`。
ページエラーを1つでも拾ったら終了コード1で落ちるので、そのまま回帰テストに使えます。
