# 第七章　七月十一日　水曜の夜（矢部さえ）

　あの夜から、三週間たった。

　水曜の厨房で、手を洗えと言われる人はもうおらん。宮地さんは来た人に「おつかれ」と言う。前からそうじゃった。前からそうじゃったのに、一回ちがうのを聞いた。じゃけえ毎週「おつかれ」が来るたびに、五人とも一回だけ宮地さんの顔を見る。

　見られとるのは、宮地さんも知っとる。知っとって、何も言わん。

　水曜の柏湯は開いとる。十九時を過ぎたら、番台を祖母に替わってもらう。替わるときに祖母は釣りの皿を自分のほうへ引く。うちの顔は見ずに「行っといで」と言う。三週間前の水曜もそう言うた。帰ってから、厨房で何があったかは聞かれんかった。聞かれんで、よかった。言うたら、うちはたぶん番台で笑う。

　柏湯から八番地までは、通りを南へ七分じゃ。七月の十九時は、まだ明るい。十四番地の板は中に入れてあって、マルヤの戸は半分閉まっとった。

　うちは十九時半に着いて、流しで手を洗うた。ブラシは流しの右にある。前からそこにあった。前からあったのに、手に取るときに一回止まる。

　――この日は、宮地さんの手がおかしかった。

　速さは変わらん。百二十を三時間で包む速さのまま、皮を取って、のせて、閉じて、盆に置く。置く場所も、手前から奥へ、左から右へ、いつもどおりじゃ。

　おかしいのは、置いたあとじゃった。

　置いて次の皮を取る前に、一回だけ口が開く。開いて、閉じる。閉じて、次の皮を取る。

　二十時から二十一時までのあいだに、うちはそれを何回も見た。次が来るかどうかを待っとったら、皮を一枚包むあいだに、また来た。

　日下部さんも見とった。見とって、何回目かのときに、粉の話を途中でやめた。

　黒江さんは看板の話をしとった。止めんかった。止めんかったけど、話の終わりが毎回、宮地さんのほうを向いとった。

　蓮見さんは何も言わずに盆の並びを直しとった。直すたびに、宮地さんの盆の端がちょっとずつ揃うていった。

　山根さんは餡をのせとった。

　――二十一時を少し過ぎたころじゃ。

　宮地さんが皮を置いた。

　置いて、次を取らんかった。

「……一個、言っていい?」

　台の上の音が、四つ止まった。止まらんかったのは山根さんの匙だけじゃった。

「なに」

　日下部さんが言うた。

「土曜に、おじいさんと食べに来た」

「誰が」

「……」

　宮地さんは台の皮を見とった。見たまま、言うた。

「こはるちゃ……こはるが」

　……。

　止まったのは、一秒もなかったと思う。宮地さんは、言いかけたところで口を閉じて、一回だけ自分で言い直した。言い直したほうの名前は、六月の金曜までと同じ呼び方ではなかった。それが、台の五人に全部聞こえとった。

　日下部さんが言うた。

「こはるちゃん」

　黒江さんが言うた。

「こはるちゃん」

　蓮見さんが皮を持ったまま言うた。

「こはるちゃん」

　うちも言うた。

「こはるちゃん」

　山根さんは匙を止めた。止めて宮地さんの顔を見て、低い声で言うた。

「こはるちゃん」

「繰り返さなくていいから!」

　宮地さんの声が、厨房でいちばん大きかった。大きい声を、うちはこの台で初めて聞いた。

　日下部さんが台に突っ伏した。三週間前と同じ格好じゃった。

　――この三週間で、日下部さんは二回、宮地さんのことを「あんずちゃん」と呼んだ。二回とも、布巾が飛んできた。一回目は日下部さんの肩に当たって、二回目は外れて、冷蔵庫の扉に当たった。冷蔵庫の扉の紙が一枚、角だけめくれた。

　黒江さんと蓮見さんは、呼んどらん。うちも呼んどらん。山根さんはもとから誰の名前も呼ばん。

　呼ばんけど、全員、覚えとる。

　――宮地さんは話の続きを皮を包みながら言うた。包みながらでないと言えんかったんじゃと思う。顔は台から上がらんかった。

「お父さんが、じいさんも連れて来いって言ったから、ほんとに連れてきた。二人で、餃子と半チャーハンを二つずつ」

「ええね」

「おじいさんは、焼きたてのほうがうまいって言って、帰りに持ち帰りも買った」

「ええね」

「それで、会計のときに」

　宮地さんはそこで一回止まった。止まって、次の皮を取った。

「来週、包みに来たいんだって。水曜の夜」

「……ほう」

　日下部さんが言うた。今度は、ほう、のあとに続きがあった。

「来るん?」

「家の人には聞いてきたって。それで、わたしに聞いてきた」

「なんて答えたん」

「……みんなに聞いてからって」

　蓮見さんがそこで顔を上げた。

「わたしたちに、聞いているんですね。いま」

「聞いてる」

「来ていいですよ」

「いいです」

「ええよ」

「来たらええ」

　四人ぶん、すぐに返ってきた。最後のは山根さんじゃった。うちは言うのが一番遅かった。

「……来たらええと思います」

　宮地さんはうなずいたんか、皮を見直したんか分からん角度で、頭を一回動かした。

　――そこから先は、段取りの話になった。

　段取りの話になると、この台は急に速い。

「何時から」

「部活が十九時までだから、十九時半。自転車で来る」

「帰りは」

「二十一時に、お父さんが車で迎えに来る」

「一時間半か」

「一時間半で、二十個くらい」

　日下部さんが台の端から端までを指でなぞった。

「どこに立たせるん」

「それ」

　宮地さんが言うて黒江さんのほうを見た。黒江さんは待っとったみたいに口を開けた。

「左ききの人を右ききの人の左に立たせると、肘が当たるんです。皮を取るときに肘が外へ出るので、右ききの人は右へ、左ききの人は左へ出ます。だから左ききの人の左側には誰もいないほうがいい。つまり台の左の端です。左の端に立つと、壁が肘から二十センチくらいなので、壁のほうは問題ない。問題は、左の端に今いる人を……」

「黒江さん」

　日下部さんじゃった。

「要するに、左の端じゃろ」

「……はい。要するに、左の端です」

　台の左の端に立っとるのは、うちじゃった。二年前の九月から、ずっとそこじゃ。決めたわけではない。最初の水曜に空いとったのがそこで、次の水曜も空いとった。空いとるところに立つと、次からはそこが空けてある。

「矢部さん、一個ずれてもらってもいい?」

「ずれます」

　うちは右へ一歩ずれてみた。ずれたところは、蓮見さんとのあいだが狭うなった。蓮見さんも一歩ずれた。黒江さんもずれた。順番に一人ずつずれていって、右の端で山根さんのずれる場所がなくなった。

「……うちは、流しのほうへ回る」

　山根さんが言うた。台の右の端から、角を回って、流し側の短い辺に立った。立ってみたら、そこからでも匙は届いた。

「届くんじゃ」

「届く」

　――二十三時十分に、百二十で合うた。

　片付けが済んで、みんなが裏の戸から出ていくときに、宮地さんが一回だけ呼び止めた。

「来週」

「うん」

「普通にして」

「普通に」

「普通に、ね」

　日下部さんが言うて、戸を閉めた。閉める前に、ちょっとだけ笑うとった。

　水曜の前掛けは、宮地さんの家のものじゃ。六枚あって、洗うのも宮地さんじゃ。二年前に一枚ずつ増えて、六枚になったときから増えとらん。名前は書いとらん。書いとらんけど、どれが誰のかは、六人とも分かる。紐の結び目の癖が、一枚ずつちがうけえじゃ。

　うちは最後に出ようとして、振り返った。

　冷蔵庫の横のフックに、前掛けが六枚かかっとる。宮地さんは棚の上の箱から、たたんだ前掛けを一枚出した。広げて、ほかの六枚の左の端のフックに、一枚足した。
