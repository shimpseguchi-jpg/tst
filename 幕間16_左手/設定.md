## 筋

　弟の遼の、高校の部活の後輩が、学校の就業体験で一週間、福来軒に来る。
　**あんずが、珍しくちゃんと「お姉さん」をやろうとする。**手順を紙に書き、言葉を選び、声を落とす。
　水曜の夜、包む手が一度だけ左になる。それで六人にばれる。
　木曜の昼、餃子会が面白がって、別々の用事のふりをして見に来る。

| 章 | 日 | 語り手 | 何が起きるか |
|---|---|---|---|

| 四 | 六月十四日（木）の昼 | 日下部なつ | 見学。なつ、黒江・蓮見、矢部が別々に来る。あんずの「〜しようか」。日誌に判が押される |

## 封じるもの（一つだけ）

**あんずが、なぜ夜に左手で包む練習をしたか。**練習したことは書く（二章で後輩が、三章で六人が見る）。理由は誰も聞かず、本人も言わない。
**遼が何を思っているかも書かない。**五章で遼が言うのは事実だけ（「おれのときは、紙はなかった」「二回な」）。
**こはるが水曜の夜に来たかどうかも書かない。**第六章（六月二十日）にこはるは出てこない。**七月十八日に一度来る**（第八章）。七月二十五日（幕間07）は「この日は六人だった」なので、その週は来ていない。以後のことは書かない。頼んで、返事をもらわずに帰る。以後の篇（幕間07 の二十九人ほか）に、こはるは出ていない

## 補ったもの（この篇で決めた）

| | |
|---|---|
| 三好 こはる | **高校二年、十六歳。**遼の出た高校の、遼の二つ下。**卓球部で遼の後輩だった。**家は市の北のほうで、自転車で来る。**左きき。**道の駅で福来軒の餃子を買ったことがある。言葉は備後の言葉で、目上には「〜です」をつける |
| 就業体験 | 高校二年の全員が、六月の第二週に五日間。**受け入れ先は自分で探してよい。**こはるが遼に聞き、遼があんずに聞き、あんずが父に聞いた。**水曜は店が休みなので四日。**時間は九時から十五時。書類は『就業体験（インターンシップ）実施計画書』『体験日誌』『事業所評価票』 |
| 体験日誌 | 毎日、事業所担当者の欄に印。担当者はあんず。**あんずは自分の判を持っていない**（店の角印と父の判はある） |
| 遼 | 四月から福山へ通っている。夕方に帰る |
| 手順の紙 | あんずが週末に書いた。A4一枚、包み方を七つに分けてある。**右手の人の書き方。**左きき用は書き直さず、裏に左右を入れ替えたものを書いた |
| ゴム印 | 山根ともが水曜の夜に彫った。『宮地』。木曜の朝、福来軒の郵便受けに入っていた |

## 文体の目標

**`python3 tools/文体.py 幕間16_左手` で測る。**速い篇（幕間15 と同じ幅）。

| | 目標 |
|---|---|
| 地の文の文 | 16–19 字 |
| 長文 | 2 %以下（四十字を超える文） |
| 一行の文数 | 1.8–2.3 文 |
| 地の一行 | 32–42 字 |
| 地の連（字） | 90–160 字 |
| 地の連（行） | 4.5 行以下 |
| 会話字 | 18–30 % |
| 会話行 | 40–60 % |
| 会話一行 | 8–13 字 |
| 会話の連（行） | 2.5 行以上 |
| 読点 | 26 字以上あける |
| 場面 | 5–8 ／章 |

　**三章（山根とも）と六章は遅くなってよい。**六章は話が途切れるのが中身なので、文が短く、会話が続かない。ともは喋らないので、六人の声を地の文が受ける。
　**地の文の時刻は二十四時間制。**台詞は言うとおり。章題の末尾に（名前）。
