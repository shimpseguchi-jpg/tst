## 世界のほうを壊してある

　書き方だけでなく、**起きたことが、この世界では起こらない。**
　だから**書き直しても本編にできない。**年表・既刊表・字数の合計にも入れない。

　次のどれかがあれば、ここに入る。

1. **この世界にないことが起きる。**時間が戻る、体が入れ替わる、薬が効く、性別が変わる
2. **人から店を剥がす。**この連作の人は、店でできている
3. **封じてあるものを開ける。**屋根、名前、顔、内面、九年姿を見せない人

## 何を外したか

| 本編のルール | ここでの扱い |
|---|---|
| 数字は漢数字 | **アラビア数字**（0.2ミリ、42番、120個、100万人） |
| 三点リーダーは「……」、ダッシュは「――」 | 「…」「～」「!!」「!?」を混ぜる |
| セリフと叙述を同一行に混ぜない | **混ぜる** |
| 忌避表現（めっちゃ／ヤバい／ぶっちゃけ／てゆうか／〜すぎる／的な） | **全部使う** |
| 感情の既製品（ドキッとした／涙が溢れた／胸が熱くなった） | **全部使う** |
| 擬音の多用を避ける | **ドンッ／バチーン／ゴゴゴゴゴ** |
| 「まるで〜のような」を使わない | **使う** |
| 温度で絆を表現しない | **使う**（本文中で自分から謝っている） |
| 感情を直接説明しない | **説明する** |
| 章の終わりは物か動作で閉じる | **感慨で閉じる** |
| 本文にマークダウンを入れない | **見出しを入れる** |
| 読点は二十四字に一つ | **数えていない** |

　**一篇で外すのは一つに絞る。**外す場所を一つに絞ると、その一つが内容になる。
　四本目『ゲスト回』は、形そのものは幕間03 と同じである。壊したのは**コメント欄**だけで、
　幕間03 の設定にある「コメントに俗語を使わない」「忌避表現も入れない」をそこだけ外した。

## 何を外さなかったか

- **露骨な性的描写はしない。**本編でも番外編でもここでも変えない。
  九本目の第五章・第六章には夜の場面があるが、
  **触れるところと、決めたことまでで、その先は書いていない。**
  書いてよい線は作品17 第七章と同じである。**区分がどこであろうと、この線は動かさない**
- 未成年を性的な文脈に置かない。**夜の場面に出るのは成人四人だけである**
- 実在の人物・団体を出さない
- 本編の本文を書き換えない

## 十五本目（惚れ薬）について

**二〇三六年十月一日（水）— 五日（日）。全十八章、一万二千七百字。文体はラノベ。**
語り手は宮地あんずを主に、六人に渡していく。

### 壊したのは、宮地あんずが数の外にいること

　この人は連作で唯一の「数える側」で、**数の中に入らない。**
　番外編の十本目で、本人にこう言わせている——
　**「数えるほうの人間が、数の中におったら、数えられんようになる」。**

　この一篇は、それを実行した。**六人が一斉に、宮地あんずを数えはじめる。**

| 誰 | どう狂うか |
|---|---|
| 黒江 いと | **人の字数を数えてしまう。**宮地の発言だけ。ノートに正の字 |
| 蓮見 すず | **四十二字の上限が外れる。**最長八百十二字。本人がいちばん驚く |
| 矢部 さえ | **宮地の体温だけ分かる。**道具が要らない。ほかの人は分からない |
| 山根 とも | **自分から質問する。**木曜だけで二十五個。一晩で印を六本彫る |
| 日下部 なつ | **声が出なくなる。**もともと付き合っているので、量だけが三、四倍になる |
| 沖田 ちさと | **配信で名前を言いかける。**四万人の前で。持ち帰りの二個を食べた |

　**そして宮地あんずは、四日間、一度も数えられない。**
　皮の枚数が数えられなくなる。十一年で初めてである。
　こわいのは六人に見られることではなく、**自分が測れなくなること**だと気づく。

### 仕掛け

　**三隅るりが、ラベルを読み違える。**校正を九年やっている人が、である。
　大阪の古い乾物屋で買った瓶で、崩し字の「花」の下が椒ではなかった。
　効くのは**作った人に対して、三日と半日**。目録にはそれしか書いていない。

　**解くのも校正である。**取り寄せた目録の百三十七ページで、活版の行が一行ぶんずれていた。
　乾物屋も、それを見て売っていた。**刷った側が先にまちがえていた。**
　るりは、そこに赤を入れる。**九年でいちばん遅い校正**である。

　切れる順番は、食べた数で決まる。宮地が指を動かして出す。
　**四日ぶりに、この人が数える場面**がそれである。

### 痛いほう

- **矢部さえ**が、木曜の夜に大阪へ電話して「ごめん」だけで切る。
  九年見上げてきた人の声で、何も起きなくなっている。
  解けたあと、るりは怒らない。**「読み違えたんはうちや」「あんたは食うただけや」**
- **山根とも**と**沖田ちさと**が、午前三時のランドリーで互いに何も感じない。
  「うちは、あと七時間ある」「待っとれ」
- **黒江いと**と**蓮見すず**が、別の人の話で一時間半喋る。
  **五年でいちばん会話が多い一時間半だった**

### 芯——言われなかったのが効いた

　六人のうち五人は、四日のあいだに言いに来た。

　**日下部なつだけ、声が出ないので何も言えなかった。**
　薬が切れても、この人の量は減らない。むしろ水曜の前より少し多い。

> 　「あんただけ、何も言わんかった」
> 　「言えんかったんです」
> 　「知っとる」
> 　「**言われんかったのが、いちばん効いた**」

### 開けなかったもの

- **沖田ちさとの四文字。**配信で言いかけて、口が止まる。地の文も書かない
- **宮地あんずが進学をやめた理由。**山根ともが「継ぐんか」と聞いて、店が静かになる。答えない
- **瓶の字が何なのか。**るりも「わからん」で終わる
- 効能の説明。目録の欄が**「三日と半日、作った人に向く」で終わっている**

### 本編に持ち込めないもの

- 薬。惚れること。四日間の全部
- 蓮見すずが八百字喋ること。山根ともが一晩で六本彫ること

### 持ち込めるもの

　**「今日は、よう入るのう」**

　娘の店に六人が押しかけて地獄になっている昼に、父が厨房から出てきて言う一行である。
　この人は、娘が進学をやめた年にも理由を聞かなかった。**聞かないことが、この父の全部**である。
　**本編でそのまま使える。**


## 十四本目（学園）について

**県立柏尾高校の一年間。全二十八章、二万千七百字。本編の外でいちばん長い。**
文体はラノベ。主な語り手は日下部なつで、章ごとに渡していく。

### 壊したのは、人が店でできていること

　この連作の人物は、**全員が職でできている。**
　山根ともは十年彫ってきた手であり、黒江いとは五年ぶん疑われてきた人であり、
　宮地あんずは十一年数えてきた人である。

　**この一篇は、そこを全部剥がした。**店がない。家業もない。全員が生徒である。
　残ったのは、癖と、速さと、距離の取り方だけになる。

### 置き換え

| 連作 | 学校 |
|---|---|
| 店で呼ぶ（「山根さんとこの」） | クラスと部で呼ぶ |
| 山根印房・手彫り | **美術部。朝五時五十分から第2美術室で彫っている** |
| 銀紷堂・看板 | **美術部の文字班。**黒江が書き、蓮見が紙をそろえる |
| 福来軒・数える | **文化祭実行委員の会計** |
| 柏尾製パン・二時四十分 | **ソフトボール部の朝練。**全校でいちばん早く着く |
| 柏湯・四十二度と四十三度 | **温水プールの水温。二十七度と二十八度** |
| 文林堂の二階（九年会っていない） | **書庫の奥の司書。**やりとりは戸の下の隙間の紙だけ |
| 白詰ねむ（顔を出さない配信） | **昼の校内放送。**二年、名乗っていない |
| 備陽新報・藤木かなえ | 新聞部の三年。部員は二人 |
| 組合事務員・森岡 | **事務室の人。**「断りません。かわりに、何も保証しません」 |
| **アーケードの屋根が外れた** | **部室棟が三月二十日に壊される** |

### A案——年齢差は学年に、三隅るりだけ学校の外へ

　**矢部さえ×三隅るりを、教師と生徒にしない。**これが設計でいちばん大事なところである。
　さえは一年（十六）、るりは**文化祭のパンフレットを刷る印刷所の校正者（三十二）**にした。
　原作の初対面と同じ年齢差で、上下関係が発生しない。

　**「うつる／うつらない」が、そのまま「校内／校外」の距離になる。**
　二〇三四年一月二十八日にあたるものは、**この一篇でも書いていない。**
　るりが学年を聞いて、一拍置く。置いたことに、向こうは気づいていない。それだけである。

### 背骨——進路希望調査票

　一年で三回出す。六月、十月、一月。

| | 第一希望の欄 |
|---|---|
| 日下部なつ | 「パン屋」。**家はパン屋ではない。**朝がいちばん早いから。四回とも書き換えない |
| 宮地あんず | **三回とも空欄。**六月に三回計算して、三回とも答えが違った |
| 山根とも | 空欄で出す。担任は何も言わない |
| 沢渡ふゆ | 「未定」。書庫に紙を入れる——「空欄で出してもいいですか」 |
| 矢部さえ | 丸をつけるだけの一年の様式。**余白に書く欄がない** |

　**あんずが書けない理由は、開けていない。**「言えません」で終わる。弟にも言っていない。
　数字で説明できる部分だけ書いたら嘘になる、とだけ書いた。

### 行事

- **体育祭（九月二十二日）。**得点板の字は美術部が書く。誰が書いたかは誰も知らない。
  山根ともがアンカーで、**最後まで速さを上げない。**「上げたら、崩れる」。三位
- **文化祭（十一月七日）。**正門の看板は六文字を四十八分で書く。
  **題は地の文が書かない。**昼の放送がその四十八分の話をして、焼きそばが七十分早く売り切れる。
  「看板は、計算に入れとらんかった」

### 回収したもの

- **「先に彫る。あとで誰かが使う」**（第四章）→ 解体の日に、六つの印が配られる（第二十七章）。
  去年の四月から彫っていた。名前しか彫っていない。「ほかに、まだ何もないけえ」
- **「名乗るかどうか」**（第二十一章）→ 一月二十六日、最後の昼の放送で名乗る（第二十四章）。
  誰も騒がない。**それで正しい**
- **「三段目から上に行けません」**（第十章）→ 三月十三日、五段目に上がる（第二十六章）。
  **「なくなるものには、上がるんですね」「なくならないものには、上がらないんですね」**

### 芯

　**学校では、誰もまだ何でもない。**

　この連作の人たちは、十年とか九年とか五年とかを背負って喋る。それを全部抜いた。
　抜いたあとに残るのは、名前だけである。

> 　「これ、名前じゃね」
> 　「名前じゃ」
> 　「……名前しか、彫っとらんね」
> 　「ほかに、まだ何もないけえ」

### 本編に持ち込めないもの

- 全部。**これは連作の土台そのものを外した一篇である**

### 持ち込めるもの

　**沢渡ふゆの理由の書き方。**「ほかに置いてある場所を、わたしは知りません」。
　決められない人が、決めない理由を初めて言葉にする形になっている。
　**学校でなくても成立する。**


## 九本目（逆さ）について

**二〇三六年二月十八日（月）— 二十一日（木）。全九章、一万千九百字。ラノベ・性転換。**
語り手は沖田ちさと・山根とも・蓮見すず・黒江いと・沖田ちさと・蓮見すず・宮地あんず・
山根とも・黒江いとである。

### 仕掛け

　**山根印房の蔵から出た古い印を押すと、三日だけ逆になる。**

　連作の作品10 の題は『逆さに彫る』で、あの一本はこの一行でできている。

> 　印章は左右逆に彫る。押して初めて、正しく読める。

　**それを人に適用した。**逆さになった三日のあいだ、通りは二人を正しく読んでしまう。

　押したのは**山根ともと黒江いと**である。この二人を選んだ理由は一つで、
　**本編で「好き」を自分から言っていないのが、この二人だけ**だからである。

### 三日で変わったもの（本人の仕事は一つも変わっていない）

| | 逆になったあいだ |
|---|---|
| 山根とも | 二時間で三回「継ぐんか」と聞かれる。**十年で一回も聞かれていなかった** |
| 同 | 注文の電話が二日で五本。普段は月に四本 |
| 同 | 父が客に訂正しないのは同じ。**隠すためではなく、自然だから**になる |
| 黒江いと | 見積もりが一回で通る。いつもは三回に二回聞き返される |
| 同 | 「看板屋さん」ではなく名前で呼ばれる |
| 同 | 二割高い数字が通る。四分の説明が遮られない |
| 同 | 木曜に戻ると、**一日で十七回疑われる。**火曜はゼロだった |

### 芯は、得だったかどうかを片づけないこと

　第七章で日下部なつが聞く。**「その体、得じゃないですか」**
　この人は通りでいちばん素直なので、いちばん先に本当のことを聞く。

　答えは二つ出て、どちらも消さない。

- 黒江いと「同じものを出しています。**わたしは、五年分、疑われていたということです**」
- 山根とも「注文が倍来た」——そのうえで、**「彫れん」**

　**山根ともだけは、体が変わって仕事が壊れる。**
　手が五ミリ大きくなると、印刀を支える指の腹の位置がずれる。
　十年かけて合わせたもので、三日では合わない。練習を三本彫って、三本とも上手だった。
　**上手で、ともの字ではなかった。**

　宮地あんずが数える。二百四十個は二百四十個で、失敗した皮も三枚で同じだった。
　**扱いは変わる。数は変わらない。**

### 夜の場面（第五章・第六章）

　成人四人の話である。**線は作品17 第七章と同じ**で、そこから先には行かない。

- 沖田ちさと（第五章）——声も背も肩も変わって、**手だけ変わらない。**
  この人が好きになったのは二〇三二年九月二十日の午前三時に見た**手元**である
- 蓮見すず（第六章）——五年、脚立を押さえる側だった人が、**五段目に上がる。**
  怖いのは高さではなく、届いたら外せないことである

### 「好き」の扱い

　第五章で、山根ともが初めて「好きじゃ」と言う。**知らない喉から出た声である。**
　沖田ちさとはそれを受け取らない。**「三日たったら、自分の声で、もう一回です」**
　第八章で、自分の声で言う。

　**本編に持ち込まない。**本編のこの人は、まだ一度も言っていない。

### 父が一行だけ喋る（第八章）

> 　「**わしも、二十八で押した**」

　これで、第二章の「楽になったか」が、**質問ではなく記憶だったことになる。**
　山根吉春は、それ以上言わない。**この人は十年、そうである。**

### 本編に持ち込めないもの

- 印で体が変わること。蔵の箱と、底の紙
- 山根ともが「好きじゃ」と言うこと
- 蓮見すずが五段目に上がること。**本編ではまだ四段目が一度きりである**
- 山根吉春が自分のことを喋ること

### 持ち込めるもの

　**「同じものを出して、扱いだけが変わりました」**

　黒江いとが五年、三回に二回聞き返されてきたことは、本編の事実である。
　**逆さにしなくても書ける。**書くなら、通る日を一日も出さないで書く。


## 八本目（入れ替わり）について

**二〇三五年十二月十四日（金）十二時十四分 — 十五日（土）十二時十四分。全九章、一万百字。**
章ごとに語り手が替わる。森岡佑・黒江いと・蓮見すず・山根とも・沖田ちさと・
沢渡ふゆ・藤木かなえ・宮地あんず・森岡佑。

**置き場所。**作品18 の第六章が二〇三五年十二月で、十二月十四日の福引きに
藤木かなえが出て**四等**を引いている。そこを壊さずに重ねた。
一等を引くのは黒江・山根とも・沢渡ふゆ・宮地あんずの四人である。

### 仕掛け

　**一等を引いた人は、その日いちばん長く一緒にいた人と、二十四時間入れ替わる。**

　一等は二〇〇七年から商品券五千円で変わっていない。**理由は組合の記録にない**
（共有設定の年中行事にそう書いてある）。この一篇が、その理由である。

　金額を上げると並ぶ人が増える。増えると出る。だから上げない。
　知っているのは森岡ひとりで、**記録していない。**「書くと、理由が残るので」

### 各組で起きること

| 組 | 分かること |
|---|---|
| 黒江 ↔ 蓮見 | **蓮見の体は四段目で平気だった。**怖いのは高さではなく「落ちたら誰かが困る」こと |
| 同 | 蓮見が黒江の口で百六十二字喋る。**同じことを言っている。**蓮見はいつも四字で言う |
| 山根とも ↔ 沖田 | ともが生配信をやる。喋れないので**彫る音を四時間流す。**同接が七年でいちばん増える |
| 同 | ちさとが彫る。手は覚えていても目が覚えていない。**父が音で気づく。**「止まるところが多い」 |
| 沢渡 ↔ 藤木 | ふゆが藤木の目で読む。**滑らない。ただし残らない。**目の問題ではなかった |
| 同 | 藤木が自分の記事を読めない。**八年書いたものが一行も入ってこない** |
| 宮地 ↔ 日下部 | **日下部の体が二時四十分に勝手に起きる。**窯があると、数えなくても手が止まらない |

### 本編に持ち込めないもの

- 入れ替わりそのもの。福引きの一等の中身
- 沖田ちさとが自分の名前の印を彫ること。**地の文は四文字を読み上げていない**
- 藤木かなえが、文林堂の二階に九年ぶん聞かれていることを先に知ること。
  **本人は沢渡に言わない。**言うと、あの人がやめるからである

### 持ち込めるもの

　**「落ちたら、誰かが困ります」**（十四字）

　蓮見すずが五年、三段目で止まっていた理由である。高さではない。
　作品16 でも幕間06 でも、この人は理由を言っていない。**本編で言わせる場面は、まだない。**


## 七本目（水曜ループ）について

**二〇三四年九月二十日（水）。全十章、七千四百字。宮地あんずの一人称。ラノベ・時間ループ。**

**置き場所に注意。** 本編の二〇三四年九月は、作品16 が月に一度しか触っていない空白である。
冷蔵庫の紙は、作品13（二〇三三年八月）で五枚目、幕間06（二〇三五年三月）で七枚目になる。
**あいだの六枚目が、本編では決まっていない。** この一篇は、そこに入る。

### 仕掛け

　気づくのは宮地あんずで、理由は**数が合いすぎるから**である。
　百二十個がぴったり合うのは全体の三割しかない。それが三回続いた。
　**破れた皮の枚数まで三回とも二枚だった。**

　検証が七つある。数を変える、包まない、店を出る、起きない、日付を確かめる、
　紙を見る、数えないで待つ。七つ目で分かる。
　**この日は、あんずが数え終わるまで終わらない。**

### 抜け方（作品13 の裏側）

　仮説は一度崩れる。〇日のはずの日だから合わない、という説明を立てて、
　**毎回ぴったり合っているので崩れる。**

　本当の理由は、作品13 第七章の一行目にある。

> 　合ったので、この日も何も起きなかったことになる。

　**日を終わらせているのは、あんず本人である。**
　四年で夜が四百回あって、冷蔵庫の紙は五枚しかない。
　残りの三百九十五回を、この人が「何も起きなかった日」にしてきた。
　**ループは今週から始まったのではない。気づいただけ。**

　抜け方は、作品13 第七章の最後の二行にある。

> 　これはノートに書かなかった。
> 　書く欄が、この見開きにはない。

　**欄を作る。** 物差しで縦線を一本引いて、右のいちばん上に『出来』と二文字書く。
　欄の幅が足りなくて、出来事の二文字で止まる。
　そこに数ではないものを書いて、**合った日なのに紙を貼る。**六枚目である。

### 回収したもの

- 山根とも「終わらせ方は、始まり方と同じじゃ」（八回目の夜）
- 黒江いと 四分喋って全部外れるが、一行だけ当たる。「版をずらすのは、刷る側です」
- 蓮見すず「それは、つらいです」（十字）。**あんずはこれを十九回聞く**
- 作品13 第九章、名簿に定休日の欄がなくて、森岡の「数えましょうか」を断った夜

### 本編に持ち込めないもの

- 繰り返し。三十二回
- 六人に三十一回説明して、三十一回とも翌朝に消えること
- 六人が誰も帰らない夜（第六章）

### 持ち込めるもの

　**六枚目の紙。**本編では中身が決まっていない。
　ここで『九月二十日　六人来た』にしたが、**本編で別のものにしてもよい。**
　持ち込むのは中身ではなく、**合った日にも貼ることがある、という一点だけ**である。


## 四本目（ゲスト回）について

二〇三六年四月。**全十三節、七千六百字。地の文がない。**
白詰ねむの発話が「　」、ゲストの声が『　』、コメントは鉤括弧なし。

　幕間03『四百八十円』と同じ形である。あちらは三千二百字の一章で、
　**この形だと人が一人しか出せない。**コメントは四万人いるが、あれは人数ではなく速度で、
　誰が書いたか分からないようにしてあるので、人として数えられない。

　**だから十一人出した。**

### 来た順

| | 誰 | どうなったか |
|---|---|---|
| 1 | 山根とも | 一時間喋らない。押した六分の原因。最後まで隣にいた |
| 2 | 宮地あんず | 段取りを組む。**六年十か月ぶんの一行を読み上げられる** |
| 3 | 日下部なつ | 音割れ。**二時四十分起きの人なので、途中で寝る** |
| 4・5 | 黒江いと・蓮見すず | 二七八字と六字。コメントが文字数を数えはじめる |
| 6・7 | 矢部さえ・三隅るり | 四十二度と四十三度。九年前のことは「本編でやる」と断る |
| 8 | 森岡佑 | 鞄の中身に私物が一つもない。十七曲は権利の処理をしていないので流せない |
| 9 | 沢渡ふゆ | **朗読する。**コメントが止まる。同接が減らない |
| 10 | 藤木かなえ | 取材を始めてしまう。「今日、取材じゃないです」 |
| 11 | 塚本律子 | 予定になかった。**三つ聞いて帰る** |

### 本編に持ち込めないもの

- 山根ともが配信に出ること。七時間喋る場所に出る理由がない
- 宮地あんずが出ること。**言わずに聞いてきたことが、この人のいちばん大事なところ**である
- 塚本律子の三つ目の質問。誰のことかは、ここでも言わせていない
- 沢渡ふゆの朗読。本編でこれを聞いているのは、**二階の人だけ**である

### 持ち込めるもの

　**声に出したことは、残る。**

　四時間喋ったあとに一時間かけて言葉を引く人と、声に出さないと一行が入ってこない人。
　この二人は本編で一度も会っていないし、会わせる予定もない。
　それでも、毎晩、別々に声に出している。


## 三本目（オールナイト）について

二〇三六年四月。作品18 が終わった次の月である。**全二十二節、二万字。**
時刻で節を立てて、十七時から翌朝四時五十分まで。

**目的はひとつ。全員で集合写真を一枚撮ること。**

この連作は、写真がとても弱い。
顔を出していない配信者がいる。九年で写真が一枚もない人がいる。
撮る仕事なのに「わたしは写らなくていいです」と言った記者がいる。
九年姿を見せない店主がいる。内面を書かないと決めてある人がいる。
十年、昼の光の下に出ていない人がいる。
**本編では、この全員が一枚に入らない。**

だから、一晩かけて障害を一つずつ壊す。節が進むごとに一人ずつ入れるようにしていく。

### 壊したもの

| 節 | 何を壊したか |
|---|---|
| 3 | 藤木かなえが撮る側から降りる。**この連作で初めて、人が泣く** |
| 4 | 沖田ちさとがフードを脱ぐ。宮地あんずと正面から喋る |
| 5 | 矢部さえが、九年で一枚目を撮る |
| 6 | 滝沢篤子が階段を降りる。**九年ぶんの声が、上から聞こえていた** |
| 7 | 塚本律子の内面に、地の文が一行だけ入る。**入れて、すぐ閉めた** |
| 15 | 山根ともの取り分が十年変わっていないことを、父が初めて説明する |
| 17 | **屋根が戻る。**四百十二メートル、照明四十七本。雨が鳴る |
| 18 | 全員が泣く。**十八作と七つの幕間で一度もなかった** |
| 19 | 蓮見すずが、自分で四段目に上がる |

### 壊さなかったもの

- **森岡の三つ目。**「見てしまったものを言うと、見られた人が、見られたことを知ります」
- **宇田ときの家。**本人が来て、名前を言って、それでも「今日も、言わないです」と言う
- **矢部さえと三隅るりの二〇三四年一月二十八日。**「本編でやるけえ」と本人が断る
- **宮地あんずの相手。**「います」と即答するが、誰かは言わない（十一本目で開けた）
- 塚本律子の内面は、一行だけ開けて閉じた。**もう開けない**

### この一篇で決めたこと

- 冷蔵庫の紙は**十枚目**。『一人百二十個』。三千八百四十個包んだ
- 黒江いとの本編での最長は百四十四字。**この夜は三百二十字**
- 蓮見すずは四十二字を守らない。カラオケで千二百字歌う
- 久世昭三の写真が一枚出る。一九七一年。**切符の切り方が曲がっている**

**本編に持ち込むのは一つだけ。**
　矢部さえが撮った、九年で一枚目。ブレていて、二人とも写っている。
　**本編でもいつか撮る。理由は説明しないで成立するように書く。**


## 二本目（甘々）について

本編で「好き」が口に出されたのは**二回**だけである。

1. 作品15 第八章　沖田ちさと「好きな人が作っているものの値段を四万人に言いました」
2. 作品16 第十一章　蓮見すず「そうです。好きです」

**山根ともと黒江いとは、最後まで自分からは言っていない。**
二本目では、ともに「好きじゃ」と言わせ、いとに三メートルの板を出させている。
**本編では、どちらもやらせない。**

二本目で足した甘さの道具（本編には持ち込まない）
　呼び方（ともちゃん／すず／さえちゃん）、お揃いの印、手を触った回数の記録、
　頭ぽんぽん、通りに出す告白の板、九年ぶりの一枚、「好き」百回。

**唯一、本編に持ち込んでよいのは考え方のほうである。**
　「砂糖を入れないと決めた人が、一粒だけ入れたときにだけ甘い」。
　これは第五節に書いた。**本編の運転の仕方そのものなので、忘れないこと。**
