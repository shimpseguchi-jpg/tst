# 番外編について

**八篇ある。** `番外編/` の下。分類の定義は `分類.md` にある。

## 書き方だけを壊してある

　起きたことのほうは、この世界で起こりうる。
　年表に入れてもどこも壊れない。だから**入れないだけで、矛盾はしていない。**

## 本編にできる

**書き方を本編に戻して書き直せば、本編にできる。**

　実際に二篇そうなった。**もとは四篇あった。三本目と四本目が卒業した。**
　——『一泊二日』は **作品17『十四分』**、『拡大餃子会』は **幕間07『二十九枚』** になった。
　あの二本は文体も表記も本編のままで書いてあったので、
　入れるときに落としたのは**作者あとがきの一節だけ**である。

　だから、番外編を書くときは、**先に「何を壊すか」を一つだけ決める。**
　壊さないなら、それは最初から本編の候補として書いたほうがよい。

**ただし、書き直すまでは正史ではない。**
　ここで書いたことを、本編の地の文が既知のものとして扱わない。
　**年表・既刊表・字数の合計には入れない。**

## 世界のほうは壊していない

　壊すと、それは二次創作になる。`二次創作/` のほうへ行く。

- 超常のことは起こさない（時間が戻る、入れ替わる、薬が効く、性別が変わる）
- 人から店を剥がさない
- 封じてあるものを開けない——屋根、滝沢篤子の顔、橘ひなたの五年、
  森岡が見てしまったもの、塚本律子の月曜の行き先、久世藍の次回作、山根吉春の訂正

## 外さなかったこと

- **露骨な性的描写はしない。**書いてよい線は作品17 第七章と同じである。
  **区分がどこであろうと、この線は動かさない**
- 未成年を性的な文脈に置かない
- 実在の人物・団体を出さない
- 本編の本文を書き換えない

## 仕組み

- データは `tools/本編外データ.py` が作る（出力は `reader/data/x.json` ほか）
- 通番は書いた順の通し番号で、`二次創作/` とまたいでいる。**動かさない**
- `tools/リーダー用データ.py` と `tools/資料データ.py` は、この folder を見ない

## 十七本目（執事喫茶）について

**二〇三六年十二月十三日（土）、歳末の売り出しの初日。全十六節、一万三千七百字。**
十六本目の続きである。**前の回に着なかった三人が着る。**
宮地あんず、蓮見すず、山根とも。着ないのは矢部さえ、日下部なつ、黒江いと。

### 壊したのは、一篇の文体を一つにしなかったこと

　この連作は、**一篇のなかで文体を切り替えたことがない。**
　これまでは、壊すときは一篇ぜんぶを壊してきた。ラノベならぜんぶラノベである。

　この一篇は、**六人の節を本編の文体のままにした。**漢数字、忌避表現なし、
　心理を直接説明しない、節の終わりは物か動作で閉じる。

　**壊れているのは、沖田ちさとの五節だけである。**
　アラビア数字、擬音、「!!」「!?」、感情の既製品、心理の全開、感慨で閉じる。

　外から見ると、この人は五時間ずっと黙って座っている小さい客である。
　**地の文だけが決壊している。**その落差が、この一篇の中身になった。

| 節 | 語り手 | 文体 |
|---|---|---|
| 1・9・13 | 宮地あんず | 本編 |
| 2・14 | 日下部なつ | 本編 |
| 4・11・16 | 山根とも | 本編 |
| 6 | 蓮見すず | 本編 |
| 7 | 黒江いと | 本編 |
| 8 | 矢部さえ | 本編 |
| **3・5・10・12・15** | **沖田ちさと** | **壊した** |

### 成り行き

　十一月三日に丸尾ふみが「そっちの三人は、着んの?」と聞き、日下部なつが
　「次があったら」と言ってしまう。**予定はなかった。**
　**予定を作ったのは宮地あんずである。**言ったのは向こうで、覚えていたのはこっちだった。

　企画名の欄は『喫茶（もう一日）』。森岡は前と一つだけ変える。
　「前のときに、通るとは限りません、と言いました」「今度は言いません」。

　衣装はまた七番地を経由するが、**今回は山根ともが自分で借りに行く。**
　前は「知っとる人がおる」「言えん」で済ませた。今度は「うちが借りる」と言う。
　**一字しか違わないが、言うときに喉が引っかかる。**

### 手袋

　この一篇の中心は手袋である。

　山根ともの手は、甲に細かい傷があって、指の腹と爪のあいだに朱と黒が入っている。
　十年落ちていない（`資料/寸法.md`）。**通りの人間は、この人が彫っていることを知らない。**

　執事服には白い手袋がつく。**一日だけ、その色が布の下に入る。**

　沖田ちさとは、袖を二センチ長くした。本人には「手袋するから」と言った。
　**本当の理由は言っていない。**手首にも傷が二つある。

### 宮地あんずのコーヒー一杯

　カウンターの端の客が誰かを、六人のうち**宮地あんずだけが分かる。**
　顔ではない。**右肩が五ミリ下がった座り方と、荷物を膝から足元へ下ろす動きで分かる。**

　分かって、何もしない。声もかけない。
　かわりに、コーヒーを一杯持っていって「お代わりです」とだけ言う。伝票には書かない。

　**この日、宮地あんずは「表に出ているあいだは数を言わない」と自分に決めている。**
　守った。数えたのは頭の中だけである。

### 封印は開けていない

- **沖田ちさとの顔も本名も出していない。**地の文もその四文字を読み上げない
- **通りで気づいたのは二人だけ**（山根ともと宮地あんず）。幕間07 以降の状態のままである
- 山根ともが彫っていることは、この日も誰にも知られない
- 沖田ちさとは最後に「顔を出してもいいかもしれない」と思う。**思っただけである。出さない**

### 本編に持ち込めないもの

- 執事服。手袋。四番地をもう一日使うこと
- **沖田ちさとの地の文**（この文体は本編に存在しない）

### 持ち込めるもの

　**「今度は言いません」**（森岡佑）。これだけは本編の文体のままである。


## 十六本目（メイド喫茶）について

**二〇三六年十一月三日（月・祝）、第十二回 食べ歩きの日。全十八章、一万三千八百字。ラノベ。**
語り手は章ごとに替わる。日下部なつを主に、宮地あんず・黒江いと・矢部さえ・蓮見すず・山根とも。

### 壊したのは、役を演じさせたこと

　この連作は、**十六篇と八幕間で、誰にも一度も別人のふりをさせていない。**
　入れ替わり（二次創作の八本目）も性転換（九本目）も、**中身や体が変わるだけで、演技ではない。**

　この一篇で初めて、**人物が「言わない言葉」を言う。**「おかえりなさいませ」である。

　そして、**演じられる人と、演じられない人がはっきり分かれる。**それがこの一篇の中身になった。

### 成り行き

　組合の回覧板に、空き店舗を使った企画の募集が入る。誰も出さない。
　**日下部なつが、その場で書いて出す。**企画名の欄は「喫茶（1日だけ）」。
　メイドとは書いていない。**思いついたのは、その二日後である。**

　森岡の対応は十二年変わらない。「受けます」「通るとは限りません」「かわりに、何も保証しません」。

　会場は**四番地、喫茶みちくさ。**二〇二九年十二月二十八日に閉まって、七年たっている。
　一九七一年の加盟で、五十八年やっていた店である。**喫茶だった場所で喫茶をやる。**

　日付は**十一月三日**。作品04 で宮地と日下部が十六歳で餃子パンを出した、**あの行事の八年後**である。

### 着る三人と、着ない三人

| | 誰 | なぜ |
|---|---|---|
| **着る** | 矢部さえ | 「服が変わっても、やることは変わらんけえです」 |
| | 日下部なつ | 呼び込みができる。**ただし店ぜんぶに向かって言う。**矢部に「来た人一人に言うてください」と直される |
| | 黒江いと | 説明をやめられない。「おかえりなさいませ」のあとに必ず説明が始まる |
| **着ない** | 宮地あんず | 厨房と会計 |
| | 蓮見すず | 「喋れるからです」「わたしは、喋れません」——**押しつけず、自分で降りる** |
| | 山根とも | 洗い場。人前で喋らない |

　衣装は三着しかない。**六人なので、半分が着て、半分が着ない。**
　決まるまでに四十分かかる。**外したのではなく、自分で決めた**形にしてある。

### 宮地あんずの一行が、店の形を決める

　黒江が説明をやめられない、と電話で相談される。返事は九字だった。

> 　**「説明する店にせえ」**

　黒江は一卓に着くとなかなか離れない。内容はコーヒーではなく、
　**この建物の話**である。七年前まで喫茶みちくさだったこと、木札に七年前の値段があること。
　客の一人が「あんた、説明の人?」と言い、「来年もやりんさい」と言って帰る。

### 数（原則4を守る）

　入った客は百九十八人。売上十九万二千四百円、残りが十四万四千円。六人で割って一人二万四千円。

　**それで通りは何も変わらない。**四番地は翌日からまた閉まっている。屋根も戻らない。
　八年前と同じである。**商店街は活気づかない。**

　ただ、パンだけ数が合わない。百八十個持ってきて百七十六個売れて、残りが二個しかない。
　宮地は二回数えて、**それを数に入れないことにする。**五時間立ちっぱなしで一枚も割らなかった
　人間が、洗い場にいるからである。

### 書き直したこと

　初稿は、六人を**軸の名札で動かしていた。**矢部さえが客の温度を言い、蓮見すずが
「四十二字です」と数を申告し、黒江いとが「百四十四字」「三分五十二秒」を数える。
　地の文が「この人は決めてから考える人じゃ」と性格を説明していた。

　全篇を書き直し、**数と温度の申告を全部落とした。**かわりに、`資料/まだ書いていない面.md`
から、軸と関係のない面を一人に一つか二つ入れた。

| 誰 | 入れた面 | どこに出るか |
|---|---|---|
| 日下部なつ | 字が下手／名前を覚えるのが速い | 企画書の欄。並んでいる客に「さっきコーヒーじゃったですよね」 |
| 宮地あんず | 音を入れない | 古いラジオが鳴って、**黙って消す。**理由は言わない |
| 黒江いと | 黙るときがある | 考えていないときに黙る。「喋らんこともあるんじゃ」「いまです」 |
| 蓮見すず | 書くと長い／道具を貸さない | 定規を貸さず自分で三百枚引く。最後、**厚い封筒を一通だけ書く** |
| 矢部さえ | 縫える | 前の晩に自分の丈を上げ、**黒江の袖を二センチ出す。**誰にも言わない |
| 山根とも | 甘いものを大量に食べる／歌を覚えている | **合わない二個はこの人である。**布の裏で十年前の曲をうたう |

　**残した数は、宮地あんずの帳簿だけである。**それはこの人の仕事だからである。

　あわせて、藤木かなえの所属を直した。**柏尾支局は二〇三六年三月三十一日に閉まっている**
（作品18）。十一月三日には、もう福山から回ってきている。

### 開けなかったもの

- **衣装の貸主。**山根ともが七番地を経由して持ってくる。「知っとる人がおる」「言えん」。
  袋の底に手書きの紙が入っている——「無理はせんでください」。**名前は書いていない**
- **山根ともが彫っていること。**表に四歩出ただけで店が静かになる。「知らん人だからです」
- **十一月三日は月曜である。**理容室つかもとの定休日なので、**塚本律子は出さない。**
  最後の客は十三番地のマルヤの丸尾ふみにした

### 覚え書き

　**着なかった三人（宮地・蓮見・山根）は、最後まで表に出ない。**
　最後の客に「そっちの三人は、着んの?」と聞かれて、三人とも黙る。
　日下部が口を先に動かして「次があったら」と言ってしまう。**次の予定はない。**

　**この三人の続きが、十七本目である。**

### 本編に持ち込めないもの

- 役を演じること。衣装。「おかえりなさいませ」
- 四番地を使うこと。**本編では、閉まった店は閉まったままである**

### 持ち込めるもの

　**「説明する店にせえ」**（九字）

　黒江いとの長さを、欠点ではなく品目として扱った一行である。
　**本編でも、この人の長さをそう扱う場面は作れる。**


## 十三本目（採点を切る）について

**二〇三六年九月三日（水）。全九章、七千二百字。語り手は蓮見すず一人である。**
道の駅の棚替えで納品が火曜に動き、**宮地あんずの水曜の夜が十一年ぶりに空く。**

### 壊したのは、人に点をつけないこと

　この連作は、**人物の上手下手を地の文が判定しない。**
　森岡は数えて評価しない。宮地は数えて人を数に入れない。
　矢部は湯の温度を二つ持っているが、どちらがいい湯かを一度も言わない。
　**この町の人は、物を測って、人を測らない。**

　カラオケの採点機能は、**機械が人を百点満点で測る。**それを六人に浴びせた。

| 誰 | 点 | 何が起きたか |
|---|---|---|
| 黒江いと（一回目） | **六一** | 字が入りきらない。「単位が違うものを同じ機械で測ると、こうなります」 |
| 日下部なつ（一回目） | 八四 | 声が大きいので機械がよく拾う |
| 山根とも | **九七** | 座ったまま。音が外れない。「機械が出したもんじゃろ」 |
| 宮地あんず | 八九 | **画面を見ない。**「数は、聞いたら覚えるけえ」 |
| 日下部なつ（二回目） | 七一 | 父が歌う古い歌。「下がっても、楽しいです」 |
| 矢部さえ | 九一 | **「四十二度です」。**この人が四十二度を出したのは初めてである |
| 黒江いと（二回目） | **五四** | 合わせるのをやめて、長く引いた。下がった。**そちらのほうがよかった** |
| 蓮見すず | **なし** | 採点を切ってから歌った |

### 芯

　**山根ともが最高点を出すのは、十年、誰にも聞かせないようにしてきたからである。**
　印刀を一定の速さで引く人の音は、まっすぐになる。まっすぐなものを機械は高く出す。
　本人は点に興味がない。

　**黒江いとが最低点なのは、文字の数で喋る人だからである。**
　歌は切るところが先に決まっている。先に決まっているところに、この人の言葉は入らない。
　二回目で合わせるのをやめたら、点はさらに下がって、**聞きやすくなった。**
　筆と同じである——足りないときは、引き直すのではなく、長く引く。

　最後に蓮見すずが採点を切る。理由は九字と八字で言う。

> 　「点がつくと、比べます」
> 　「比べると、続きません」

　この人と黒江いとは、五年、乾くのを待つあいだ喋る人と紙を揃える人でやってきた。
　**その形には点がついていない。ついていないから続いている。**

### 決めごと

- **曲の題を一つも書かない。**誰が何を歌ったかは、その場の六人しか知らない
- 飲まない。七月の酒盛りがまだ効いている。烏龍茶とジュースである
- **歩道橋を使わず、三百メートル南の踏切から渡る。**六人とも黙ってそちらへ行く。
  蓮見すずが向こう側へ行くのは、二〇三五年三月二十四日以来、一年五か月ぶりである

### 開けなかったもの

- **二十一時五十二分。**山根ともの携帯が伏せたまま光る。本人は見ない。
  何の時間かを、地の文は説明していない
- **矢部さえが送らなかった相手。**「大阪は、いま、起きとると思います」までで止める
- **宮地あんずと日下部なつ。**二人のことは、視線が二回合うだけである

### 本編に持ち込めないもの

- 点がつくこと。**本編では、誰も誰にも点をつけない**
- 山根ともが人前で歌うこと

### 持ち込めるもの

　**「点がつくと、比べます。比べると、続きません」**（九字と八字）

　黒江いとと蓮見すずが五年続いている理由の説明になっている。
　**本編でも、この二人ならこの長さで言える。**


## 十二本目（七本と、一杯）について

**二〇三六年七月二十三日（水）十九時 — 翌朝六時。全八章、七千四百字。**
節ごとに語り手が替わる。蓮見すず・黒江いと・矢部さえ・山根とも・日下部なつ・
宮地あんず・森岡佑・蓮見すず。

### 壊したのは、文体の統制そのもの

　この連作は読点を二十四字に一つで管理している。**この一篇は、それを節ごとに崩す。**

| 節 | 語り手 | 時刻 | 字／読点 |
|---|---|---|---|
| 1 | 蓮見すず | 十九時 | **二八・七** |
| 2 | 黒江いと | 二十時 | 二一・〇 |
| 3 | 矢部さえ | 二十時四十分 | 一四・九 |
| 4 | 山根とも | 二十一時五十二分 | 一二・八 |
| 5 | 日下部なつ | 二十二時十分 | 八・四 |
| 6 | 宮地あんず | 二十三時 | **七・三** |
| 7 | 森岡佑 | 二十三時四十分 | **二八・七** |
| 8 | 蓮見すず | 翌朝六時 | 二八・一 |

　**酔うほど読点が増える。**文が切れて、同じことを二度書いて、時刻が飛ぶ。
　第六章は、宮地あんずが数えられなくなる節である。

|---|---|---|
| 山根とも × 沖田ちさと | 方言 | **ちさとが訛る。**三年五か月で一度もなかった |
| 黒江いと × 蓮見すず | 文の長さ | **すずが百六十七字喋り、いとが四字で答える。**五年で初めて上限が動く |
| 矢部さえ × 三隅るり | 敬語 | **るりが敬語になり、さえが敬語をやめる。**九年ぶんが入れ替わる |
| 沢渡ふゆ × 藤木かなえ | 断定するかどうか | **ふゆが一つも「たぶん」を使わず、かなえが文を終えられない** |

　**軸は連作の背骨なので、一日でも動かすと本編に戻せない。**
　「壊す一つ」を、今回は文体の外から選んだ、という一本である。

### もう一つの規則——言っていない側から

　本編で「好き」を口に出したのは二人だけ（沖田ちさと、蓮見すず）で、
　四組とも**片方が先に言っている**（沖田ちさと・蓮見すず・矢部さえ・沢渡ふゆ）。

　この一篇では、**四回とも、言っていない側から始まる。**
　山根とも、黒江いと、三隅るり、藤木かなえである。
　**言えない人が、言わずに済む方法を選ぶ。**それだけの話にした。

### 四回の中身

- とも × ちさと——ちさとが、二〇三二年九月二十日にともが言った一文をそのまま返す。
  **「そこ、乾燥だけ壊れとるよ」。**訛っている。とも本人の言葉である
- いと × すず——マルヤの三十円。すずが百六十七字で理由を説明し、いとが「うれしい」と四字。
  **四回のうち、長いのはここだけである。**深さを書くかわりに、
  **〇・二ミリのずれが目で分かる人が、長さを測らなかった**と書いた。
  そのあいだ、すずは一字も言っていない。四十二字が上限の人間が、ゼロになる。
  いとの側は、筆の理由で説明される——**二度引いた線は乾いてから必ず分かるので、
  足りないときは引き直すのではなく長く引く**
- さえ × るり——柏湯は木曜が休みで、湯がない。**四十二度も四十三度もない日**である
- ふゆ × かなえ——文林堂の閉店間際。二階で本が一冊落ちる。ふゆは上を見ない

### キスだけは、規則を壊していない

　連作は**キスを禁じていない。一度も場面にしていないだけ**である。
　性的な対象として身体を描かないという線にも触れていない。

　**深さは、その人が普段測っているもので測る。**
　寸法の人には長さを測らせない。四十二字の人にはゼロを出させる。
　息と歯までは書いて、それ以上は数えない。**この書き方なら本編でも通る。**

　だから、**この一篇のうち、キスは本編に持ち込める。**持ち込めないのは軸のほうである。

### 本編に持ち込めないもの

- 沖田ちさとが訛ること。**うつらないこと自体がこの二人の距離である**
- 蓮見すずが四十二字を超えること。黒江いとが四字で済ませること
- 三隅るりの敬語と、矢部さえが敬語をやめること
- 沢渡ふゆが断定すること。**この人が「たぶん」を落とすと、別人になる**
- 沢渡ふゆと藤木かなえに「決まった日」ができること。**この組の表には、その欄がない**

### 開けなかったもの

- **矢部さえと三隅るりの二〇三四年一月二十八日。**「あの日」としか呼ばせていない
- **滝沢篤子。**二階から本が落ちる音だけで、声も姿も出していない
- **藤木かなえが、二階に九年ぶん聞かれていること。**沢渡ふゆは言わない
- **宮地あんずの相手。**「います」だけで、誰かは言わない（十一本目で開けた。本編では閉じたまま）。
  この人は数える側なので、**数の中に入らない。**そこだけは本編と同じである

### 持ち込めるもの

　**マルヤの段ボールの箱。**二月一日に出て、十四日の夕方に下げる。
　六個で三百円、ばらが一個三十円。絵は十九年変えていない（丸尾ふみ「絵は変えん」）。
　通りに菓子屋がないので、二月に何か買う人はここへ来る。
　**年中行事の二月の欄に足してよい。**節分の豆と同じ扱いである。


## 六本目（姉の友達）について

二〇三六年八月二十日（水）。**全八章、六千七百字。宮地遼（二十）の一人称。**
文体はラノベ。**語り手が、連作で一度も語っていない人**である。

　遼は作品09 と作品11 と幕間05 に出るが、台詞がほとんど「知らん」だけの人である。
　二〇三六年は大学二年。帰省中に、父に「手伝え」と言われて水曜の夜の厨房に下りる。
　そこに女が六人いる。**全員が何かに異常に特化していて、全員が彼に興味がない。**

### ラノベの型を借りて、外すもの

　男が一人、女が六人。ラノベならヒロイン紹介回になる。
　**誰も彼をヒロインとして扱わない。**質問は十五個くらい来るが、全部よそ向きである。
　黒江は字に興味があり、矢部は秒数に興味があり、日下部は家賃に興味がある。

### 芯

　**三年間、誰も「継ぐんか」と聞いてこなかった。**

　遼はそれを楽だと思っていた。この夜、十五個の質問を受けて、一個も継ぐ話でないと気づく。
　**楽というのは、誰も自分の人生の続きを予定に入れていない、ということでもある。**

　第七章で、山根ともが三年ぶりにそれを聞く。
　この人は十年、彫っているのに訂正していない人である。

> 　「うちはな。**聞かれんかったけえ、継いだ**」
> 　「聞かれんうちに決めえ」
> 　「聞かれてから決めると、**答えが返事になる**」

### 一か所だけ、地の文が説明をやめる

　この一篇の地の文は、思ったことを全部説明する。ラノベなので、そう書いてある。

　第六章で、遼が姉のノートの二〇三一年三月のページをめくる。
　同じ計算が三回してあって、三回とも答えが違う。三回目に二重線。
　**余白の一行だけ、ボールペンなので消えていない。**

> 　『十一―三』

　ここで、地の文が止まる。
　「書けないんじゃなくて、**分からない**」と書いて、それ以上説明しない。

　**あんずが進学をやめた理由は、連作の本文に一行も書いていない。**
　ここでも書かない。**弟にも分からせない。**

### 本編に持ち込めないもの

- 遼の一人称。連作はこの人に語らせていない
- 山根ともが自分の十年を人に説明すること。**本編では誰にも言っていない**
- あんずが弟の二十個を翌日の昼に店で出すこと。「よくないです」「言われたいので」

### 持ち込めるもの

　**「聞かれてから決めると、答えが返事になる」**

　これは山根とも自身の十年そのものなので、本編でも成立する。
　ただし本編のこの人は説明をしないので、**言わせるには相当の場面が要る。**


## 五本目（尾行）について

二〇三六年五月十一日（日）。**全八章、九千二百字。尾道。**
奇数章が日下部なつ、偶数章が黒江いとの一人称。

**壊したのは文体だけ。** ラノベにした。
心の声の括弧書き、地の文のツッコミ、短文と体言止め、算用数字、章題がセリフ調で長い。
連作の地の文は、感情を直接説明しない。ここでは**全部説明する。**

### 中身

　黒江いとと蓮見すずが、付き合って一年二か月で**初めて二人で出かける。**
　その日を、宮地あんずと日下部なつが朝から尾行する。
　言い出したのは宮地あんずで、理由は「うまくいってるか、見たいだけです」である。

| 章 | 語り手 | 何が起きるか |
|---|---|---|
| 1 | なつ | 前の晩の厨房。あんずが尾行を提案する。冷蔵庫の十一枚目に『10時18分』 |
| 2 | いと | 白の付いていない服が二着しかない。一文目から百七十一字喋る |
| 3 | なつ | 隣の車両。マルヤで買った千二百円の双眼鏡。観察記録 |
| 4 | いと | 尾道にはアーケードがある。看板を見てしまう。**蓮見がメモを取っていた** |
| 5 | なつ | ラーメン。麺が伸びる。「デートって、何をするんですか」「知らん」 |
| 6 | いと | ロープウェイ。高低差百十五メートル。**上から見ないと、屋根は見えない** |
| 7 | なつ | **地声でバレる。**「うまくいっています」（九字） |
| 8 | いと | 帰りの電車。十一枚目の紙に、二行目が足される |

### 本編に持ち込めないもの

- **黒江いとの百七十一字と、ロープウェイの千百字。**本編の最長は百四十四字である
- 蓮見すずがロープウェイに乗ること。**高いところは、まだ四段目までである**
- 宮地あんずが他人のデートを尾行すること。**この人は、人のことを数えない**
- 黒江いとの心の声。本編でこの人の内側は一度も書いていない

### 持ち込めるもの

　**「落ちるのは、押さえてくれる人がいれば、起きません」**（三十字）

　五年、脚立を押さえてきたのは蓮見すずのほうである。
　二〇三五年三月十五日に四段目へ上がったのが一度きりで、その日から一年二か月たっている。
　**怖いものの名前が、高さではなかったという話は、本編でも使える。**
