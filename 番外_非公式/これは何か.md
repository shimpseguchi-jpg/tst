# 番外（非公式）について

## これは正史ではない

**いまは九篇である。** どれも、作者が本編のルールを外して書いたものである。

**もとは四篇あった。三本目と四本目は本編に入れた。**
——三本目『一泊二日』は **作品17『十四分』**、四本目『拡大餃子会』は **幕間07『二十九枚』** になった。
あの二本は文体も表記も本編のままで書いてあったので、入れるときに落としたのは**作者あとがきの一節だけ**である。
経緯と、そこで開いた封印は `商店街連作設定.md` に移した。**このファイルには、残った二篇のことだけ書く。**

|---|---|---|---|

| `非公式二次創作_甘々.md` | 二　甘々 | 4,706 | **全部甘くする。**好きを百回、呼び方、お揃い、手つなぎ |

**九篇とも、どこか一つを壊してある。** そこが、本編に入った二本との違いだった。
**文体を壊していない番外は、本編にできる。壊した番外は、本編にできない。**
この一行が、前の三本目と四本目が卒業していった理由である。
——だから、番外を書くときは、**先に「文体を壊すかどうか」を決める。**
壊さないなら、それは最初から本編の候補として書いたほうがよい。
三本目『オールナイト』は、**壊すと決めてから書いた。**だから残る。
四本目『ゲスト回』は、形そのものは幕間03 と同じである。壊したのは**コメント欄**だけ。
幕間03 の設定に「コメントに俗語を使わない」「忌避表現も入れない」と書いてあるので、そこを外した。
**外す場所を一つに絞ると、その一つが内容になる。**

- 既刊表に入れない／年表に入れない／字数の合計に入れない
- `tools/リーダー用データ.py` と `tools/資料データ.py` は、この folder を見ない
- データは `tools/番外データ.py` だけが作る（出力は `reader/data/x.json`）

## 何を外したか

| 本編のルール | 番外での扱い |
|---|---|
| 数字は漢数字 | **アラビア数字**（0.2ミリ、42番、120個、100万人） |
| 三点リーダーは「……」、ダッシュは「――」 | 「…」「～」「!!」「!?」を混ぜる |
| セリフと叙述を同一行に混ぜない | **混ぜる** |
| 忌避表現（めっちゃ／ヤバい／ぶっちゃけ／てゆうか／〜すぎる／的な） | **全部使う** |
| 感情の既製品（ドキッとした／涙が溢れた／胸が熱くなった） | **全部使う** |
| 擬音の多用を避ける | **ドンッ／バチーン／ゴゴゴゴゴ** |
| 「まるで〜のような」を使わない | **使う** |
| 温度で絆を表現しない | **使う**（本文中で自分から謝っている） |
| 感情を直接説明しない | **説明する** |
| 章の終わりは物か動作で閉じる | **感慨で閉じる** |
| 本文にマークダウンを入れない | **見出しを入れる** |
| 読点は二十四字に一つ | **数えていない** |

## 何を外さなかったか

- **露骨な性的描写はしない。** 本編でも番外でも変えない。
  九本目の第五章・第六章には夜の場面があるが、**触れるところと、決めたことまでで、その先は書いていない。**
  書いてよい線は作品17 第七章と同じである。**番外だからといって、この線は動かさない**
- 未成年を性的な文脈に置かない。**夜の場面に出るのは成人四人だけである**
- 実在の人物・団体を出さない
- 本編の本文を書き換えない

## ここで開けた「封じてあるもの」

**番外で開けても、本編では閉じたままにする。一つも持ち込まない。**
（沖田ちさとの本名と、あんずとちさとが会うことは、この表から外した。
　どちらも作品17 と幕間07 で**本編の側が開けた**ので、もう番外の話ではない。）

- 滝沢篤子の顔（作品03）
- 橘ひなたの五年（作品01）
- 森岡が見てしまったもの（作品07）※番外でも最後まで言わせていない
- 塚本律子の月曜の行き先（連作ぜんたい）
- 久世藍の次回作の宣言（作品02・14）
- 山根吉春が客に訂正すること（作品10・13・14・15）
- アーケードの屋根（作品07で外れた）

**ただし、塚本律子の月曜だけは例外にしてよい。**
番外の第7節で出した「銀星座で月曜の一回目を観ている」は、本編で使う価値があると判断した。
使うときは、四十八年と、もぎりと、月曜の一回目だけ残して、あとは全部削る。

## 九本目（逆さ）について

**二〇三六年二月十八日（月）— 二十一日（木）。全九章、一万千九百字。ラノベ・性転換。**
語り手は沖田ちさと・山根とも・蓮見すず・黒江いと・沖田ちさと・蓮見すず・宮地あんず・
山根とも・黒江いとである。

### 仕掛け

　**山根印房の蔵から出た古い印を押すと、三日だけ逆になる。**

　連作の作品10 の題は『逆さに彫る』で、あの一本はこの一行でできている。

> 　印章は左右逆に彫る。押して初めて、正しく読める。

　**それを人に適用した。**逆さになった三日のあいだ、通りは二人を正しく読んでしまう。

　押したのは**山根ともと黒江いと**である。この二人を選んだ理由は一つで、
　**本編で「好き」を自分から言っていないのが、この二人だけ**だからである。

### 三日で変わったもの（本人の仕事は一つも変わっていない）

| | 逆になったあいだ |
|---|---|
| 山根とも | 二時間で三回「継ぐんか」と聞かれる。**十年で一回も聞かれていなかった** |
| 同 | 注文の電話が二日で五本。普段は月に四本 |
| 同 | 父が客に訂正しないのは同じ。**隠すためではなく、自然だから**になる |
| 黒江いと | 見積もりが一回で通る。いつもは三回に二回聞き返される |
| 同 | 「看板屋さん」ではなく名前で呼ばれる |
| 同 | 二割高い数字が通る。四分の説明が遮られない |
| 同 | 木曜に戻ると、**一日で十七回疑われる。**火曜はゼロだった |

### 芯は、得だったかどうかを片づけないこと

　第七章で日下部なつが聞く。**「その体、得じゃないですか」**
　この人は通りでいちばん素直なので、いちばん先に本当のことを聞く。

　答えは二つ出て、どちらも消さない。

- 黒江いと「同じものを出しています。**わたしは、五年分、疑われていたということです**」
- 山根とも「注文が倍来た」——そのうえで、**「彫れん」**

　**山根ともだけは、体が変わって仕事が壊れる。**
　手が五ミリ大きくなると、印刀を支える指の腹の位置がずれる。
　十年かけて合わせたもので、三日では合わない。練習を三本彫って、三本とも上手だった。
　**上手で、ともの字ではなかった。**

　宮地あんずが数える。二百四十個は二百四十個で、失敗した皮も三枚で同じだった。
　**扱いは変わる。数は変わらない。**

### 夜の場面（第五章・第六章）

　成人四人の話である。**線は作品17 第七章と同じ**で、そこから先には行かない。

- 沖田ちさと（第五章）——声も背も肩も変わって、**手だけ変わらない。**
  この人が好きになったのは二〇三二年九月二十日の午前三時に見た**手元**である
- 蓮見すず（第六章）——五年、脚立を押さえる側だった人が、**五段目に上がる。**
  怖いのは高さではなく、届いたら外せないことである

### 「好き」の扱い

　第五章で、山根ともが初めて「好きじゃ」と言う。**知らない喉から出た声である。**
　沖田ちさとはそれを受け取らない。**「三日たったら、自分の声で、もう一回です」**
　第八章で、自分の声で言う。

　**本編に持ち込まない。**本編のこの人は、まだ一度も言っていない。

### 父が一行だけ喋る（第八章）

> 　「**わしも、二十八で押した**」

　これで、第二章の「楽になったか」が、**質問ではなく記憶だったことになる。**
　山根吉春は、それ以上言わない。**この人は十年、そうである。**

### 本編に持ち込めないもの

- 印で体が変わること。蔵の箱と、底の紙
- 山根ともが「好きじゃ」と言うこと
- 蓮見すずが五段目に上がること。**本編ではまだ四段目が一度きりである**
- 山根吉春が自分のことを喋ること

### 持ち込めるもの

　**「同じものを出して、扱いだけが変わりました」**

　黒江いとが五年、三回に二回聞き返されてきたことは、本編の事実である。
　**逆さにしなくても書ける。**書くなら、通る日を一日も出さないで書く。

## 八本目（入れ替わり）について

**二〇三五年十二月十四日（金）十二時十四分 — 十五日（土）十二時十四分。全九章、一万百字。**
章ごとに語り手が替わる。森岡佑・黒江いと・蓮見すず・山根とも・沖田ちさと・
沢渡ふゆ・藤木かなえ・宮地あんず・森岡佑。

**置き場所。**作品18 の第六章が二〇三五年十二月で、十二月十四日の福引きに
藤木かなえが出て**四等**を引いている。そこを壊さずに重ねた。
一等を引くのは黒江・山根とも・沢渡ふゆ・宮地あんずの四人である。

### 仕掛け

　**一等を引いた人は、その日いちばん長く一緒にいた人と、二十四時間入れ替わる。**

　一等は二〇〇七年から商品券五千円で変わっていない。**理由は組合の記録にない**
（共有設定の年中行事にそう書いてある）。この一篇が、その理由である。

　金額を上げると並ぶ人が増える。増えると出る。だから上げない。
　知っているのは森岡ひとりで、**記録していない。**「書くと、理由が残るので」

### 各組で起きること

| 組 | 分かること |
|---|---|
| 黒江 ↔ 蓮見 | **蓮見の体は四段目で平気だった。**怖いのは高さではなく「落ちたら誰かが困る」こと |
| 同 | 蓮見が黒江の口で百六十二字喋る。**同じことを言っている。**蓮見はいつも四字で言う |
| 山根とも ↔ 沖田 | ともが生配信をやる。喋れないので**彫る音を四時間流す。**同接が七年でいちばん増える |
| 同 | ちさとが彫る。手は覚えていても目が覚えていない。**父が音で気づく。**「止まるところが多い」 |
| 沢渡 ↔ 藤木 | ふゆが藤木の目で読む。**滑らない。ただし残らない。**目の問題ではなかった |
| 同 | 藤木が自分の記事を読めない。**八年書いたものが一行も入ってこない** |
| 宮地 ↔ 日下部 | **日下部の体が二時四十分に勝手に起きる。**窯があると、数えなくても手が止まらない |

### 本編に持ち込めないもの

- 入れ替わりそのもの。福引きの一等の中身
- 沖田ちさとが自分の名前の印を彫ること。**地の文は四文字を読み上げていない**
- 藤木かなえが、文林堂の二階に九年ぶん聞かれていることを先に知ること。
  **本人は沢渡に言わない。**言うと、あの人がやめるからである

### 持ち込めるもの

　**「落ちたら、誰かが困ります」**（十四字）

　蓮見すずが五年、三段目で止まっていた理由である。高さではない。
　作品16 でも幕間06 でも、この人は理由を言っていない。**本編で言わせる場面は、まだない。**

## 七本目（水曜ループ）について

**二〇三四年九月二十日（水）。全十章、七千四百字。宮地あんずの一人称。ラノベ・時間ループ。**

**置き場所に注意。** 本編の二〇三四年九月は、作品16 が月に一度しか触っていない空白である。
冷蔵庫の紙は、作品13（二〇三三年八月）で五枚目、幕間06（二〇三五年三月）で七枚目になる。
**あいだの六枚目が、本編では決まっていない。** この一篇は、そこに入る。

### 仕掛け

　気づくのは宮地あんずで、理由は**数が合いすぎるから**である。
　百二十個がぴったり合うのは全体の三割しかない。それが三回続いた。
　**破れた皮の枚数まで三回とも二枚だった。**

　検証が七つある。数を変える、包まない、店を出る、起きない、日付を確かめる、
　紙を見る、数えないで待つ。七つ目で分かる。
　**この日は、あんずが数え終わるまで終わらない。**

### 抜け方（作品13 の裏側）

　仮説は一度崩れる。〇日のはずの日だから合わない、という説明を立てて、
　**毎回ぴったり合っているので崩れる。**

　本当の理由は、作品13 第七章の一行目にある。

> 　合ったので、この日も何も起きなかったことになる。

　**日を終わらせているのは、あんず本人である。**
　四年で夜が四百回あって、冷蔵庫の紙は五枚しかない。
　残りの三百九十五回を、この人が「何も起きなかった日」にしてきた。
　**ループは今週から始まったのではない。気づいただけ。**

　抜け方は、作品13 第七章の最後の二行にある。

> 　これはノートに書かなかった。
> 　書く欄が、この見開きにはない。

　**欄を作る。** 物差しで縦線を一本引いて、右のいちばん上に『出来』と二文字書く。
　欄の幅が足りなくて、出来事の二文字で止まる。
　そこに数ではないものを書いて、**合った日なのに紙を貼る。**六枚目である。

### 回収したもの

- 山根とも「終わらせ方は、始まり方と同じじゃ」（八回目の夜）
- 黒江いと 四分喋って全部外れるが、一行だけ当たる。「版をずらすのは、刷る側です」
- 蓮見すず「それは、つらいです」（十字）。**あんずはこれを十九回聞く**
- 作品13 第九章、名簿に定休日の欄がなくて、森岡の「数えましょうか」を断った夜

### 本編に持ち込めないもの

- 繰り返し。三十二回
- 六人に三十一回説明して、三十一回とも翌朝に消えること
- 六人が誰も帰らない夜（第六章）

### 持ち込めるもの

　**六枚目の紙。**本編では中身が決まっていない。
　ここで『九月二十日　六人来た』にしたが、**本編で別のものにしてもよい。**
　持ち込むのは中身ではなく、**合った日にも貼ることがある、という一点だけ**である。

## 六本目（姉の友達）について

二〇三六年八月二十日（水）。**全八章、六千七百字。宮地遼（二十）の一人称。**
文体はラノベ。**語り手が、連作で一度も語っていない人**である。

　遼は作品09 と作品11 と幕間05 に出るが、台詞がほとんど「知らん」だけの人である。
　二〇三六年は大学二年。帰省中に、父に「手伝え」と言われて水曜の夜の厨房に下りる。
　そこに女が六人いる。**全員が何かに異常に特化していて、全員が彼に興味がない。**

### ラノベの型を借りて、外すもの

　男が一人、女が六人。ラノベならヒロイン紹介回になる。
　**誰も彼をヒロインとして扱わない。**質問は十五個くらい来るが、全部よそ向きである。
　黒江は字に興味があり、矢部は秒数に興味があり、日下部は家賃に興味がある。

### 芯

　**三年間、誰も「継ぐんか」と聞いてこなかった。**

　遼はそれを楽だと思っていた。この夜、十五個の質問を受けて、一個も継ぐ話でないと気づく。
　**楽というのは、誰も自分の人生の続きを予定に入れていない、ということでもある。**

　第七章で、山根ともが三年ぶりにそれを聞く。
　この人は十年、彫っているのに訂正していない人である。

> 　「うちはな。**聞かれんかったけえ、継いだ**」
> 　「聞かれんうちに決めえ」
> 　「聞かれてから決めると、**答えが返事になる**」

### 一か所だけ、地の文が説明をやめる

　この一篇の地の文は、思ったことを全部説明する。ラノベなので、そう書いてある。

　第六章で、遼が姉のノートの二〇三一年三月のページをめくる。
　同じ計算が三回してあって、三回とも答えが違う。三回目に二重線。
　**余白の一行だけ、ボールペンなので消えていない。**

> 　『十一―三』

　ここで、地の文が止まる。
　「書けないんじゃなくて、**分からない**」と書いて、それ以上説明しない。

　**あんずが進学をやめた理由は、連作の本文に一行も書いていない。**
　番外でも書かない。**弟にも分からせない。**

### 本編に持ち込めないもの

- 遼の一人称。連作はこの人に語らせていない
- 山根ともが自分の十年を人に説明すること。**本編では誰にも言っていない**
- あんずが弟の二十個を翌日の昼に店で出すこと。「よくないです」「言われたいので」

### 持ち込めるもの

　**「聞かれてから決めると、答えが返事になる」**

　これは山根とも自身の十年そのものなので、本編でも成立する。
　ただし本編のこの人は説明をしないので、**言わせるには相当の場面が要る。**

## 五本目（尾行）について

二〇三六年五月十一日（日）。**全八章、九千二百字。尾道。**
奇数章が日下部なつ、偶数章が黒江いとの一人称。

**壊したのは文体だけ。** ラノベにした。
心の声の括弧書き、地の文のツッコミ、短文と体言止め、算用数字、章題がセリフ調で長い。
連作の地の文は、感情を直接説明しない。ここでは**全部説明する。**

### 中身

　黒江いとと蓮見すずが、付き合って一年二か月で**初めて二人で出かける。**
　その日を、宮地あんずと日下部なつが朝から尾行する。
　言い出したのは宮地あんずで、理由は「うまくいってるか、見たいだけです」である。

| 章 | 語り手 | 何が起きるか |
|---|---|---|
| 1 | なつ | 前の晩の厨房。あんずが尾行を提案する。冷蔵庫の十一枚目に『10時18分』 |
| 2 | いと | 白の付いていない服が二着しかない。一文目から百七十一字喋る |
| 3 | なつ | 隣の車両。マルヤで買った千二百円の双眼鏡。観察記録 |
| 4 | いと | 尾道にはアーケードがある。看板を見てしまう。**蓮見がメモを取っていた** |
| 5 | なつ | ラーメン。麺が伸びる。「デートって、何をするんですか」「知らん」 |
| 6 | いと | ロープウェイ。高低差百十五メートル。**上から見ないと、屋根は見えない** |
| 7 | なつ | **地声でバレる。**「うまくいっています」（九字） |
| 8 | いと | 帰りの電車。十一枚目の紙に、二行目が足される |

### 本編に持ち込めないもの

- **黒江いとの百七十一字と、ロープウェイの千百字。**本編の最長は百四十四字である
- 蓮見すずがロープウェイに乗ること。**高いところは、まだ四段目までである**
- 宮地あんずが他人のデートを尾行すること。**この人は、人のことを数えない**
- 黒江いとの心の声。本編でこの人の内側は一度も書いていない

### 持ち込めるもの

　**「落ちるのは、押さえてくれる人がいれば、起きません」**（三十字）

　五年、脚立を押さえてきたのは蓮見すずのほうである。
　二〇三五年三月十五日に四段目へ上がったのが一度きりで、その日から一年二か月たっている。
　**怖いものの名前が、高さではなかったという話は、本編でも使える。**

## 四本目（ゲスト回）について

二〇三六年四月。**全十三節、七千六百字。地の文がない。**
白詰ねむの発話が「　」、ゲストの声が『　』、コメントは鉤括弧なし。

　幕間03『四百八十円』と同じ形である。あちらは三千二百字の一章で、
　**この形だと人が一人しか出せない。**コメントは四万人いるが、あれは人数ではなく速度で、
　誰が書いたか分からないようにしてあるので、人として数えられない。

　**だから十一人出した。**

### 本編に持ち込めないもの

- 山根ともが配信に出ること。七時間喋る場所に出る理由がない
- 宮地あんずが出ること。**言わずに聞いてきたことが、この人のいちばん大事なところ**である
- 塚本律子の三つ目の質問。誰のことかは、番外でも言わせていない
- 沢渡ふゆの朗読。本編でこれを聞いているのは、**二階の人だけ**である

### 持ち込めるもの

　**声に出したことは、残る。**

　四時間喋ったあとに一時間かけて言葉を引く人と、声に出さないと一行が入ってこない人。
　この二人は本編で一度も会っていないし、会わせる予定もない。
　それでも、毎晩、別々に声に出している。

## 三本目（オールナイト）について

二〇三六年四月。作品18 が終わった次の月である。**全二十二節、二万字。番外でいちばん長い。**
時刻で節を立てて、十七時から翌朝四時五十分まで。

**目的はひとつ。全員で集合写真を一枚撮ること。**

この連作は、写真がとても弱い。
顔を出していない配信者がいる。九年で写真が一枚もない人がいる。
撮る仕事なのに「わたしは写らなくていいです」と言った記者がいる。
九年姿を見せない店主がいる。内面を書かないと決めてある人がいる。
十年、昼の光の下に出ていない人がいる。
**本編では、この全員が一枚に入らない。**

だから、一晩かけて障害を一つずつ壊す。節が進むごとに一人ずつ入れるようにしていく。

| 4 | 沖田ちさとがフードを脱ぐ。宮地あんずと正面から喋る |
| 5 | 矢部さえが、九年で一枚目を撮る |
| 6 | 滝沢篤子が階段を降りる。**九年ぶんの声が、上から聞こえていた** |
| 7 | 塚本律子の内面に、地の文が一行だけ入る。**入れて、すぐ閉めた** |

| 19 | 蓮見すずが、自分で四段目に上がる |

### 壊さなかったもの

- **森岡の三つ目。**「見てしまったものを言うと、見られた人が、見られたことを知ります」
- **宇田ときの家。**本人が来て、名前を言って、それでも「今日も、言わないです」と言う
- **矢部さえと三隅るりの二〇三四年一月二十八日。**「本編でやるけえ」と本人が断る
- **宮地あんずの相手。**「います」と即答するが、誰かは言わない
- 塚本律子の内面は、一行だけ開けて閉じた。**もう開けない**

### この一篇で決めたこと

- 冷蔵庫の紙は**十枚目**。『一人百二十個』。三千八百四十個包んだ
- 黒江いとの本編での最長は百四十四字。**この夜は三百二十字**
- 蓮見すずは四十二字を守らない。カラオケで千二百字歌う
- 久世昭三の写真が一枚出る。一九七一年。**切符の切り方が曲がっている**

**本編に持ち込むのは一つだけ。**
　矢部さえが撮った、九年で一枚目。ブレていて、二人とも写っている。
　**本編でもいつか撮る。理由は説明しないで成立するように書く。**

## 二本目（甘々）について

本編で「好き」が口に出されたのは**二回**だけである。

1. 作品15 第八章　沖田ちさと「好きな人が作っているものの値段を四万人に言いました」
2. 作品16 第十一章　蓮見すず「そうです。好きです」

**山根ともと黒江いとは、最後まで自分からは言っていない。**
番外の二本目では、ともに「好きじゃ」と言わせ、いとに三メートルの板を出させている。
**本編では、どちらもやらせない。**

二本目で足した甘さの道具（本編には持ち込まない）
　呼び方（ともちゃん／すず／さえちゃん）、お揃いの印、手を触った回数の記録、
　頭ぽんぽん、通りに出す告白の板、九年ぶりの一枚、「好き」百回。

**唯一、本編に持ち込んでよいのは考え方のほうである。**
　「砂糖を入れないと決めた人が、一粒だけ入れたときにだけ甘い」。
　これは番外の第五節に書いた。**本編の運転の仕方そのものなので、忘れないこと。**

## 読み方

リーダーの作品一覧のいちばん下、「備陽新報の紙面」の横に「？」がある。
**五回押すと開く。** 三回目から色が変わる。
一度開くと、その端末では一押しで開くようになり、ボタンに小さい点が付く。

## 載せ方

**本編と同じ形で載せてある。** 番外だけの読み物ページではない。

「？」を押すと、作品一覧が番外の一覧に入れ替わる。
見出しが「番外（非公式）」になり、篇・節・字の数がそこだけの合計に変わる。
行は本編と同じで、番号、題名、副題、紹介、節数、字数、しおりが並ぶ。
本文は本編と同じ縦書きの画面で読む。目次も、進捗も、字の大きさも、全画面も同じである。
違うのは数え方の単位だけで、**章ではなく節**と出る（「第三節 ／ 全十六節」「次の節」）。

　`reader/data/x.json`　　　　　　　番外の一覧（`index.json` と同じ形）
　`reader/data/x1.json`・`x2.json`　一篇ぶん（作品の `.json` と同じ形）

　`libx` が真のあいだだけ、一覧と目次が番外のほうを見る。
　`open()` は番号が `x` で始まるかどうかで、これを自分で切り替える。
　だから番外を読んでいるときの「一覧」は番外の一覧に戻り、
　そこから「本編の一覧へ」で本編に戻る。

**混ざらないようにしてあるもの**
　`index.json` と `guide.json` に番外は入っていない。
　本編の一覧の合計（二十四篇）にも入っていない。
　`sw.js` の先読みにも入れていない（`x*.json` は開いたときに初めて取りに行く）。
