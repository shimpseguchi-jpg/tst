# 番外（非公式）について

## これは正史ではない

**四篇ある。** どれも、作者が本編のルールを外して書いたものである。

| ファイル | ラベル | 字数 | 中身 |
|---|---|---|---|
| `非公式二次創作.md` | 一　大宴会 | 6,314 | **封印を全部開ける。**全員集合、秘密の開示、屋根の復活 |
| `非公式二次創作_甘々.md` | 二　甘々 | 4,706 | **全部甘くする。**好きを百回、呼び方、お揃い、手つなぎ |
| `非公式二次創作_旅行.md` | 三　一泊二日 | 22,263 | **文体は本編のまま、内容の制限だけ外す。**二人の旅行と、その報告 |
| `非公式二次創作_拡大餃子会.md` | 四　拡大餃子会 | 14,176 | **文体も表記も本編のまま、人数の制限だけ外す。**通りが一日閉めて、二十九人集まる |

**三本目と四本目は、外し方が違う。**
一本目と二本目は文体を壊した。三本目は**文体をまったく壊していない。**
漢数字、三点リーダー、セリフと叙述の分離、感情を直接説明しない、節の終わりは物か動作。
全部そのままで、**内容の制限だけ外してある。**
読点も測ってある（二十二・六字に一つ。本編と同じ「よい」）。

**四本目は、外したものが一つしかない。同じ部屋に入れていい人数である。**
文体も表記も三人称の距離も本編のままで、忌避表現も使っていない。
読点は三十二・五字に一つ（本編より少ないくらいである）。
**外れているのは、連作の原則2「主役は毎回、女の子二人」だけ。**

- 既刊表に入れない／年表に入れない／字数の合計に入れない
- `tools/リーダー用データ.py` と `tools/資料データ.py` は、この folder を見ない
- データは `tools/番外データ.py` だけが作る（出力は `reader/data/x.json`）

## 何を外したか

| 本編のルール | 番外での扱い |
|---|---|
| 数字は漢数字 | **アラビア数字**（0.2ミリ、42番、120個、100万人） |
| 三点リーダーは「……」、ダッシュは「――」 | 「…」「～」「!!」「!?」を混ぜる |
| セリフと叙述を同一行に混ぜない | **混ぜる** |
| 忌避表現（めっちゃ／ヤバい／ぶっちゃけ／てゆうか／〜すぎる／的な） | **全部使う** |
| 感情の既製品（ドキッとした／涙が溢れた／胸が熱くなった） | **全部使う** |
| 擬音の多用を避ける | **ドンッ／バチーン／ゴゴゴゴゴ** |
| 「まるで〜のような」を使わない | **使う** |
| 温度で絆を表現しない | **使う**（本文中で自分から謝っている） |
| 感情を直接説明しない | **説明する** |
| 章の終わりは物か動作で閉じる | **感慨で閉じる** |
| 本文にマークダウンを入れない | **見出しを入れる** |
| 読点は二十四字に一つ | **数えていない** |

## 何を外さなかったか

- **身体を性的な対象として描かない。** これは本編でも番外でも変えない
- 実在の人物・団体を出さない
- 本編の本文を書き換えない

**番外で開けても、本編では閉じたままにする。一つも持ち込まない。**

使うときは、四十八年と、もぎりと、月曜の一回目だけ残して、あとは全部削る。

## 四本目（拡大餃子会）について

二〇三五年八月二十二日（水）。**八番地の水曜の夜に、通りが二十九軒ぶん入ってくる。**
視点は三人称。誰の頭の中にも入りきらず、**あとから記録した人の距離**で書いてある。
（「あとで分かったが、宮地はその場では分からなかった」——この語り方を全編で通す。）

**仕掛けは一つだけで、作品13の答えを裏返したものである。**

作品13 で確定したのは、**二十九軒が二十九回、別々に休みを決めたから合わない**ということだった。
六人でも〇日。二十九軒なら数える前から〇日である。
**だから、重ねるのをやめて、一日だけ全部閉めた。**

- 森岡が**組合の名簿に三十年ぶりに欄を一つ足す**（作品13 第九章「定休日の欄がない」の回収）
- 用途の欄には「その他」とだけ書く。**理由を書かない。**「書くと、理由が残ります」
- 石垣理事長が**祭りの日を避ける。**「祭りの日にやったら、祭りのぶんになります」
- 塚本律子の月曜は、**欄に「月曜」と書いて、行き先は聞かない。**番外でも開けていない

### ここで初めてやったこと

1. **宮地あんずと沖田ちさとを同じ部屋に入れた。**
   作品11 の約束（以後この二人を会わせない）と、幕間05 の「断ったのはあんずである」を外した。
   **本編には一つも持ち込まない。**
2. **塚本律子が座る。** 幕間04 では戸口で三往復して帰った人である
3. **川本青果の店先に立つ人が、名前を言う。**「川本ゆき」。
   作品12 で藤木かなえが聞いて、聞けなかった名前である。
   **本編では、まだ聞けていないままにする**
4. **三田村燈子が羽室から柏尾へ来る。** 共有設定の「逆方向（羽室→柏尾）はいまは作らない」を外した。
   来る理由は**仕事**である（食品パッケージ／柏尾製パンの一括表示）。
   共有設定が「必要になったらカードとして使う」と書いてあるとおりに使った
5. **芦原まひるが羽室へ行っていたことにした。**「まだ書いていない」往来を、ここで既成事実にした。
   **年に一度か二度、九回。誰にも言っていない**

### 開けなかったもの（番外でも開けていない）

- **塚本律子の月曜の行き先。**欄に書いたのは曜日だけである
- **文林堂の二階。**沢渡ふゆが戸の下から紙を入れて、戸の下から返ってくる。「皆さんによろしく」
- **森岡が見てしまったもの。**この夜、森岡は鞄を持っていない。書類にしない
- **山根ともが彫っていること。**父の吉春が言ったのは「あれは、ようできとった」の一行だけで、
  誰が彫ったとは言っていない。**厨房の二十八人のうち二十六人が聞き流す**

## 二本目（甘々）について

本編で「好き」が口に出されたのは**二回**だけである。

1. 作品15 第八章　沖田ちさと「好きな人が作っているものの値段を四万人に言いました」
2. 作品16 第十一章　蓮見すず「そうです。好きです」

**山根ともと黒江いとは、最後まで自分からは言っていない。**
番外の二本目では、ともに「好きじゃ」と言わせ、いとに三メートルの板を出させている。
**本編では、どちらもやらせない。**

二本目で足した甘さの道具（本編には持ち込まない）
　呼び方（ともちゃん／すず／さえちゃん）、お揃いの印、手を触った回数の記録、
　頭ぽんぽん、通りに出す告白の板、九年ぶりの一枚、「好き」百回。

**唯一、本編に持ち込んでよいのは考え方のほうである。**
　「砂糖を入れないと決めた人が、一粒だけ入れたときにだけ甘い」。
　これは番外の第五節に書いた。**本編の運転の仕方そのものなので、忘れないこと。**

## 三本目（一泊二日）について

二〇三五年十一月十五日から十六日。**二周年の旅行。**
奇数節が沖田ちさと、偶数節が山根とも。本編と同じ交互の一人称である。

本編でやらないことを三つやった。

1. **柏尾の外へ出した。**連作は十六作と六つの幕間で、柏尾と羽室から一度も出ていない
2. **二人で泊まらせた。**一つの布団と、二つ並んだ枕
3. **沖田ちさとに、自分の名前を声に出させた**（第六節・部屋の露天風呂）

**三つ目は本編ではまだやらない。**
幕間06 の時点で、あの人は書くことはできて、言うことはできない。
言える日が来るとしても、**それは露天風呂ではない。もっと何でもない場所にする。**

第七節（夜）の書き方
　触れるところまでは書いて、その先を間に置いた。行為そのものは書いていない。
　触っているあいだは、**測る人が何を測ったか**で書いた。
　指の腹の赤と黒の厚さ、印床の角が当たる左の親指の付け根、右の肩が五ミリ下がっていること。
　そのあとは、**二時と、三時と、四時五十分**を書いた。
　二人が二年間、別々の場所で起きていた時刻である。
　四時五十分から二十二分、山の中なので本物の無音が聞こえて、ちさとはそれをこわいと思う。
　**三年半好きだと思っていた無音は、無音ではなかった。**

第九節（報告）の黒塗りについて

　**行ごと塗らない。単語だけ塗る。**

```
「ど、どこを」
「■を触られた」
「ひ、ひぇ〜!!」
```

　前半は、前後の文法を見せたまま**名詞一つだけ**を塗る。
　下に入っているのは、腕、肩、首の横、背中といった程度のもので、露骨なものではない。

　**そして、前半は隠れていない。**
　黒江いとが次の行で必ず叫び返すので、塗った言葉がその場で割れる。
　「隠す気、ないんですか」「隠しとらん」が、そのまま本当になっている。

　**後半は、黒江の質問ごと塗る。**
　「ここから、黒江が変わった」以降、この人の聞くことがそのまま帯になる。
　帯が一行まるごとになり、答えも帯になり、**読んでいる人には何も分からなくなる。**
　分からなくなるのは読者だけで、厨房の五人には全部聞こえている。

　**最後に、最初から塗る必要のなかったものが出てくる。**「背中じゃ」「そっちが騒ぐけえじゃ」

　黒江いとの造形
　　この人は**人に興味がないふりが上手いだけ**である。
　　二年二か月、台で人の話を自分から振ったことが一度もない。看板と塗料と字と匂いの話しかしない。
　　人の話になると手元を見る。**手元を見ているときが、いちばん聞いている**（蓮見すずの証言）。
　　最後に、しゃがんだまま台の下から言う。「わたし、こういう話」「たぶん、好きです」
　　**この人が自分のことを言うときは、必ず「たぶん」が付く。**付いているが、言った。

　実装
　　`tools/番外データ.py` は `{{ }}` をそのまま通す。
　　`reader/index.html` の `deco()` が `<span class="xred">` に変える。
　　`deco()` は本文の描画そのものに入っているので、縦書きでも横組みでも帯になる。
　　CSS は `color` と `background` を両方 `--ink` にして、`user-select:none` を掛けてある。
　　縦のときは `padding` の向きを変える（`body.tate .xred`）。
　　`**〜**` は `<b>` になる。一本目と二本目でしか使っていない。

第九節の終わりについて
　五人は四分五十秒で三十一個聞いた。黒江二十三、日下部七、矢部一、蓮見〇。
　蓮見が言ったのは「それは、さすがに」と「大丈夫ですか」だけなので、質問に入らない。
　**宮地あんずは〇である。**最後に一つだけ聞いて、それは夜の話ではない。
　「その人、楽しそうでしたか」——四年半、声だけ聞いてきた人の質問である。
　**この一つのほうが、答えるのに時間がかかる。**

本編に持ち込まないもの
　旅行、宿、泊まり、名前を声に出すこと、六十センチが〇になること、黒塗り。

**本編に持ち込んでよいのは、十四分のほうである。**
　vlogを撮るつもりで行って、着いてから一分も撮らなかった。撮れたのは午前の十四分だけ。
　**理由を説明していない。**説明しないことで成立している。これは本編の運転そのものである。

## 読み方

リーダーの作品一覧のいちばん下、「備陽新報の紙面」の横に「？」がある。
**五回押すと開く。** 三回目から色が変わる。
一度開くと、その端末では一押しで開くようになり、ボタンに小さい点が付く。

## 載せ方

**本編と同じ形で載せてある。** 番外だけの読み物ページではない。

「？」を押すと、作品一覧が番外の一覧に入れ替わる。
見出しが「番外（非公式）」になり、篇・節・字の数がそこだけの合計に変わる。
行は本編と同じで、番号、題名、副題、紹介、節数、字数、しおりが並ぶ。
本文は本編と同じ縦書きの画面で読む。目次も、進捗も、字の大きさも、全画面も同じである。
違うのは数え方の単位だけで、**章ではなく節**と出る（「第九節 ／ 全十節」「次の節」）。

　`reader/data/x.json`　　　番外の一覧（`index.json` と同じ形）
　`reader/data/x1.json` 他　一篇ぶん（作品の `.json` と同じ形）

　`libx` が真のあいだだけ、一覧と目次が番外のほうを見る。
　`open()` は番号が `x` で始まるかどうかで、これを自分で切り替える。
　だから番外を読んでいるときの「一覧」は番外の一覧に戻り、
　そこから「本編の一覧へ」で本編に戻る。

**混ざらないようにしてあるもの**
　`index.json` と `guide.json` に番外は入っていない。
　本編の一覧の合計（二十二篇）にも入っていない。
　`sw.js` の先読みにも入れていない（`x*.json` は開いたときに初めて取りに行く）。
