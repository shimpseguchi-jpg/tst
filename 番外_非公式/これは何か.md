# 番外（非公式）について

## これは正史ではない

**三篇ある。** どれも、作者が本編のルールを外して書いたものである。

| ファイル | ラベル | 字数 | 中身 |
|---|---|---|---|
| `非公式二次創作.md` | 一　大宴会 | 6,314 | **封印を全部開ける。**全員集合、秘密の開示、屋根の復活 |
| `非公式二次創作_甘々.md` | 二　甘々 | 4,706 | **全部甘くする。**好きを百回、呼び方、お揃い、手つなぎ |
| `非公式二次創作_旅行.md` | 三　一泊二日 | 17,055 | **文体は本編のまま、内容の制限だけ外す。**二人の旅行 |

**三本目だけ、外し方が違う。**
一本目と二本目は文体を壊した。三本目は**文体をまったく壊していない。**
漢数字、三点リーダー、セリフと叙述の分離、感情を直接説明しない、節の終わりは物か動作。
全部そのままで、**内容の制限だけ外してある。**
読点も測ってある（二十二・六字に一つ。本編と同じ「よい」）。

- 既刊表に入れない／年表に入れない／字数の合計に入れない
- `tools/リーダー用データ.py` と `tools/資料データ.py` は、この folder を見ない
- データは `tools/番外データ.py` だけが作る（出力は `reader/data/x.json`）

## 何を外したか

| 本編のルール | 番外での扱い |
|---|---|
| 数字は漢数字 | **アラビア数字**（0.2ミリ、42番、120個、100万人） |
| 三点リーダーは「……」、ダッシュは「――」 | 「…」「～」「!!」「!?」を混ぜる |
| セリフと叙述を同一行に混ぜない | **混ぜる** |
| 忌避表現（めっちゃ／ヤバい／ぶっちゃけ／てゆうか／〜すぎる／的な） | **全部使う** |
| 感情の既製品（ドキッとした／涙が溢れた／胸が熱くなった） | **全部使う** |
| 擬音の多用を避ける | **ドンッ／バチーン／ゴゴゴゴゴ** |
| 「まるで〜のような」を使わない | **使う** |
| 温度で絆を表現しない | **使う**（本文中で自分から謝っている） |
| 感情を直接説明しない | **説明する** |
| 章の終わりは物か動作で閉じる | **感慨で閉じる** |
| 本文にマークダウンを入れない | **見出しを入れる** |
| 読点は二十四字に一つ | **数えていない** |

## 何を外さなかったか

- **身体を性的な対象として描かない。** これは本編でも番外でも変えない
- 実在の人物・団体を出さない
- 本編の本文を書き換えない

## ここで開けた「封じてあるもの」

**番外で開けても、本編では閉じたままにする。一つも持ち込まない。**

- 滝沢篤子の顔（作品03）
- 橘ひなたの五年（作品01）
- 森岡が見てしまったもの（作品07）※番外でも最後まで言わせていない
- 沖田ちさとの本名（作品10・14・15・幕間05・06）
- 塚本律子の月曜の行き先（連作ぜんたい）
- 久世藍の次回作の宣言（作品02・14）
- 山根吉春が客に訂正すること（作品10・13・14・15）
- 宮地あんずと沖田ちさとが会うこと（作品10・11の約束）
- アーケードの屋根（作品07で外れた）

**ただし、塚本律子の月曜だけは例外にしてよい。**
番外の第7節で出した「銀星座で月曜の一回目を観ている」は、本編で使う価値があると判断した。
使うときは、四十八年と、もぎりと、月曜の一回目だけ残して、あとは全部削る。

## 二本目（甘々）について

本編で「好き」が口に出されたのは**二回**だけである。

1. 作品15 第八章　沖田ちさと「好きな人が作っているものの値段を四万人に言いました」
2. 作品16 第十一章　蓮見すず「そうです。好きです」

**山根ともと黒江いとは、最後まで自分からは言っていない。**
番外の二本目では、ともに「好きじゃ」と言わせ、いとに三メートルの板を出させている。
**本編では、どちらもやらせない。**

二本目で足した甘さの道具（本編には持ち込まない）
　呼び方（ともちゃん／すず／さえちゃん）、お揃いの印、手を触った回数の記録、
　頭ぽんぽん、通りに出す告白の板、九年ぶりの一枚、「好き」百回。

**唯一、本編に持ち込んでよいのは考え方のほうである。**
　「砂糖を入れないと決めた人が、一粒だけ入れたときにだけ甘い」。
　これは番外の第五節に書いた。**本編の運転の仕方そのものなので、忘れないこと。**

## 三本目（一泊二日）について

二〇三五年十一月十五日から十六日。**二周年の旅行。**
奇数節が沖田ちさと、偶数節が山根とも。本編と同じ交互の一人称である。

本編でやらないことを三つやった。

1. **柏尾の外へ出した。**連作は十六作と六つの幕間で、柏尾と羽室から一度も出ていない
2. **二人で泊まらせた。**一つの布団と、二つ並んだ枕
3. **沖田ちさとに、自分の名前を声に出させた**（第六節・部屋の露天風呂）

**三つ目は本編ではまだやらない。**
幕間06 の時点で、あの人は書くことはできて、言うことはできない。
言える日が来るとしても、**それは露天風呂ではない。もっと何でもない場所にする。**

第七節（夜）の書き方
　触れるところまでは書いて、その先を間に置いた。行為そのものは書いていない。
　触っているあいだは、**測る人が何を測ったか**で書いた。
　指の腹の赤と黒の厚さ、印床の角が当たる左の親指の付け根、右の肩が五ミリ下がっていること。
　そのあとは、**二時と、三時と、四時五十分**を書いた。
　二人が二年間、別々の場所で起きていた時刻である。
　四時五十分から二十二分、山の中なので本物の無音が聞こえて、ちさとはそれをこわいと思う。
　**三年半好きだと思っていた無音は、無音ではなかった。**

本編に持ち込まないもの
　旅行、宿、泊まり、名前を声に出すこと、六十センチが〇になること。

**本編に持ち込んでよいのは、十四分のほうである。**
　vlogを撮るつもりで行って、着いてから一分も撮らなかった。撮れたのは午前の十四分だけ。
　**理由を説明していない。**説明しないことで成立している。これは本編の運転そのものである。

## 読み方

リーダーの作品一覧のいちばん下、「備陽新報の紙面」の横に「？」がある。
**五回押すと開く。** 三回目から色が変わる。開くと上に三本ぶんのタブが出る。
一度開くと、その端末では一押しで開くようになり、ボタンに小さい点が付く。
