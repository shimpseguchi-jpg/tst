# 番外（非公式）について

## これは正史ではない

**いまは十六篇である。** どれも、作者が本編のルールを外して書いたものである。

**もとは四篇あった。三本目と四本目は本編に入れた。**
——三本目『一泊二日』は **作品17『十四分』**、四本目『拡大餃子会』は **幕間07『二十九枚』** になった。
あの二本は文体も表記も本編のままで書いてあったので、入れるときに落としたのは**作者あとがきの一節だけ**である。
経緯と、そこで開いた封印は `商店街連作設定.md` に移した。**このファイルには、残った二篇のことだけ書く。**

**十六篇とも、どこか一つを壊してある。** そこが、本編に入った二本との違いだった。
**文体を壊していない番外は、本編にできる。壊した番外は、本編にできない。**
この一行が、前の三本目と四本目が卒業していった理由である。
——だから、番外を書くときは、**先に「文体を壊すかどうか」を決める。**
壊さないなら、それは最初から本編の候補として書いたほうがよい。
三本目『オールナイト』は、**壊すと決めてから書いた。**だから残る。
四本目『ゲスト回』は、形そのものは幕間03 と同じである。壊したのは**コメント欄**だけ。
幕間03 の設定に「コメントに俗語を使わない」「忌避表現も入れない」と書いてあるので、そこを外した。
**外す場所を一つに絞ると、その一つが内容になる。**

- 既刊表に入れない／年表に入れない／字数の合計に入れない
- `tools/リーダー用データ.py` と `tools/資料データ.py` は、この folder を見ない
- データは `tools/番外データ.py` だけが作る（出力は `reader/data/x.json`）

## 何を外したか

| 本編のルール | 番外での扱い |
|---|---|
| 数字は漢数字 | **アラビア数字**（0.2ミリ、42番、120個、100万人） |
| 三点リーダーは「……」、ダッシュは「――」 | 「…」「～」「!!」「!?」を混ぜる |
| セリフと叙述を同一行に混ぜない | **混ぜる** |
| 忌避表現（めっちゃ／ヤバい／ぶっちゃけ／てゆうか／〜すぎる／的な） | **全部使う** |
| 感情の既製品（ドキッとした／涙が溢れた／胸が熱くなった） | **全部使う** |
| 擬音の多用を避ける | **ドンッ／バチーン／ゴゴゴゴゴ** |
| 「まるで〜のような」を使わない | **使う** |
| 温度で絆を表現しない | **使う**（本文中で自分から謝っている） |
| 感情を直接説明しない | **説明する** |
| 章の終わりは物か動作で閉じる | **感慨で閉じる** |
| 本文にマークダウンを入れない | **見出しを入れる** |
| 読点は二十四字に一つ | **数えていない** |

## 何を外さなかったか

- **露骨な性的描写はしない。** 本編でも番外でも変えない。
  九本目の第五章・第六章には夜の場面があるが、**触れるところと、決めたことまでで、その先は書いていない。**
  書いてよい線は作品17 第七章と同じである。**番外だからといって、この線は動かさない**
- 未成年を性的な文脈に置かない。**夜の場面に出るのは成人四人だけである**
- 実在の人物・団体を出さない
- 本編の本文を書き換えない

## ここで開けた「封じてあるもの」

**番外で開けても、本編では閉じたままにする。一つも持ち込まない。**
（沖田ちさとの本名と、あんずとちさとが会うことは、この表から外した。
　どちらも作品17 と幕間07 で**本編の側が開けた**ので、もう番外の話ではない。）

- 滝沢篤子の顔（作品03）
- 橘ひなたの五年（作品01）
- 森岡が見てしまったもの（作品07）※番外でも最後まで言わせていない
- 塚本律子の月曜の行き先（連作ぜんたい）
- 久世藍の次回作の宣言（作品02・14）
- 山根吉春が客に訂正すること（作品10・13・14・15）
- アーケードの屋根（作品07で外れた）

**ただし、塚本律子の月曜だけは例外にしてよい。**
番外の第7節で出した「銀星座で月曜の一回目を観ている」は、本編で使う価値があると判断した。
使うときは、四十八年と、もぎりと、月曜の一回目だけ残して、あとは全部削る。

## 十六本目（メイド喫茶）について

**二〇三六年十一月三日（月・祝）、第十二回 食べ歩きの日。全十八章、一万三千八百字。ラノベ。**
語り手は章ごとに替わる。日下部なつを主に、宮地あんず・黒江いと・矢部さえ・蓮見すず・山根とも。

### 壊したのは、役を演じさせたこと

　この連作は、**十六篇と八幕間で、誰にも一度も別人のふりをさせていない。**
　入れ替わり（番外八）も性転換（番外九）も、**中身や体が変わるだけで、演技ではない。**

　この一篇で初めて、**人物が「言わない言葉」を言う。**「おかえりなさいませ」である。

　そして、**演じられる人と、演じられない人がはっきり分かれる。**それがこの一篇の中身になった。

### 成り行き

　組合の回覧板に、空き店舗を使った企画の募集が入る。誰も出さない。
　**日下部なつが、その場で書いて出す。**企画名の欄は「喫茶（1日だけ）」。
　メイドとは書いていない。**思いついたのは、その二日後である。**

　森岡の対応は十二年変わらない。「受けます」「通るとは限りません」「かわりに、何も保証しません」。

　会場は**四番地、喫茶みちくさ。**二〇二九年十二月二十八日に閉まって、七年たっている。
　一九七一年の加盟で、五十八年やっていた店である。**喫茶だった場所で喫茶をやる。**

　日付は**十一月三日**。作品04 で宮地と日下部が十六歳で餃子パンを出した、**あの行事の八年後**である。

### 着る三人と、着ない三人

| | 誰 | なぜ |
|---|---|---|
| **着る** | 矢部さえ | 「服が変わっても、やることは変わらんけえです」 |
| | 日下部なつ | 呼び込みができる。**ただし店ぜんぶに向かって言う。**矢部に「来た人一人に言うてください」と直される |
| | 黒江いと | 説明をやめられない。「おかえりなさいませ」のあとに必ず説明が始まる |
| **着ない** | 宮地あんず | 厨房と会計 |
| | 蓮見すず | 「喋れるからです」「わたしは、喋れません」——**押しつけず、自分で降りる** |
| | 山根とも | 洗い場。人前で喋らない |

　衣装は三着しかない。**六人なので、半分が着て、半分が着ない。**
　決まるまでに四十分かかる。**外したのではなく、自分で決めた**形にしてある。

### 宮地あんずの一行が、店の形を決める

　黒江が説明をやめられない、と電話で相談される。返事は九字だった。

> 　**「説明する店にせえ」**

　黒江は一卓に着くとなかなか離れない。内容はコーヒーではなく、
　**この建物の話**である。七年前まで喫茶みちくさだったこと、木札に七年前の値段があること。
　客の一人が「あんた、説明の人?」と言い、「来年もやりんさい」と言って帰る。

### 数（原則4を守る）

　入った客は百九十八人。売上十九万二千四百円、残りが十四万四千円。六人で割って一人二万四千円。

　**それで通りは何も変わらない。**四番地は翌日からまた閉まっている。屋根も戻らない。
　八年前と同じである。**商店街は活気づかない。**

　ただ、パンだけ数が合わない。百八十個持ってきて百七十六個売れて、残りが二個しかない。
　宮地は二回数えて、**それを数に入れないことにする。**五時間立ちっぱなしで一枚も割らなかった
　人間が、洗い場にいるからである。

### 書き直したこと

　初稿は、六人を**軸の名札で動かしていた。**矢部さえが客の温度を言い、蓮見すずが
「四十二字です」と数を申告し、黒江いとが「百四十四字」「三分五十二秒」を数える。
　地の文が「この人は決めてから考える人じゃ」と性格を説明していた。

　全篇を書き直し、**数と温度の申告を全部落とした。**かわりに、`資料/まだ書いていない面.md`
から、軸と関係のない面を一人に一つか二つ入れた。

| 誰 | 入れた面 | どこに出るか |
|---|---|---|
| 日下部なつ | 字が下手／名前を覚えるのが速い | 企画書の欄。並んでいる客に「さっきコーヒーじゃったですよね」 |
| 宮地あんず | 音を入れない | 古いラジオが鳴って、**黙って消す。**理由は言わない |
| 黒江いと | 黙るときがある | 考えていないときに黙る。「喋らんこともあるんじゃ」「いまです」 |
| 蓮見すず | 書くと長い／道具を貸さない | 定規を貸さず自分で三百枚引く。最後、**厚い封筒を一通だけ書く** |
| 矢部さえ | 縫える | 前の晩に自分の丈を上げ、**黒江の袖を二センチ出す。**誰にも言わない |
| 山根とも | 甘いものを大量に食べる／歌を覚えている | **合わない二個はこの人である。**布の裏で十年前の曲をうたう |

　**残した数は、宮地あんずの帳簿だけである。**それはこの人の仕事だからである。

　あわせて、藤木かなえの所属を直した。**柏尾支局は二〇三六年三月三十一日に閉まっている**
（作品18）。十一月三日には、もう福山から回ってきている。

### 開けなかったもの

- **衣装の貸主。**山根ともが七番地を経由して持ってくる。「知っとる人がおる」「言えん」。
  袋の底に手書きの紙が入っている——「無理はせんでください」。**名前は書いていない**
- **山根ともが彫っていること。**表に四歩出ただけで店が静かになる。「知らん人だからです」
- **十一月三日は月曜である。**理容室つかもとの定休日なので、**塚本律子は出さない。**
  最後の客は十三番地のマルヤの丸尾ふみにした

### 覚え書き

　**着なかった三人（宮地・蓮見・山根）は、最後まで表に出ない。**
　最後の客に「そっちの三人は、着んの?」と聞かれて、三人とも黙る。
　日下部が口を先に動かして「次があったら」と言ってしまう。**次の予定はない。**

　**この三人の続きは、まだ書いていない。**

### 本編に持ち込めないもの

- 役を演じること。衣装。「おかえりなさいませ」
- 四番地を使うこと。**本編では、閉まった店は閉まったままである**

### 持ち込めるもの

　**「説明する店にせえ」**（九字）

　黒江いとの長さを、欠点ではなく品目として扱った一行である。
　**本編でも、この人の長さをそう扱う場面は作れる。**

## 十五本目（惚れ薬）について

**二〇三六年十月一日（水）— 五日（日）。全十八章、一万二千七百字。文体はラノベ。**
語り手は宮地あんずを主に、六人に渡していく。

### 壊したのは、宮地あんずが数の外にいること

　この人は連作で唯一の「数える側」で、**数の中に入らない。**
　番外の十本目で、本人にこう言わせている——
　**「数えるほうの人間が、数の中におったら、数えられんようになる」。**

　この一篇は、それを実行した。**六人が一斉に、宮地あんずを数えはじめる。**

| 誰 | どう狂うか |
|---|---|
| 黒江 いと | **人の字数を数えてしまう。**宮地の発言だけ。ノートに正の字 |
| 蓮見 すず | **四十二字の上限が外れる。**最長八百十二字。本人がいちばん驚く |
| 矢部 さえ | **宮地の体温だけ分かる。**道具が要らない。ほかの人は分からない |
| 山根 とも | **自分から質問する。**木曜だけで二十五個。一晩で印を六本彫る |
| 日下部 なつ | **声が出なくなる。**もともと付き合っているので、量だけが三、四倍になる |
| 沖田 ちさと | **配信で名前を言いかける。**四万人の前で。持ち帰りの二個を食べた |

　**そして宮地あんずは、四日間、一度も数えられない。**
　皮の枚数が数えられなくなる。十一年で初めてである。
　こわいのは六人に見られることではなく、**自分が測れなくなること**だと気づく。

### 仕掛け

　**三隅るりが、ラベルを読み違える。**校正を九年やっている人が、である。
　大阪の古い乾物屋で買った瓶で、崩し字の「花」の下が椒ではなかった。
　効くのは**作った人に対して、三日と半日**。目録にはそれしか書いていない。

　**解くのも校正である。**取り寄せた目録の百三十七ページで、活版の行が一行ぶんずれていた。
　乾物屋も、それを見て売っていた。**刷った側が先にまちがえていた。**
　るりは、そこに赤を入れる。**九年でいちばん遅い校正**である。

　切れる順番は、食べた数で決まる。宮地が指を動かして出す。
　**四日ぶりに、この人が数える場面**がそれである。

### 痛いほう

- **矢部さえ**が、木曜の夜に大阪へ電話して「ごめん」だけで切る。
  九年見上げてきた人の声で、何も起きなくなっている。
  解けたあと、るりは怒らない。**「読み違えたんはうちや」「あんたは食うただけや」**
- **山根とも**と**沖田ちさと**が、午前三時のランドリーで互いに何も感じない。
  「うちは、あと七時間ある」「待っとれ」
- **黒江いと**と**蓮見すず**が、別の人の話で一時間半喋る。
  **五年でいちばん会話が多い一時間半だった**

### 芯——言われなかったのが効いた

　六人のうち五人は、四日のあいだに言いに来た。

　**日下部なつだけ、声が出ないので何も言えなかった。**
　薬が切れても、この人の量は減らない。むしろ水曜の前より少し多い。

> 　「あんただけ、何も言わんかった」
> 　「言えんかったんです」
> 　「知っとる」
> 　「**言われんかったのが、いちばん効いた**」

### 開けなかったもの

- **沖田ちさとの四文字。**配信で言いかけて、口が止まる。地の文も書かない
- **宮地あんずが進学をやめた理由。**山根ともが「継ぐんか」と聞いて、店が静かになる。答えない
- **瓶の字が何なのか。**るりも「わからん」で終わる
- 効能の説明。目録の欄が**「三日と半日、作った人に向く」で終わっている**

### 本編に持ち込めないもの

- 薬。惚れること。四日間の全部
- 蓮見すずが八百字喋ること。山根ともが一晩で六本彫ること

### 持ち込めるもの

　**「今日は、よう入るのう」**

　娘の店に六人が押しかけて地獄になっている昼に、父が厨房から出てきて言う一行である。
　この人は、娘が進学をやめた年にも理由を聞かなかった。**聞かないことが、この父の全部**である。
　**本編でそのまま使える。**

## 十四本目（学園）について

**県立柏尾高校の一年間。全二十八章、二万千七百字。番外でいちばん長い。**
文体はラノベ。主な語り手は日下部なつで、章ごとに渡していく。

### 壊したのは、人が店でできていること

　この連作の人物は、**全員が職でできている。**
　山根ともは十年彫ってきた手であり、黒江いとは五年ぶん疑われてきた人であり、
　宮地あんずは十一年数えてきた人である。

　**この一篇は、そこを全部剥がした。**店がない。家業もない。全員が生徒である。
　残ったのは、癖と、速さと、距離の取り方だけになる。

### 寄り道（第四章 — 第六章）

　乗り換えは福山で、**二時間四分空けてある。**
　空けたのは宮地あんずで、日下部なつには言っていない。切符の時刻で気づかれる。
　**店から出ない人が、寄る時間を先に取っていた。**それがこの一篇でいちばん大きい事実である。

　行くのは福山城で、駅を出てすぐ横にある。ホームから天守が見える。

- **第五章。**あんずが石垣の石を数えようとして、**数えられない。**
  同じものが並んでいれば数えられる。形がちがうものが並ぶと、目が引っかかって数が落ちる。
  厨房では起きないことである。**この人が「数えられんかった」と言うのは、八年で初めて**
- **第六章。**駅前の看板に「百万本のばらのまち」と書いてある。
  なつが読んで、「数えられんのに、書いてあるんです」と言う。
  **数えられない数が、一日で二つ続く。**片方は誰かが数えながら積んだもので、
  片方は誰も数えていないものである
- 一六二二年と一九六六年という年号を見て、あんずが「四百年もつんじゃね」と言う。
  なつは十三代と計算して、**言わずにやめる。**答えが要る質問と要らない質問を、
  この人は同じ言い方でする
- なつが写真を一枚撮る。**自分で撮ったのは八年で初めてで、誰にも送らない**

### 喧嘩（第七章 — 第八章）

　作品04『餃子パン』で、二人が七年間たがいを敵だと思っていた根拠は、
　**夏祭りの発電機のコード一本**だった。譲る人と譲る人が、祭りの音のなかで大声で譲り合っていた。
　誰も覚えていなかった。あの日、二人はアーケードの下で長く笑って、それで終わったことになっている。

　**終わっていない。**そのあとで、本当の喧嘩を三回している。

| | いつ | 何で |
|---|---|---|
| 一回目 | 二〇二九年八月十二日 | 餃子パンを続けるかどうか。「七十個じゃ」。百個作って七十個は損である |
| 二回目 | 二〇三〇年四月二十日 | 屋根が外れた次の月。「屋根がないほうが明るい」「雨で三割落ちる」 |
| 三回目 | 二〇三一年三月十四日 | **あんずが進学をやめた二日後。**数字を出され、なつがその場で計算して、合わないと言った |

　喧嘩の形は、いまの二人の形と同じである。
　**あんずが数で言う。返せなくなったなつが声を大きくする。あんずが黙る。**
　黙られたなつが負けた気になって、あんずは勝った気にならない。何度やっても同じ形になる。

　三回目に、なつはこう言った。

> 　「うちも継ぐんじゃけえ、同じじゃないですか」

　同じではなかった。**選んだ人間が、選んでいない人間に「同じ」と言った。**
　そのときの黙り方だけ、ほかの二回とちがう。ほかは相手を見て黙り、そのときは下を見て黙った。
　そのあと二週間、口をきいていない。**十四日ぶんも、なつは数えている。**

　**あんずは日付を覚えていない。中身は覚えている。**

　仲直りした日は、二人とも知らない。

> 　喧嘩した日は三つとも覚えとる。仲直りした日は、一つも覚えとらん。
> 　日付があるのは、悪いことのほうだけじゃった。

## 七本目（水曜ループ）について

**二〇三四年九月二十日（水）。全十章、七千四百字。宮地あんずの一人称。ラノベ・時間ループ。**

**置き場所に注意。** 本編の二〇三四年九月は、作品16 が月に一度しか触っていない空白である。
冷蔵庫の紙は、作品13（二〇三三年八月）で五枚目、幕間06（二〇三五年三月）で七枚目になる。
**あいだの六枚目が、本編では決まっていない。** この一篇は、そこに入る。

### 仕掛け

　気づくのは宮地あんずで、理由は**数が合いすぎるから**である。
　百二十個がぴったり合うのは全体の三割しかない。それが三回続いた。
　**破れた皮の枚数まで三回とも二枚だった。**

　検証が七つある。数を変える、包まない、店を出る、起きない、日付を確かめる、
　紙を見る、数えないで待つ。七つ目で分かる。
　**この日は、あんずが数え終わるまで終わらない。**

### 抜け方（作品13 の裏側）

　仮説は一度崩れる。〇日のはずの日だから合わない、という説明を立てて、
　**毎回ぴったり合っているので崩れる。**

　本当の理由は、作品13 第七章の一行目にある。

> 　合ったので、この日も何も起きなかったことになる。

　**日を終わらせているのは、あんず本人である。**
　四年で夜が四百回あって、冷蔵庫の紙は五枚しかない。
　残りの三百九十五回を、この人が「何も起きなかった日」にしてきた。
　**ループは今週から始まったのではない。気づいただけ。**

　抜け方は、作品13 第七章の最後の二行にある。

> 　これはノートに書かなかった。
> 　書く欄が、この見開きにはない。

　**欄を作る。** 物差しで縦線を一本引いて、右のいちばん上に『出来』と二文字書く。
　欄の幅が足りなくて、出来事の二文字で止まる。
　そこに数ではないものを書いて、**合った日なのに紙を貼る。**六枚目である。

### 回収したもの

- 山根とも「終わらせ方は、始まり方と同じじゃ」（八回目の夜）
- 黒江いと 四分喋って全部外れるが、一行だけ当たる。「版をずらすのは、刷る側です」
- 蓮見すず「それは、つらいです」（十字）。**あんずはこれを十九回聞く**
- 作品13 第九章、名簿に定休日の欄がなくて、森岡の「数えましょうか」を断った夜

### 本編に持ち込めないもの

- 繰り返し。三十二回
- 六人に三十一回説明して、三十一回とも翌朝に消えること
- 六人が誰も帰らない夜（第六章）

### 持ち込めるもの

　**六枚目の紙。**本編では中身が決まっていない。
　ここで『九月二十日　六人来た』にしたが、**本編で別のものにしてもよい。**
　持ち込むのは中身ではなく、**合った日にも貼ることがある、という一点だけ**である。

## 六本目（姉の友達）について

二〇三六年八月二十日（水）。**全八章、六千七百字。宮地遼（二十）の一人称。**
文体はラノベ。**語り手が、連作で一度も語っていない人**である。

　遼は作品09 と作品11 と幕間05 に出るが、台詞がほとんど「知らん」だけの人である。
　二〇三六年は大学二年。帰省中に、父に「手伝え」と言われて水曜の夜の厨房に下りる。
　そこに女が六人いる。**全員が何かに異常に特化していて、全員が彼に興味がない。**

### ラノベの型を借りて、外すもの

　男が一人、女が六人。ラノベならヒロイン紹介回になる。
　**誰も彼をヒロインとして扱わない。**質問は十五個くらい来るが、全部よそ向きである。
　黒江は字に興味があり、矢部は秒数に興味があり、日下部は家賃に興味がある。

### 芯

　**三年間、誰も「継ぐんか」と聞いてこなかった。**

　遼はそれを楽だと思っていた。この夜、十五個の質問を受けて、一個も継ぐ話でないと気づく。
　**楽というのは、誰も自分の人生の続きを予定に入れていない、ということでもある。**

　第七章で、山根ともが三年ぶりにそれを聞く。
　この人は十年、彫っているのに訂正していない人である。

> 　「うちはな。**聞かれんかったけえ、継いだ**」
> 　「聞かれんうちに決めえ」
> 　「聞かれてから決めると、**答えが返事になる**」

### 一か所だけ、地の文が説明をやめる

　この一篇の地の文は、思ったことを全部説明する。ラノベなので、そう書いてある。

　第六章で、遼が姉のノートの二〇三一年三月のページをめくる。
　同じ計算が三回してあって、三回とも答えが違う。三回目に二重線。
　**余白の一行だけ、ボールペンなので消えていない。**

> 　『十一―三』

　ここで、地の文が止まる。
　「書けないんじゃなくて、**分からない**」と書いて、それ以上説明しない。

　**あんずが進学をやめた理由は、連作の本文に一行も書いていない。**
　番外でも書かない。**弟にも分からせない。**

### 本編に持ち込めないもの

- 遼の一人称。連作はこの人に語らせていない
- 山根ともが自分の十年を人に説明すること。**本編では誰にも言っていない**
- あんずが弟の二十個を翌日の昼に店で出すこと。「よくないです」「言われたいので」

### 持ち込めるもの

　**「聞かれてから決めると、答えが返事になる」**

　これは山根とも自身の十年そのものなので、本編でも成立する。
　ただし本編のこの人は説明をしないので、**言わせるには相当の場面が要る。**

## 五本目（尾行）について

二〇三六年五月十一日（日）。**全八章、九千二百字。尾道。**
奇数章が日下部なつ、偶数章が黒江いとの一人称。

**壊したのは文体だけ。** ラノベにした。
心の声の括弧書き、地の文のツッコミ、短文と体言止め、算用数字、章題がセリフ調で長い。
連作の地の文は、感情を直接説明しない。ここでは**全部説明する。**

### 中身

## 三本目（オールナイト）について

二〇三六年四月。作品18 が終わった次の月である。**全二十二節、二万字。番外でいちばん長い。**
時刻で節を立てて、十七時から翌朝四時五十分まで。

**目的はひとつ。全員で集合写真を一枚撮ること。**

この連作は、写真がとても弱い。
顔を出していない配信者がいる。九年で写真が一枚もない人がいる。
撮る仕事なのに「わたしは写らなくていいです」と言った記者がいる。
九年姿を見せない店主がいる。内面を書かないと決めてある人がいる。
十年、昼の光の下に出ていない人がいる。
**本編では、この全員が一枚に入らない。**

だから、一晩かけて障害を一つずつ壊す。節が進むごとに一人ずつ入れるようにしていく。

## 読み方

リーダーの作品一覧のいちばん下、「備陽新報の紙面」の横に「？」がある。
**五回押すと開く。** 三回目から色が変わる。
一度開くと、その端末では一押しで開くようになり、ボタンに小さい点が付く。

## 載せ方

**本編と同じ形で載せてある。** 番外だけの読み物ページではない。

「？」を押すと、作品一覧が番外の一覧に入れ替わる。
見出しが「番外（非公式）」になり、篇・節・字の数がそこだけの合計に変わる。
行は本編と同じで、番号、題名、副題、紹介、節数、字数、しおりが並ぶ。
本文は本編と同じ縦書きの画面で読む。目次も、進捗も、字の大きさも、全画面も同じである。
違うのは数え方の単位だけで、**章ではなく節**と出る（「第三節 ／ 全十六節」「次の節」）。

　`reader/data/x.json`　　　　　　　番外の一覧（`index.json` と同じ形）
　`reader/data/x1.json`・`x2.json`　一篇ぶん（作品の `.json` と同じ形）

　`libx` が真のあいだだけ、一覧と目次が番外のほうを見る。
　`open()` は番号が `x` で始まるかどうかで、これを自分で切り替える。
　だから番外を読んでいるときの「一覧」は番外の一覧に戻り、
　そこから「本編の一覧へ」で本編に戻る。

**混ざらないようにしてあるもの**
　`index.json` と `guide.json` に番外は入っていない。
　本編の一覧の合計（二十四篇）にも入っていない。
　`sw.js` の先読みにも入れていない（`x*.json` は開いたときに初めて取りに行く）。
