# 作品13『重ならない』設定

連作十三作目。**人を増やさない。** 出るのはすでにいる六人と、その周りだけ。
書くのは**仕事ではなく、休みのほう。**

- **時期**　**二〇三三年七月二十七日 — 九月七日。** 幕間04『半人前が六つ』のすぐあと
  （幕間04は七月二十一日の木曜。「来週の水曜」が七月二十七日にあたる）
- **視点**　**章ごとに移す。全部一人称。** 六人の声を並べる
- **全十章。各章三千四百字。およそ三万四千字**

## 0. この作品が答えるもの

幕間04の終わりで、蓮見すずが「また、集まりたいです」と言い、
宮地あんずが「来週の水曜です」と即答した。

**その水曜は、来ない。**

理由は気持ちではない。**休みの形が、六人とも違うからである。**
そして、六人全員の休みが重なる日は、**一年に一日もない。**

## 1. 定休日（連作の共有事実として、ここで確定させる）

| 店 | 休み | 実際のところ |
|---|---|---|
| 中華 福来軒 | **水曜** | **その水曜の夜に、道の駅へ出すぶんを包む。あんずに休みはない** |
| 柏尾製パン | **日曜** | なつの体は日曜も二時四十分に起きる |
| 銀紷堂 | **土日** | いととすずが同じ日に休む。**二人とも、休んだ気がしない** |
| 柏湯 | **火・木・土・日**（月水金だけ開ける） | さえは大学四年 |
| 山根印房 | **不定**（十四時から十六時だけ開ける） | **注文が切れた日が休み。いつ来るか決まらない** |
| 理容室つかもと | 月曜 | 四十八年、毎週どこかへ行っている（本作では追わない） |
| 古書店 文林堂 | 水曜 | 作品03で既出 |
| 川本青果・白鳩舎 | 日曜 | |
| 銀星座 | 火曜 | |
| ランドリーぎんてん | 無休・無人 | |

**あんずの水曜となつの日曜は、永久に重ならない。** これが本作の骨である。

## 3. 落ちるところ

　答えは、幕間04がすでに出していた。
　あの夜、六人は**休みの日ではなく、包み終えた夜**に集まっていた。
　**休みを合わせようとしたから、合わなかった。**
　合わせるのをやめて、あんずの水曜の夜に来ればいい。来れば包むのを手伝うことになる。
　それなら全員が来られる。

　**誰も最初から気づかない。** 十章かけて、元の場所に戻る。

## 4. 一人称を六つ書き分ける

| | 文の特徴 |
|---|---|
| あんず | 数字が先に来る。即答する。**段落が短い。比喩を使わない** |
| なつ | 備後弁。声が大きい人の文。**文が長くなり、途中で切れる** |
| いと | 饒舌。**括弧の中に足していく。脱線してから戻る** |
| すず | 敬語のまま考える。**短い。言い切る前に止まる** |
| さえ | 観察が細かい。**他人のことは正確に書けて、自分のことになると文が止まる**（作品05から一貫） |
| とも | 口数が少ない。**一文が短い。説明しない。形容詞をほとんど使わない** |

## 5. 矢部さえの章（第五章）について

**ここだけ温かく書く。** ほかの九章は連作の温度のままにして、五章だけ上げる。
上げた落差が、この作品の呼吸になる。

- 三隅るり、三十八歳。作品06から六年。**まだ月水金に柏湯へ来ている。七年目である。**
- **関係に名前をつけない。** 作品05・06と同じ扱いを続ける。
- さえは大学四年。就職を決める年。**柏湯を継ぐかどうかは、この作品でも決めない。**
- 作品06でるりが「四年後」と決めた日付（二〇三一年）は、**もう過ぎている。**
  何があったかは書かない。**二人がいまどうなっているかだけを、動作で見せる。**
- **［厳守］身体を性的な対象として描かない。** さえは二十二だが、連作の作法を変えない。
  温かさは、距離の近さと、遠慮のなさで出す。

## 6. やらないこと

- **新しい人物を出さない。** 一人も増やさない
- **誰かが店を辞めない。閉店させない。** 事件を起こさない
- 六人を揃えない。**最終章でも、揃うのは次の水曜の約束までである**
- 塚本律子の月曜を追わない。**通りかかるだけにする**（別の作品のために取っておく）
- 森岡を主役にしない。第九章に一度だけ出す
- 沖田ちさとを出さない（作品10と11の約束）

## 7. 仕事以外の、この六人（本作でいちばん大事な項）

**これまでの連作は、仕事と動作と癖でこの六人を書いてきた。**
本作は一人称なので、**その人が何を好きで、何を欲しがっているかを、本人の言葉で出す。**
ただし感情の既製品（胸が締めつけられた、涙が溢れた）は使わない。
**好きなものは具体で、欲しいものは言い切らずに出す。**

### 宮地 あんず（21）

- **好き**　配信を聞いている。四年になる。誰にも言っていない（作品11）。
  聞くのは包んでいるあいだで、片耳だけ。**内容ではなく、喋り方の速さが好き。**
  自分の即答と似ていて、似ていない。あちらは間を置ける。
- **欲しい**　**数えること以外で、何かができると言われたい。**
  数が合うと褒められるが、それは数が合っただけである。
- **弱いところ**　人を誘ったことがない。先週の「来週の水曜です」が、生まれて初めての誘いだった。

### 日下部 なつ（20）

- **好き**　**日曜の二時四十分から七時までの町。** 誰も起きていない。それが好きだと、
  誰にも言ったことがない。言う相手が起きていないからである。
- **好き**　自転車。速さ。坂を下りるときに声が出る。
- **欲しい**　**人がいる時間に、人がいる場所へ行きたい。** 五年、そうしていない。
- **弱いところ**　声が大きいことを、自分では直せないと思っている。直す気もない。

### 黒江 いと（25）

- **好き**　**看板の写真。** 携帯に四千枚以上ある。旅先でも撮る。整理していない。
  好きなのは字そのものではなく、**書いた人の手が止まった場所**である。
- **好き**　匂い。塗料、紙、雨の前の空気。
- **欲しい**　**蓮見さんに、速さ以外のことを言われたい。**
  速い、は二年言われ続けている。速いは、うまいではない。
- **弱いところ**　自分のやっていることが技術ではなく癖なのではないか、と時々思う。

### 蓮見 すず（28）

- **好き**　**人が捨てる印刷物。** チラシ、切符、レシート、薬の説明書。
  箱に入れてある。使う予定はない。**組み方を見るのが好き。**
- **好き**　水の音。機械のローラーを洗っている三十分が、一日でいちばん静かである。
- **欲しい**　**仕事以外のことを聞かれたい。** 敬語が守っているのは自分だと分かっている。
- **弱いところ**　休み方を知らない。**高いところが怖いので、行ける場所が少ない。**

### 矢部 さえ（22）

- **好き**　**写真。** 六年撮っている。猫、石段、郵便受け、湯の面。
  **るりの写真は一枚もない。** 撮っていいか聞けないからである（作品06から）。
- **好き**　四十二度。柏湯に四十二度はない。ないものが好き、という形になっている。
- **欲しい**　**決めなくていい時間。** 大学四年で、就職を決める年である。
- **弱いところ**　他人のことは正確に書けるのに、自分のことになると文が止まる。

### 山根 とも（26）

- **好き**　**人がいる場所に、喋らずにいること。** 深夜のランドリー、コンビニ、定食屋。
  誰も話しかけてこない時間に、人のいるところにいる。
- **好き**　車で聞く音楽。**夜しか運転しないので、好きな曲は全部夜に聞いた曲になった。**
- **欲しい**　**昼に、この通りを歩きたい。** 十年思っていて、一度も実行していない。
- **弱いところ**　彫っていないときの自分を、どう扱えばいいのか分からない。

## 8. 本作で補ったディテール（以後、崩さない）

### 中華 福来軒
- 水曜の夜に包むぶんの皮は、**一週で四百枚**仕入れる。餡は一個**十六グラム**
- 一人で包むと**五時間十分**かかる。十七時に始めて二十三時十分に終わる
- 皿は三十枚ある。席は十四（作品09から）
- 道の駅へ出すラベルは**銀紷堂が刷る**。日付だけは店で回転式のゴム印を押す
- 『水曜定休』の紙は二〇二六年から貼りっぱなし。角が四か所とも丸い（作品13 第一章・第九章）
- 冷蔵庫の扉に貼る紙は、**数が動いた日にだけ書く**。第七章で五枚目、第十章で六枚目
- 宮地健一は二十六で継いだ。宮地遼は十七で、水曜は塾。帰りは二十二時

### 柏尾製パン
- 粉の配達は**月曜と木曜の朝**。五十キロ。外には置けない
- 二十八年前に一度、休みを火曜に変えて三か月でやめた。**変えた月は三割落ちた**
- 組合の一斉清掃は**第二日曜の朝**。柏尾製パンは休みなので三十年出ている
- ミキサーは一回ぶんの大きさしかない
- なつは帰りの坂（下り二百メートル）で毎回声が出る。**考えごとをしていると出ない**

### 柏尾銀天街振興組合
- 名簿の欄は六つ。**店名・代表者・住所・間口・電話・加盟年**
- **定休日の欄はない。** 三十年、誰も要ると言わなかった
- 休みは届け出るものではなく、各店が別々に決めてよいことになっている
- 事務所は通りの南の口の二階。階段が急で、机が四つある

### その他
- 山根ともは**試し押しの紙を十年ぶん箱に取ってある。** 隅に日付と時刻が入っている
- 蓮見すずは**四つ目の箱を作った。** 中は一枚だけ（宮地の紙を刷ったもの）
- 黒江いとは**日曜の朝に看板を撮りに出る。** 朝いちばんの光だと剥げが分かる
- 餃子のひだは、あんず六本、いと七本、なつ五本で大きい
- 柏湯は瓶の牛乳を置いている。閉店時の売れ残り本数は日によって違う
