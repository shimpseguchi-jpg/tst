# 小説執筆（汎用版）

小説を一章ずつ書くための工程と、書き方の規則。
特定の作品の設定は持たない。**作品ごとの決まりは、作品の `設定.md` に書く。**

**書くことに関する規則の正は、このファイルである。**
`CLAUDE.md` には要点だけを置いて、ここを指す。二か所に同じことを書くと、片方だけ古くなる。

## ファイルの置き方

| | どこに書くか |
|---|---|
| 書き方の規則 | **このファイル** |
| 世界の事実（年表・人物・場所・言葉の決まり） | プロジェクトの世界設定ファイル（例：`世界設定.md`） |
| その作品だけの決まり（分量・速さ・視点・封印・禁止） | 作品フォルダの `設定.md`。**このファイルより優先する** |
| 章ごとの筋 | 作品フォルダの `プロット.md` |
| 書いた章の要約と、既出の表現 | 作品フォルダの `あらすじ記録.md` |
| 既刊を直した履歴 | `直した記録.md`（一件ずつ） |

本文ファイルには、見出し以外のメタ情報（字数、注記、AIとしての言及）を書かない。

---

## 0. 書く前に、既刊で確かめる

**長い物語でいちばん多い事故は、文体ではなく事実である。**
取りちがえは、書く前に本文を開けばほとんど避けられる。

**書き出す前に、出す人・出す場所・出す日ごとに、次の五つを本文で確かめる。**
設定ファイルの要約ではなく、**その人が出てくる既刊の本文**を開く。要約は、書いた人の解釈である。

1. **言葉**——その人は、その相手に、どの言葉で喋るか（方言／標準語／敬語／呼び方）。
   **相手と場所で変わる人がいる**
2. **場所**——そこに何があるか。その時点で存在しているか、なくなったあとか
3. **日**——その曜日・時刻に、その場所は開いているか、その人はそこにいられるか。
   その日に既刊で何が起きているか（年表）
4. **出来事**——既刊が書いた場面の続きや裏を書くなら、**その場面の本文を最後まで読む。**
   誰が何を持っていて、誰が何を言ったか
5. **年齢と関係**——その時点で何歳か。誰と誰がどういう関係で、互いをどう呼ぶか

**確かめたことは、その作品の `設定.md` に「既刊から動かせないもの」として書く。**
書いておけば、次に書く人が同じ本文を開かなくて済む。

### 時系列を進めすぎない

既刊の時間の中に新しい話を入れるときは、**空いている時期を年表で探して、そこへ置く。**
いちばん新しい日付より先へ延ばすと、全員の年齢と年数が動く。先へ行くなら、書く前に作者に確認する。

## 1. 分量

**一章の長さは作品の `設定.md` で決め、篇をまたいでそろえる。**決めていなければ、三千字前後（二千七百〜三千四百字）を既定にする。

| | |
|---|---|
| 守る幅 | `設定.md` に書いた幅 |
| 下げる・上げるとき | `設定.md` に**理由を書いたときだけ** |

**この規則は、少しずつ破られる。**新しい作品の分量を決めるたびに前の作品より少し低く置くと、
一篇ずつ測ればどれも目標の内側なので、気づかない。**作品をまたいで一章あたりを並べて見る。**

- **一発目から目標字数で書く。**短く書いて後から加筆しない。
  加筆で足した文は、密度と呼吸が本文と合わない。**書き出す前に章を場面に割り、場面ごとにおよその字数を配る**
- **初稿は目標の上のほうを狙う。**書き手は短く書きがちである。足りないと分かってから水増しするより、場面を一つ多く用意しておく
- 当該章のプロットから始め、前章末尾の動作を受ける
- 一度描写した設定・人物・場所を、以後の章で再説明しない
- 設定に無いディテールは判断で補ってよい。**補ったものは `設定.md` に追記する**
- 予測可能な展開を避ける。ただしプロットの骨は動かさない。
  裏切るのは章内のディテール（誰が何を言うか、どの動作で閉じるか）であって、構造ではない

## 2. 速さを、数で置く

**速さは好みではなく、その作品の中身である。**二人が喋りつづける話は速く、一人で過ごす話は遅い。

**書き出す前に、`設定.md` の「文体の目標」を見る。無ければ先に置く。**
速さを決めずに書きはじめると、その章は**直前に書いた作品の速さ**で出てくる。

### 十二の数

| 数 | 測り方 |
|---|---|
| 地の文の文 | 地の文だけの、一文の平均字数 |
| 長文 | 四十字を超える文の割合 |
| 一行の文数 | 地の文の一段落（一行）に、文がいくつ入っているか |
| 地の一行 | 地の文の一段落の平均字数 |
| 地の連（字） | 台詞をはさまずに続く地の文の塊の、平均字数 |
| 地の連（行） | 同じ塊の、平均段落数 |
| 会話字 | 本文のうち、台詞が占める**字数**の割合 |
| 会話行 | 本文のうち、台詞が占める**行数**の割合 |
| 会話一行 | 台詞一行の平均字数 |
| 会話の連（行） | 地の文をはさまずに続く台詞の、平均行数 |
| 読点 | 何字に一つ読点があるか |
| 場面 | 一章あたりの場面の数（場面の区切りで数える） |

### 行で数えない。字で数える

　台詞の行は十字前後、地の文の行は二十五字前後ある。**行の数は量を表さない。**
　会話行が半分を超えていても、字で数えると三分の一で、三分の二は地の文、ということが普通にある。
　読む人が感じるのは字のほうなので、迷ったら「会話字」を見る。

**文の長さも、地の文だけで測る。**台詞を混ぜると短く出る。

### 速い作品と遅い作品

**どちらが正しいということはない。その作品が狙った速さから外れていないかだけを見る。**

**速い作品は、つないで作る。ただし一文ずつは短くしない。**
速い作品でも、本文の三分の二は地の文である。減らすのではなく、切り方が違う。
一行に文を二つ近く入れ、そのつないだ行を二つか三つ重ねて百字前後。**そこで必ず誰かが喋る。**

| 何をしている文か | どうするか |
|---|---|
| 説明・描写 | **つなげる。**句点で切っていたものを `〜て、` `〜で、` `〜が、` でつなぐ |
| 落とす・突っ込む | **短いまま。**短いところが芸である |

- 四十字を超える文は少なく（数％まで）。十四字を十八字にするのであって、三十字にはしない
- **つなげたぶん、読点を足さない。**つなぐときは、まず読点なしで書いてみる

**遅い作品**は、地の文を三百字続けてよい。一行はむしろ短くする（一行一文に寄せる）。
**「地の文が多い」と「遅い」は別である。**多いまま速くできる。

**一人の章は、速い作品の中でも地の連が伸びる。**割って入る人がいないからで、速さが落ちたからではない。
一人の章に、幅を合わせるための台詞を入れない。作品ぜんたいの目標を少し広く取って、理由を `設定.md` に書く。

### `設定.md` に置く形

数は決め打ちせず、**近い既刊を測って決める。**

```
## 文体の目標

| | 目標 |
|---|---|
| 地の文の文 | 16–19 字 |
| 長文 | 2 %以下（四十字を超える文） |
| 一行の文数 | 1.8–2.3 文 |
| 地の一行 | 32–42 字 |
| 地の連（字） | 90–140 字 |
| 地の連（行） | 4 行以下 |
| 会話字 | 18–30 % |
| 会話行 | 40–60 % |
| 会話一行 | 8–13 字 |
| 会話の連（行） | 2.5 行以上 |
| 読点 | 26 字以上あける |
| 場面 | 5–8 ／章 |
```

**目標と本文が食い違ったら、どちらが古いかを考える。**本文のほうが良ければ、直すのは `設定.md` である。
**一章では外れてよい。作品でそろえる。**導入の章は遅く、山の章は速い。これは事故ではなく作りである。

## 3. 表記

作品ごとに決めて `設定.md` に書く。決めていなければ、次を既定にする。**一つの作品の中では必ずそろえる。**

| | 既定 | 例外 |
|---|---|---|
| ダッシュ | 「――」（U+2015 を二つ） | 「——」（U+2014）と混ぜない |
| 三点リーダー | 「……」（二つ組） | 「…」「・・・」「...」は使わない |
| 数字 | 縦書きの文芸なら漢数字 | 規格名・型番／作中の書類・メモ・札の写し |
| 時刻（地の文） | 二十四時間制 | |
| 時刻（台詞） | **その人が言うとおり** | 人は「十五時」とは言わない |

　地の文と台詞で時刻が食い違って見えるが、食い違っていない。**地の文は測る側で、台詞は喋る側である。**

**規則と、本文と、測る道具の三つが同じことを言っているかを確かめる。**
規則を変えたら、道具も変える。道具だけが古い規則で数えていると、誰も気づかない。

## 4. 書きながら守る形式

### 語り手を、章題の末尾に

**章ごとに語り手が替わる作品では、章題の末尾に（名前）を入れる。本文には書かない。**

```
# 第三章　十二月十九日　火曜の夜（名前）
```

一人称が多いと「わたし」が重なる。**誰が喋っているのかを読者に探させない。**
語り手が一人の作品（一人称一人、三人称一元）は要らない。

### 台詞と地の文

**いま目の前で交わされている会話は、独立行に置く。地の文に畳み込まない。**

- ×　彼女は「失礼します」と言って切った。（**いまの場面の一言**）
- ○　「失礼します」／　そう言って、彼女は切った。

**畳み込んでよいのは、次の三つだけ。**

| | 例 |
|---|---|
| **回想・伝聞**（いまここで交わされていない） | 中学のとき、隣の子に「粉ふいてる」と言われた |
| **仮定**（まだ起きていない） | 聞いて、櫛を置いて、それから「そうねえ」と言う。そこで終わる |
| **看板・書類・単語の引用** | 第一希望の欄に「映画」と書いた |

禁じるのは、**会話を並べるのを面倒がって地の文に押しこむこと**だけである。回想と仮定の畳み込みは技術である。

- セリフでは助詞・接続詞を省略しない。**ただし方言と口語の自然さが優先される**
- 複数の人物を扱うとき、人物ごとのセクション分けをしない。ひと続きの描写に統合する
- 体型・外見に触れるときは、作品の対象年齢にふさわしい自然な語を使う。性的な強調をしない（どこまで書くかは `設定.md` に明記する）
- **章の終わりは、感慨ではなく物か動作で閉じる**

### 読点

**読点は放っておくと増える。**作品を重ねるごとに密度が上がっていく。

**二十字に一つを切ったら多い。**目標そのものは `設定.md` が決める。

増える原因は、ほぼ一つ。**「〜は、」である。**

- ×　彼女は、そこで足を止めた。　○　彼女はそこで足を止めた。

**主語が短く、述部も短く、対比もないとき、この読点は要らない。**
残してよいのは、主語が長い／間を置きたい（一章に数回まで）／対比がある、の三つ。
主語は固有名詞とはかぎらない——**短い語＋は／が**の形で見る。

**動作をつなぐだけの `〜て、` は落とせる。**ただし次の四つは落とさない——
三つ以上の列挙／理由・条件の節／逆接／後ろに別の主語が立つとき。
落としたあと、読点なしで三十八字を超える文ができたら、一つ戻す。

## 5. 人物を芸にしない

**長い物語がいちばん壊れやすいのは、人物が一芸に縮むところである。**

### 三つの禁止

1. **一作品につき、一人の癖は一回まで。**二回目からは別の面を出す。
   出す面がないなら、人物ごとに「まだ書いていない面」を三つずつ用意した表から取り、使ったら表から消して新しい面を足す
2. **地の文で性格を説明しない。**「この人は〜する人だ」「十年、そうしている」は書かない。
   **感情の直接説明と同じ扱いにする。**行動だけ書いて、説明を足さない
3. **字数・温度・秒数のような数を、地の文が申告しない。**本人にも他人にも数えさせない。
   **数で測る癖のある人物ほど、数えないで済ませる場面を作る**

### 軸は組に付ける。人に付けない

**軸（方言・文の長さ・敬語・断定・伝聞か典拠か、など）は、同じ場面にいる二人の声を割る道具である。性質ではない。**

- **同じ人が、二つの組で同じ軸を使わない。**組を新しく作るときは、軸も新しく作る
- **一人につき、軸の振れている側に立つ組が最低一つ要る。**どの組でも振られる側なら、それは役である
- **三人以上の場面では軸を立てない。**誰が喋ったかは、言い方ではなく**何に口を出したか**で分かるように書く
- **一人の場面には軸がない。**そこが、その人の素の声の出る唯一の場所である

**軸と、変わらない言葉を混ぜない。**相手が替わっても変わらない言葉（いつも方言、いつも敬語）は人の属性で、組の物差しには使えない。

### 役割を剥がす

人物は職業や居場所で呼んでよい。**やめるのは、その人の用事を、いつも職業の用事にすることである。**

1. **勤務表や定休日で人を選ばない。**動く理由は職場の外から——病院、役所、家族、金、約束、乗りもの、天気
2. **一作品につき一人、職場にいないところで出す。**誰にも見られていない時間に何をしているか（「一人のとき」）を人物ごとに用意し、一作品に一人ぶんだけ使う。説明しない。全員ぶん並べない
3. **職は奪わない**

### 休ませる

**同じ癖が続いたら、何作品か出さないと決めて、`設定.md` か世界設定に書いておく。**
続けて出したかどうかは、一作品の中では分からない。作品をまたいで見る。

## 6. 封じるものは、一つに絞る

**説明しない文体は、説明しないことが癖になる。**

> **隙間は、読者が埋める。別の話で埋める。**

封じたものは効くが、**書き忘れたものは、別の話になって返ってくる。**

| | |
|---|---|
| **出来事** | **書く。**誰が、どこで、何をしたか |
| **その出来事の意味する事実** | **書く。** |
| **その人の気持ち・理由** | **書かない。**ここだけが封印である |

**一作品につき、封じるものは一つ。**`設定.md` に「封じるもの」として書く。

**点検**——その章だけを、外を知らない人が読んだつもりで一度読む。起きたことを言い直せないなら足りない。
足すのは**事実であって、気持ちではない。**「あとで分かる」で先送りしない。

## 7. 使わない言葉

生成段階で選ばない。**言い換えた痕跡を本文に残さない。**
**禁じるのは用法であって、語ではない。**語で禁じると、正しい日本語まで消える。

| | 禁じる | 禁じない |
|---|---|---|
| 口癖 | `めっちゃ` `ヤバい` `ぶっちゃけ` `てゆうか` `何！？` | （人物の台詞として設定.md で許したもの） |
| 「的な」 | 仮名のあとの口癖（`ゆるい的な`） | 合理的な、一般的な、目的なので |
| 「まるで」 | `まるで〜のような` の手垢のついた直喩 | まるで気持ちが入っていない（＝全然） |
| 「〜すぎる」 | 強調の口癖（`かわいすぎる`） | 言いすぎる、重くなりすぎる（量を言う） |
| 感情の既製品 | `ドキッとした` `胸が締めつけられた` `涙が溢れた` | |
| 擬音 | `ドキドキ` `ワクワク` `ゾクッ` の多用 | |
| 言い直し | `〜かもしれない、いや、〜だ` | |
| 直接説明 | `彼女は悲しかった` | |

赤くなった、泣いた、といった身体に出たものは、**色と場所と時間（向き）で書く。**感情の名前で書かない。

## 8. 点検

### 機械で数える

測る道具があれば使う。なければ、次を数える道具を作る。

| 種類 | 中身 | どうするか |
|---|---|---|
| **違反** | 章の字数／語り手の表記／ダッシュ／三点リーダー／算用数字／使わない言葉／読点の下限 | **〇にする** |
| **要確認** | いまの会話の畳み込み／性格の説明／数の申告／地の文の十二時間制 | **読んで決める。**〇にしなくてよい |
| **速さ** | §2 の十二の数を、`設定.md` の「文体の目標」と照らす | 外れた行を見る。章ではなく作品でそろえる |

**要確認を全部消そうとしない。**「この人は二階にいる」は性格の説明ではない。

### 反復を見る

前章までと照らして——同じ文型の連鎖、同じ比喩・同じ語彙の再使用（`あらすじ記録.md` を検索する）、
セリフの受け方と間の取り方の反復。**`設定.md` が「反復モチーフ」に指定したものは除く。**

### 目で見る

- 三人以上の場面で、全員に軸が立っていないか
- 一人の場面で、軸が鳴っていないか
- この作品で、職場にいないところを一つ書いたか
- §0 の五つを、出した人と場所と日について確かめたか

### 読者ペルソナ（初稿は出力しない）

書き上げたら、必ず四人に読ませてから最終稿にする。修正はレビューの痕跡を残さず、文全体を調整して行う。

| | 好むもの | 嫌うもの |
|---|---|---|
| **A**（作者） | 文法の正確さ | パターン化した展開、前章との重複、設定の急な変更 |
| **B**（抑制を好む読者） | 抑制、行動から察すること、長い静かな場面 | 説明、泣かせ |
| **C**（この作品から読む人） | その場で分かる固有名詞、一作品で完結すること | 前作を知らないと分からない書き方 |
| **D**（速さで読む人） | 台詞の応酬、笑うところ | 続く地の文、同じ調子が三場面 |

**BとDは正面から対立する。**どちらを重く見るかは `設定.md` の「文体の目標」が決める——遅い作品はB、速い作品はD。

**`設定.md` の禁止事項と衝突する指摘は採らない。**それ以外は反映し、強みは伸ばす。

## 9. 既刊を書き直すとき

### 書き直すもの、動かさないもの

| 書き直す（書き方） | **動かさない（事実）** |
|---|---|
| 文の切り方・つなぎ方・読点 | **年表の出来事、日付、曜日、時刻** |
| 一章の長さ（足りなければ足す） | **人物の名前・年齢・関係・言葉** |
| 表記 | **作中の数字** |
| 地の文の性格説明、数の申告 | **台詞の中身**（言い方は整えてよい。言ったことは変えない） |
| 畳み込まれたいまの会話 | **封印**（書かなかった気持ち・理由は、書き直しでも書かない） |
| 足りない事実（§6） | **結末と、最後の一行** |

書き直しで足りない事実が見つかったら、足してよい。ただし**別の作品が同じ事実を書いていないか**を先に確かめる（§0）。足したものは `設定.md` に書く。

### 矛盾を見つけたら、直す

**完成済みの本文は金庫ではない。**

| | どうするか |
|---|---|
| **大きな矛盾**（筋・人物・言葉・場所・日付・数が、二つの本文で食い違う） | **直す。**多数派に合わせる。直す前に `直した記録.md` に一件書く |
| 小さな揺れ（言い回し、呼び方の一回だけのぶれ） | 書き直しの中で揃える |
| 人物が言いまちがえている（本文の中で本人の記憶ちがいとして書いてある） | **残す。** |

> **人がまちがえたのなら残す。こちらが取りちがえたのなら直す。**

**直すのは、いま書き直している作品とはかぎらない。**前の作品が少数派なら、前の作品を直す。

### 手順（一作品ずつ）

1. **前を測る。**違反と速さの数を記録する
2. **既刊で確かめる。**§0 の五つ。その作品に出る全員・全場所・全日付について
3. **`設定.md` に「文体の目標」が無ければ置く。**今の数を測って、そこを起点に寄せる。**速さは変えない**
4. **一章ずつ書き直す。**§1〜§7 で。一章ごとに速さを見る
5. **後を測る。**違反が〇になったこと、速さの外れが増えていないことを見る
6. `あらすじ記録.md` を合わせる
7. コミットする。**一作品につき一コミット**

---

## 10. 章を書き終えたら

1. 字数を測る。`設定.md` の幅に入っているか
2. 速さを測る。外れた数を見る（章では外れてよい。作品でそろえる）
3. 点検。違反を〇に
4. `あらすじ記録.md` に二百字の要約と、既出の表現を足す
5. 補ったディテールを `設定.md` に足す
6. コミットする
