## 筋

　付き合いはじめて七週間の二人の、二度目の休みの日。黒江いとが、史跡を巡る順路を組んでくる。
　条件は三月二十四日と同じ——**「三段目より上じゃないところ」**。
　郷土資料は図書館の二階にあるので、黒江が平日の昼に一人で上がって、写真に撮ってきた。

| 二 | 昼 | 蓮見すず | 東の縁の円墳。すずは石段を上がらず、裾を一周する。農家の犬と黒江。説明板 |

## 封じるもの（一つだけ）

**黒江いとが犬をこわがる理由。**こわがったことは書く。黒江は説明する人なのに、ここだけ説明できない。本人も言わず、すずも聞かない。

| 一九七二年の水の線 | 理容室つかもとの裏口の柱。地面から四十センチほどのところに、鉛筆の線と『昭和四七・七』。律子の父が引いた。水は床の下まで（郷土史の「南半分が床下まで」と合わせた） |

| 山城跡の登り口 | 北の山の麓。木の標識『城跡まで二十分』。その横に柏の木が三本 |

## 人を芸にしない

| | |
|---|---|
| 黒江の長い説明 | **一回だけ全部書く**（一章、碑の字）。あとは途中で切る |
| 蓮見の「長いです」 | **一回だけ** |
| まだ書いていない面 | 黒江「犬がこわい」（説明する人が、説明できない一点）、蓮見「道具を貸さない」は使わない |
| 塚本律子 | 一章で一度だけ。事実だけ言って黙る |
| 休ませる | 蓮見・黒江の字数申告は出さない。蓮見が歩数を数えない（「数えていません」） |
