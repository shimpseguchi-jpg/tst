## 曜日の確認

　二〇三六年二月十二日は火曜（作品18）。三月六日は木曜（幕間09）。**二〇三六年は閏年。**

```
2/18月 19火 20水 21木 22金 23土 24日 25月 26火 27水 28木 29金
3/1土 2日 3月 4火 5水 6木 ... 13木 ... 19水 20木 ... 24月 25火 26水
```

- **二月二十三日は、その月の第四土曜。**沖田ちさとの休みが第二と第四だけなので、ここしかない
- 申請の締切は**三月十三日（木）**
- 水曜の夜は八番地に六人が集まる日。**二月二十日・二十七日、三月五日・十二日・十九日・二十六日**

## 久世藍と芦原まひるが断る（この一篇で足したところ）

　**二人を同じ理由で断らせない。**同じ理由なら、一人でよかったことになる。

| | 断り方 | 理由 |
|---|---|---|
| **久世 藍**（銀星座支配人・三十九歳） | **にべもない。**三往復で終わる | **映す人である。**撮る人でも編む人でもない。**一度も自分で撮っていない**（作品14 で『きい』を十分かけた側） |
| **芦原 まひる**（二十八歳） | 断るが、長い。**手は貸さないが、話はする** | **映画には双方向性がない。**作って、届くまでに間があって、**返ってくるものがない。**それでやってきた人なので、返ってくる前提のものを教えられない |

- **久世は理由を説明しない。**説明しないことが、この人の断り方である
- **まひるは説明する。**説明したうえで、できないと言う。**同情しない**
- 餃子会は納得する。**食い下がらない。**ここで粘ると、人に店の用を押しつける話になる
- **「今度、包みに来てね」。**断られた側が誘う。
  餃子会にとっては親愛の証で、言われた側には意味が分からない。**意味は本文で説明しない**

## 音だけ・二時間（決まった形）

| | |
|---|---|
| 録る | **水曜の夜、二十時ちょうどから二時間。**八番地の厨房。包む手は止めない |
| 台本 | **ない。**原稿があるのは、おたよりを読む四十秒だけ |
| 切る | **切らない。**三回とも切っていない、を二時間でも通す |
| 出す | **配信に二時間そのまま（音だけ）。**画は一枚も動かない |
| 通り | **昼の十二時から一時。**十七曲の上に乗せる。**曲は一曲も消えない**（マイク入力で下がるだけ） |
| おたより | **柏湯の番台の木箱**と、十四番地がやっている頁 |

　**二時間を一度に通りへ流すことはできない。**十二時から一時までの一時間しかないからで、
　**週のうち四日に分けて、前半と後半を二回ずつ流す。**金曜はいつもの十七曲に戻る。

　**十七曲は一曲も消さない。**森岡佑が七年守ってきたのは「止めないこと」である。
　上に乗せるだけなら、止めなくていい。**タイマーの爪には、この一篇でも触らない。**

## 終わり方

　**数えない。**

- 緩い喋りが、思ったより聞かれたらしい。**らしい、で止める**
- **客が増えたかどうかは、誰も知らない。**数えていない
- 増えた気がする。声をかけられることも増えた気がする。**気がする、を直さない**
- **この連作は、効果を測らない。**測ると、測れないものが落ちる

## 森岡佑の書き方（動かさない）

- 一人称は**わたし**。地の文は常体・である調。**方言を使わない**
- **人を名簿の表記で呼ぶ。**「十二番地」「日下部さんとこの娘さん」「八番地」。十二年、これで通している（幕間08）
- 悪い返事を言うときに声を落とさない
