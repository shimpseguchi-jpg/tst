## 久世藍と芦原まひるが断る（この一篇で足したところ）

　**二人を同じ理由で断らせない。**同じ理由なら、一人でよかったことになる。

| | 断り方 | 理由 |
|---|---|---|
| **久世 藍**（銀星座支配人・三十九歳） | **にべもない。**三往復で終わる | **映す人である。**撮る人でも編む人でもない。**一度も自分で撮っていない**（作品14 で『きい』を十分かけた側） |
| **芦原 まひる**（二十八歳） | 断るが、長い。**手は貸さないが、話はする** | **映画には双方向性がない。**作って、届くまでに間があって、**返ってくるものがない。**それでやってきた人なので、返ってくる前提のものを教えられない |

- **久世は理由を説明しない。**説明しないことが、この人の断り方である
- **まひるは説明する。**説明したうえで、できないと言う。**同情しない**
- 餃子会は納得する。**食い下がらない。**ここで粘ると、人に店の用を押しつける話になる
- **「今度、包みに来てね」。**断られた側が誘う。
  餃子会にとっては親愛の証で、言われた側には意味が分からない。**意味は本文で説明しない**

## 音だけ・二時間（決まった形）

| | |
|---|---|
| 録る | **水曜の夜、二十時ちょうどから二時間。**八番地の厨房。包む手は止めない |
| 台本 | **ない。**原稿があるのは、読み上げの段の三分（四百字）だけ。おたよりへの返事は、そのうちの四十秒 |
| 切る | **切らない。**三回とも切っていない、を二時間でも通す |
| 出す | **配信に二時間そのまま（音だけ）。**画は一枚も動かない |
| 通り | **昼の十二時から一時のうち、前の三十分。**十七曲の上に乗せる。**曲は一曲も消えない**（ディップスイッチの三つ目を倒して、下げない設定にする） |
| おたより | **柏湯の番台の木箱**と、十四番地がやっている頁 |

　**二時間を一度に通りへ流すことはできない。**乗せるのは一日三十分までと、森岡が三月三日に窓口で言った。
　**水曜の夜に録った二時間を、翌日の木曜から四日（木・金・月・火）に分けて、一日三十分ずつ流す。**水曜は次を録るので流さない。

- **読み上げの段（三分）は、二時間のはじめから二十分ほどのところに入る。**最初の十分は誰も喋らないので、十二時に押すと、十二時二十分に読み上げが来る
- **三月五日に録った一本目は、八日待たせて三月十三日から流した。**流しはじめる日を申請の日に合わせたため
- **三月十二日の水曜は録っていない。**一回目が流れる前に二回目を録ると、返事の来ないまま二回目になる
- 二本目は三月十九日に録って、二十日から。三本目は三月二十六日

　**十七曲は一曲も消さない。**森岡佑が十二年守ってきたのは「止めないこと」である。
　上に乗せるだけなら、止めなくていい。**タイマーの爪には、この一篇でも触らない。**

## 終わり方

　**数えない。**

- 緩い喋りが、思ったより聞かれたらしい。**らしい、で止める**
- **客が増えたかどうかは、誰も知らない。**数えていない
- 増えた気がする。声をかけられることも増えた気がする。**気がする、を直さない**
- **この連作は、効果を測らない。**測ると、測れないものが落ちる

### 目標を本文に合わせた理由（二〇二六年十月・第三版で仕上げるとき）

　再編したとき、目標は見当で置いた（一行の文数 1.6–2.3、地の一行 28–40、場面 4–8）。
　測ると、本文は**一行の文数 1.5、地の一行 25 字、場面 9.6**だった。
　**元の三篇は一行一文に近い書き方で、そこが森岡佑の章の声である。**
　「来るのは、市の封筒である。」「断れない理由は、四十メートルである。」——一行に一つ置いて、次の行で受ける。
　場面が多いのは、行頭の「――」で場面を起こす書き方だからで、一章に八〜十ある。
　**書き直しでは速さを変えない**（スキル §9）。直すのは目標のほうである。

　**地の文の時刻は二十四時間制。**台詞は変えない。
　章題の末尾に（名前）を入れる。**本文には書かない。**
