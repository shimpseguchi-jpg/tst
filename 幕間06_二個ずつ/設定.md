# 幕間06『二個ずつ』設定

連作の幕間・六本目。**全三章。各章三千四百字。およそ一万字。**
作品16『三段目』第十一章の、四日あとである。

- **時期**　**二〇三五年三月二十八日（水）の夜から、二十九日の三時まで**
- **視点**　第一章が蓮見すず、第二章が宮地あんず、第三章が山根とも。全部一人称
- **場所**　八番地・福来軒の厨房と、ランドリーぎんてん

## 0. この幕間で起きること

　**黒江いとと蓮見すずが、水曜の厨房で報告する。**
　付き合うことになったのは三月二十四日（土）である。四日たっている。

　あんずの水曜は二〇三三年九月から続いていて、一年七か月目になる。
　来られる者が来る。全員が毎週来るわけではない。

　**幕間05 と同じ形の夜にする。** あのときは山根ともが自分から言った。
　**今度は、言われる側にともがいる。**

## 1. 笑いと甘さの出どころ（四つ。それ以外で取らない）

1. **黒江いとが二分喋って、肝心なところを言い忘れる。**
   前置きと経緯と踏切と看板の話をして、何の話か分からないまま止まる。
   **蓮見すずが一行で言う。**「付き合うことになりました」
2. **蓮見が「付き合う」という言葉を、五人の前で初めて使う。**
   二人のあいだでは一度も使っていない。
   **五人に分かる言い方をしないと、何の話か分からないからである。**
   ——**これは幕間05 第二章で山根ともがやったことと、まったく同じ理屈である。**
   本文では突き合わせない。**読者にだけ分かる形にする**
3. **宮地あんずの手が止まらない。** 五人のうち、あんずだけ止まらない。
   一年三か月前に一度、同じ形の夜をやっているからである
4. **矢部さえが驚かない。** 五人のうち、いちばん早く「おめでとうございます」と言う。
   ——**質問を一つもしない。** あんずがそれを数える。
   **理由は書かない。**（`資料/さえとるり_裏記録.md` の二〇三四年一月二十八日）

## 3. 第二章で動かす数

- 水曜の夜は百二十個を包む。三月二十八日は六人で包む（宮地・日下部・黒江・蓮見・矢部・山根）
- **あんずは、いつも焼くのを六個（一人一個）にしている。** 二〇三三年九月七日からそうしている
- **この日だけ、十二個焼く。一人二個である。** 百二十から十二を引くと百八になる
- **数は合う。** 作品13 第十章で、食べたものを数に入れ忘れて百十四になった。
  あれ以来、あんずは食べたぶんを先に引く。**今度は合う**
- **合ったのに、紙を貼る。**
  冷蔵庫の紙は「数が動いた日」にだけ書く決まりである。値が変わった日、人が替わった日、
  数が合わなかった日。**一人一個が一人二個になった日は、数が動いた日である。** 七枚目

## 4. 第三章で動かすもの

- **山根ともは、沖田ちさとの名前の読み方を、一年四か月間まちがえている**（幕間05 第二章）。
  二通りに読める四文字で、聞いていない。**十月二十五日に自分が「言わんでええ。書いて」と言った**
- この夜、初めて聞く。**きっかけは、他人が口に出すのを見たことである**
- **ちさとは声に出さない。** かわりに**もう一度紙に書く。今度は読みをかなで振る。**
  ——**書くのは許されている。言うのはまだできない。**この線は崩さない
- **ともが、正しい読み方で声に出す。**「別の人みたいじゃ」「同じです」
- **一年四か月前に自分が五人に言ったことの意味が分かる。**
  あれを「練習」だと思っていた。練習というのは、あとで本番がある言い方である。
  **本番は来なかった。来なかったのは、あれが本番だったからである**

## 5. 声

| | 文の特徴 |
|---|---|
| 蓮見 すず | 一文が短い。数字が先。**四十二字を超えない**（作品16で確定。崩さない） |
| 宮地 あんず | 数字が先に来る。段落が短い。比喩を使わない。**数え直した回数を覚えている** |
| 山根 とも | 備後弁。一文が短い。説明しない |

**黒江いとは台詞だけで出す。** 語り手にしない。
二分喋る台詞を一つ置く。**そこだけ長くする**

## 6. やらないこと

- **［厳守］身体を性的な対象として描かない**
- **さえとるりのことを、地の文で説明しない。** さえに何も言わせない。質問をさせないだけにする
- **沖田ちさとを福来軒に出さない。** 宮地あんずと会わせない（作品10・11の約束）
- **沖田ちさとの本名を、地の文で読み上げない。** 読みも書かない。「その四文字」のまま
- **あんずが白詰ねむを聞いていることを、黒江・蓮見・矢部に知らせない。**
  知っているのは日下部と山根だけである
- 事件を起こさない。**誰も泣かない。** 泣かせにいく文を書かない
- 「三年」「一年七か月」を、登場人物に総括させない
