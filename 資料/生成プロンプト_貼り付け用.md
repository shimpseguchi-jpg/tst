# 生成AIに貼り付ける用　一枚絵（十五人）

`生成プロンプト.md` の前置きと差し替え文を、**一人ぶんずつ完成させたもの**である。
一つコピーして、そのまま貼る。**一度に一人だけ描かせる。** 二人以上は崩れる。

対象は語り手十四人と塚本律子。これで全十五篇の視点が埋まる。

- 出来たら縦長のまま保存する。ファイル名は気にしなくてよい。
- 取り込みは `python3 tools/絵を入れる.py`。名前もサイズも向こうで直る。

**滝沢篤子と橘ひなたは描かない。** 理由は `一枚絵_指定.md` の「描かないこと」にある。

## やり直す条件

出てきた絵が次のどれかなら、採らずにもう一度出す。一枚目から通ることは少ない。

| | 直し方 |
|---|---|
| こちらを見ている | 「横顔にする」「視線を手元に落とす」を足す |
| 笑っている | 「無表情」「口を結ぶ」を足す |
| 色がついている | 「鉛筆だけ。モノクロ」を先頭に置き直す |
| **年齢が上に出た** | 学年を書き、「大人にしない」「幼さを残す」を足す |
| **看板や貼り紙の字が化けた** | 「文字を描かない」を足す（末尾に入れてある） |
| 指定した場所になっていない | 何がどちら側にあるかを、構図として書き足す |
| **昭和の絵になった** | 前置きの「現代」の段落を消さない。服と髪と持ち物を見る |

下の四つは、実際に矢部さえの一枚目と二枚目で順に起きた。
**日本固有の構造（番台、暖簾、下足箱）はまず通らない**と思っておく。

**最後の一つがいちばん質が悪い。** 絵として整っていて、指定もおおむね守られているのに、
時代だけが違う。この連作は二〇二六年から二〇三三年の話で、
**いま潰れつつある商店街の話であって、懐かしい日本の話ではない。**
