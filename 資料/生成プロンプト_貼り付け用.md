# 生成AIに貼り付ける用　一枚絵（十五人）

**人物画である。情景を描かせない。** ひとり、腰から上、背景なし。
`一枚絵_指定.md` 第三-〇項と、`生成プロンプト.md` のB表を組んだもの。
一つコピーして、そのまま貼る。**一度に一人だけ描かせる。**

対象は語り手十四人と塚本律子。これで全十五篇の視点が埋まる。

- 出来たら縦長のまま保存する。ファイル名は気にしなくてよい。
- 取り込みは `python3 tools/絵を入れる.py`。名前もサイズも向こうで直る。

**滝沢篤子と橘ひなたは描かない。** 理由は `一枚絵_指定.md` の「描かないこと」にある。

## やり直す条件

一枚目から通ることは少ない。次のどれかなら採らずにもう一度出す。

| | 直し方 |
|---|---|
| こちらを見ている | 「横顔にする」「視線を手元に落とす」を足す |
| 笑っている | 「無表情」「口を結ぶ」を足す |
| 色がついている | 「鉛筆だけ。モノクロ」を先頭に置き直す |
| 年齢が上に出た | 学年を書き、「大人にしない」「幼さを残す」を足す |
| **背景を描いた** | 「背景を描かない。紙の白のまま」を足す。**これが時代崩れの入口である** |
| 昭和の絵になった | 前置きの「現代」の段落を消さない。服と髪と持ち物を見る |
| 手が切れている | 「腰から上。手が入る高さで切る」を足す |

**手を描かせる。** この連作の人物は手でできている。
律子の鋏、なつの粉、あんずの包む指、ともの朱と黒、藤木のノート、いとの筆。
顔だけの絵にすると、十五人が誰だか分からなくなる。

---

## 英語で出したいとき

前置きだけ差し替える。差し替え文は日本語のままでも通る。

```
Pencil drawing, 2B-4B graphite, monochrome, no color.
Searching overlaid construction lines left visible, not cleaned up.
Hatched shading; eraser-lifted whites used as light. Visible paper tooth.
Not anime line art. Quiet, observational figure drawing.

A single figure, waist up, hands included in frame. Aspect ratio 4:5.
No background at all — bare paper. No floor, no wall, no furniture.
The only props are what the hands are holding.

Present day, Japan, 2020s. Not Showa-era, not retro.
Clothing, hair and objects are contemporary. No sepia, no aged paper.
```

末尾は次を足す。

```
Critical: no eye contact with the viewer. No smile. No heightened emotion.
Not warm or sentimental. No color. No text. No background.
```
