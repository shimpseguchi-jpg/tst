# まだ書いていない面

　人物が一芸に縮んだときに、ここから取る。

　**一人につき三つ。どれも、その人の「軸」とは関係がない。**
　軸（方言・文の長さ・敬語・断定・数・温度）は、同じ部屋にいる二人を割るための道具であって、
　その人の中身ではない。中身はもっと雑然としている。

　**使ったら、この表から消して、消した先を書き足す。**

## 番外で先に出したもの（本編ではまだ使える）

　番外は正史ではないので、表からは消していない。ただし、**一度は書いた形がある。**
　本編で使うときは、番外と同じ出し方をしない。

| 誰 | 面 | どこ |
|---|---|---|
| 日下部なつ | 字が下手／名前を覚えるのが速い | 番外十六（メイド喫茶） |
| 宮地あんず | 音を入れない | 番外十六 |
| 黒江いと | 黙るときがある | 番外十六 |
| 蓮見すず | 書くと長い／道具を貸さない | 番外十六 |
| 矢部さえ | 縫える | 番外十六。**幕間09 で使った三つとは別である** |
| 山根とも | 甘いものを大量に食べる／歌を覚えている | 番外十六 |

## 使い方

1. 書いている人物が二回目に出てくるところで、**軸を使いそうになったら、ここを見る**
2. 一つ使ったら、**表から消して、新しい面を一つ足す**
3. **新しい面は、その人の仕事と関係のないものにする。**
   仕事の話にすると、また軸に戻る

## 覚え書き

- **面は、説明しない。**「この人は犬がこわい」と書かず、犬のいる場面で回り道をさせる
- **一篇に二つまで。**三つ出すと、今度は面のほうが芸になる
- **矛盾してよい。**喋る人が黙る、測る人が味を外す、決めない人が即決する。
  **矛盾したところが、その人のいちばん人らしいところである**
