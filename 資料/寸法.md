# 寸法

本編に一度も出していない。ここで初めて決めた。
**この連作で、からだは道具として出てくる。**
手のひらの幅で棚を測る人がいて、三段目より上に行けない人がいる。
だから、この表も**働く前提の数字**として並べる。

年齢は二〇三六年三月の時点。

## 手

　この連作でいちばん働く部分である。

| | 手のひらの幅 | 状態 |
|---|---|---|
| 宮地 あんず | 十五・五センチ | 指の腹が硬い。冬でもひび割れず、かわりにふやける |
| 日下部 なつ | 十八センチ | 厚い。**熱いものを持てる。**左の親指の腹に窯の火傷 |
| 黒江 いと | 十六センチ | 細い。爪のあいだに白が残る。**脚立の上で三十分立てる** |
| 蓮見 すず | 十六センチ | 紙で切った跡が指先に何本かある。数えていない |
| 矢部 さえ | 十四・五センチ | 湯気の中にいるので、冬でも荒れない |
| 山根 とも | 十六センチ | 甲に細かい傷。指の腹と爪のあいだに朱と黒。落ちない |
| 沖田 ちさと | 十五センチ | 何も残らない。**この人だけ、仕事の跡が手に出ない** |
| 森岡 佑 | 十八・五センチ | 紙で数えるので乾く。親指を舐めない |
| 三隅 るり | 十七センチ | 赤鉛筆の粉が中指の第一関節に付く |
| 沢渡 ふゆ | **十七センチ** | **九年前に自分で測った。**これで棚を測る |
| 藤木 かなえ | 十七センチ | 右の人差し指の第二関節が、少しだけ太い。書くほうではなく、押すほうである |
| 塚本 律子 | 十五・五センチ | 鋏を持つ手は震えない。**右肩が上がらない日が月に二、三日** |

　手のひらの幅は、**親指の付け根から小指の付け根まで**で測ってある。
　沢渡ふゆが二〇二七年に自分で測ったのが十七センチで、以後それを定規にしている。
　**同じ十七センチが、ほかに二人いる。** 三隅るりと藤木かなえである。
　二人とも、自分の手を測ったことがない。

## 肩

　二人、右肩が下がっている。理由が違う。

| | 下がり | なぜ |
|---|---|---|
| 藤木 かなえ | 一センチ | 鞄をいつも同じ側に掛ける。一年目に一度言われて、直していない |
| 沖田 ちさと | **五ミリ** | 机に向かう姿勢である。四年、同じ向きで喋っている |

　**沖田ちさとの五ミリを測った人が、一人いる。**
　測ったのは定規ではない。二〇三五年十一月十五日の夜である（作品17 第七章）。
　**本人は、いまも知らない。**

## 覚え書き

- **背がいちばん低いのは矢部さえで、いちばん高いのは森岡佑である。**
  二十七センチちがう。二人が並んだ場面は、幕間07 の一度だけである。
- **手のひらが十七センチの人が三人いる。** 沢渡ふゆ、三隅るり、藤木かなえ。
  三人とも、人の作ったものを見て直す仕事である。古本と、校正と、原稿。
  **自分の手で何かを測っているのは、そのうち一人だけである。**
- **仕事の跡が手に出ないのは沖田ちさとだけ。**
  この人の仕事は声で、声は跡が残らない。
  **残らないことが、この人が顔を出していない理由と、たぶん同じところにある。**
- **体重を測っている人は、十二人のうち三人しかいない。**
  矢部さえ（番台に体重計がある）、三隅るり（人間ドック）、塚本律子（病院）。
  あとの九人の数字は、**測ればそうなる、というだけのものである。**
