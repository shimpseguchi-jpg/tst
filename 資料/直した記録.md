# 直した記録

　**既刊の本文を直したら、ここに一件ずつ書く。**

　この連作は、完成した本文を金庫に入れない。広がりつづける前提で作っている。
　どうしても矛盾が出たときは、**過去の作品の側を直してよい。**
　ただし**直したことを覚えておかないと、連作は自分の履歴を失う。**だから台帳を置く。

---

## 直してよいとき

| | |
|---|---|
| **一** | 二つの本文が**事実として食い違っていて**、放っておくと読者が間違える |
| **二** | 片方が明らかに少数派である。**多数派の側に合わせる** |
| **三** | 直すのが**事実の一語か一文**で済む |

## 直してはいけないもの

- **好みで直すこと。**いまの文体が気に入らない、もっとうまく書ける、は理由にならない
- **封印を開けること。**滝沢篤子の顔、橘ひなたの五年、森岡が見てしまったもの、ほか
- **人物の関係と、結末**
- **軸**（`商店街連作設定.md`「書き分けの軸」）。四組の確定した軸は動かさない

## 直さずに残すもの

**どちらの本文も強いときは、直さずに記録する。**この連作には先にその作法がある。

- 作品10 第十章と作品11 第四章の食い違い。**一人称の確信が間違っているまま残す**
- 作品18 第十章「三十一日は火曜だった」と同作 第八章「二月十二日の火曜」。
  **最後の日に曜日を一つ間違えた、という形で残す**

　——**人がまちがえたのなら残す。こちらが取りちがえたのなら直す。**

## 台帳

### 一　柏尾製パンの焼き上がり（二〇三六年十月）

　**時刻を二十四時間制にそろえたときに出てきた。**

| | |
|---|---|
| 多数派 | 共有設定・作品04・作品09・作品12・幕間01・幕間14。**窯に火が入るのが三時、焼き上がりが十五時** |
| 少数派 | 幕間08 第一章、作品11 第四章。**朝のパン屋になっていた** |

　作品04『餃子パン』は、**パンが売れるのは夕方で、餃子が売れるのは昼**という
　一篇の芯がここに乗っている。多数派を動かすと、あの作品の裏のテーマが崩れる。

| 直した | |
|---|---|
| 幕間08 第一章 | 「午前中はもう半分売れている」→「午前中の棚はまだ空いている」 |
| 作品11 第四章 | 「三時に焼き上がって、五時から売って、八時前は一回目の波が終わったところ」<br>→ 棚にまだ何も出ていない形に書き直した。**朝のこの時間に表に用のある人はいない** |

　作品11 のほうは、**宮地あんずが用もないのに来ている場面**である。
　誰も来ない時間だと書いたほうが、この人が来ていることが立つ。

### 三　宮地あんずの言葉（二〇三六年十月）

　**幕間15 を書く前に既刊を確かめて出てきた。**

| | |
|---|---|
| 多数派 | 作品04（第十章ほか）・作品07 第十一章。**あんずは標準語。**「〜でしょ」「〜じゃん」「ないとも言ってない」 |
| 少数派 | 幕間14 第二章・第四章。**あんずが広島弁で喋っていた。**「去年も言うとったよ」「じゃろ」 |

　作品04 と作品07 では、**なつが訛り、あんずが訛らない**ことで二人の声が割れている。
　幕間14 のままだと、二人の台詞が見分けられなくなる。
　——**これはこちらの取りちがえである。**人物がそう喋ったのではない。

| 直した | |
|---|---|
| 幕間14 第二章 | あんずの台詞十六本を標準語に。「おる」→「いる」／「ほうか」→「ふうん」／<br>「去年も言うとったよ」→「去年も言ってたよ」／「言わん人じゃろ」→「言わない人でしょ」／<br>「あんた」→「なつ」（二か所。あんずはなつを名前で呼ぶ） |
| 幕間14 第四章 | 「あれ、言うたほうがええんじゃろうか」→「あれ、言ったほうがいいのかな」／<br>「寒ないん」→「寒くないですか」（祖母には丁寧語で通す）／<br>「四時って、なんの時間なん」→「なんの時間なの」／「帰るわ」→「帰る」 |
| 付随 | 共有設定の年表、幕間14 の 設定.md・プロット.md・あらすじ記録.md の引用も合わせた |

　**言葉の割れは、この組の軸ではない。**軸は前を言うか次を言うかである。
　そのことを `商店街連作設定.md`「軸ではないが、固定されている言葉」に書いた。

#### 三の訂正——「家でも訛らない」は行き過ぎだった（同月）

　**作品11 第二章を読み落としていた。**夜の厨房で弟の遼と二人のとき、
　あんずは「知っとる」「遅い」と言っている。**家の中では訛る。**

| | |
|---|---|
| 直した規則 | 「家でも訛らない」→ **「外では訛らない。家の中では訛る」** |
| 幕間15 第三章 | 父との二往復を広島弁へ戻した。「いる」→「おる」／「落としていい」→「落としてええ」／「下にいる」→「下におる」 |
| 幕間14・幕間15 のほか | **なつの前はすべて標準語のまま。**ここは変えない |
| 幕間11 | 餃子会の六人といる場面を標準語へ。**第六章は地の文ごと直した**（語りは作品11・幕間14 と同じ標準語である調）。ほかに第四・十一・十六・二十章の台詞 |

　——**なつは、家の中にも外にも入っていない。**十一年おなじ台所に出入りしていて、
　それでも外の声のままである。**そこが効くので、なつの前では訛らせない。**

### 四　二番地は空き店舗ではない（二〇三六年十月）

　**幕間15 で通りを南から北まで一軒ずつ歩かせたときに出てきた。**

| | |
|---|---|
| 多数派 | 共有設定の並び表、作品07、作品12、幕間07。**二番地は川本青果。営業している。**間口十一・二メートルで通りの最大。二〇三五年八月にも店先に川本ゆきがいる |
| 少数派 | 幕間14 第四章。**二番地が「わたしが生まれるより前から閉まっている」空き店舗になっていた**（一九九五年ごろ、十九年と七か月） |

　二番地が空いていると、**通りに存在しない店が一軒できる。**
　——これもこちらの取りちがえである。三番地の南どなりを確かめずに書いた。

| 直した | |
|---|---|
| 幕間14 第四章 | 「ここはわたしが生まれるより前から閉まっていて」<br>→「青果店のシャッターは、夜のあいだ下りている。朝いちばんに上げるときに鳴る」 |
| 幕間14 設定.md | 「二番地は、なつが生まれるより前から閉まっている」→「二番地は川本青果。閉まった店ではない」 |
| 資料/一言.md（i14 の 4） | 「下りてから、十九年と七か月になる」→「毎晩十八時に下りて、五時に上がる」 |
| 幕間14 あらすじ記録.md | 「十九年閉まっている二番地」→「シャッターの下りた二番地（青果店）」 |

　**場面は何も変わっていない。**とし子が立った位置も、向いた方角も、見ていたものも同じである。
　**空き店舗である必要が、もとから無かった。**夜に下りているシャッターなら、どの店でも足りる。

### 五　一章の長さが十篇かけて半分になった（二〇三六年十月）

　**これは矛盾ではない。**本文どうしが食い違ったのではなく、**規則が消えた。**

| | |
|---|---|
| 規則 | 作品01・04 の プロット.md に「各章3,000字（±10%）」。作品08・18 は三千四百字 |
| どこに無かったか | **`CLAUDE.md` にも `小説執筆` スキルにも、一行も書いていなかった** |
| 何が起きたか | 幕間01 3,340字 → 幕間06 3,241 → 幕間11 2,382 → 幕間13 2,106 → **幕間14 1,540** |

　新しい篇の `設定.md` に分量を書くとき、**前の篇より少しずつ低く置いた。**
　一篇ずつ見ればどれも目標の内側なので、`文体.py` は何も言わない。

| 直した | |
|---|---|
| CLAUDE.md | 「一章の長さ」を新設。**二千七百字を切るなら理由を 設定.md に書く** |
| 小説執筆 スキル §1 | 同じことを工程の先頭に入れた |
| 幕間15 | 三章とも書き直した。5,755字 → **8,599字**（一章二千六百〜三千字） |

　**幕間14 は直していない。**字数は事実の食い違いではないので、台帳の「直してよいとき」に当たらない。
　短いまま残す。**規則が無かった時期に書かれた、という記録のほうが要る。**
