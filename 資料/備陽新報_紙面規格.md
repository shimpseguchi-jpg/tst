# 備陽新報　地域面　紙面規格

作中の記述から割り出した寸法。**紙面の組み方はここを唯一の根拠にする。**

## 作中の記述

| 記述 | 出典 |
|---|---|
| 地域面は一ページが全十五段 | 第一章 |
| 半ページなら七段ぶん取れる | 第一章・第十三章・第二十一章 |
| 七段ぶん取れると計算した。**計算は合っている** | 第十三章 |
| 写真を一枚入れると、二段ぶん持っていかれる | 第二十一章 |
| 題と署名で、半段 | 第二十一章 |
| 本文に使えるのは二千三百字くらい | 第二十一章 |
| 前書きに二百字置くと、残りが二千百字 | 第二十一章 |
| 十四軒で割ると、一軒あたり百五十字 | 第二十一章 |
| 行にすると、三行から五行 | 第二十一章 |
| 四百字詰めの原稿用紙に直すと、全部で六枚に届かない | 第二十一章 |
| 写真説明　第二回は二十八字（うち十一字が番地） | 第十六章 |
| 写真説明　第三回は十九字 | 第二十章 |
| 写真説明　最終回は十八字 | 第二十三章 |

## 割り出した格子

七段から、写真の二段と、題と署名の半段を引くと、本文は**四・五段**。
そこに二千三百字が入るのだから、**一段はおよそ五百十字**である。

一段を五百十字にするには、一行十一字・一段四十七行になる。
これは十五段の新聞紙面としてそのまま成り立つ寸法で、一ページは約七千六百字になる。

| | 値 |
|---|---|
| 一ページ | 十五段 |
| 一段 | 四十七行（全幅） |
| 一行 | 十一字 |
| 一段の字数 | 五百十七字 |
| 主記事 | 段一〜七 |
| 写真 | 段一〜二（全幅）＝二段 |
| 題と署名 | 幅二百ピクセル×三段＝**〇・五〇段** |
| 本文 | 四・五段＝**二千二百八十八字** |

第二十一章の「二千三百字くらい」と、二十字と違わない。

## 二つ、作中で食い違っているところ

**一、第一章と第二十一章で、一段あたりの字数が合わない。**
第一章は「本文だけで四百字詰め原稿用紙にして十二枚くらい」＝四千八百字で、
七段で割ると一段六百八十六字になる。第二十一章の五百十七字と三割ちがう。
第一章は企画が通った日の概算で「くらい」がついており、第十三章が正しいと認めているのは
**七段という数だけ**である。**紙面は第二十一章の割りつけを採る。**

**二、「行」が二つの意味で使われている。**
第二十一章の「一軒あたり百五十字」「行にすると三行から五行」は、一行三十七字で計算が合う。
これは藤木が原稿を書いている画面の行であって、新聞の行（十一字）ではない。
紙面では新聞の行を使う。

## 写真の段数

第二十一章は写真一枚で二段としているが、これは最終回の本文が二千三百字あるときの話である。
**本文が短い回は、写真がそのぶん大きくなる。** 紙面は本文の字数から写真の段数を決め、
二段から五段のあいだで、本文が入るいちばん大きい写真を選ぶ。
第一章の「写真を一枚か二枚入れると、十枚を切る」も、写真が可変であることを示している。
