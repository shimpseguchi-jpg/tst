# 書き直し台帳

　**本編の三十一篇を、執筆規則の第三版で書き直す。**ここはその進み具合を書く場所である。
　規則は `.claude/skills/小説執筆/SKILL.md` の §9。

---

## 方針

| | |
|---|---|
| **書き直すもの** | 書き方。文の切り方とつなぎ方、読点、一章の長さ、表記、地の文の性格説明と数の申告、畳み込まれたいまの会話、足りない事実 |
| **動かさないもの** | **事実。**年表・日付・曜日・時刻、人物の名前・年齢・関係・言葉、数字、台詞の中身、封印、結末と最後の一行 |
| **速さ** | **変えない。**遅い篇は遅いまま、速い篇は速いまま。第三版の幅に寄せるのは、その篇の速さの中で |
| **対象外** | 番外編と二次創作。壊してあることが中身である |
| **単位** | **一篇につき一コミット。**前と後を `tools/点検.py --前後` で測って、ここに貼る |

　**大きな矛盾を見つけたら、直す。**多数派に合わせる。前の篇が少数派なら、前の篇を直す。
　直す前に `資料/直した記録.md` に一件書く。**この台帳とは別に書く**——混ぜると、何を動かしたかが追えなくなる。
　小さな揺れは書き直しの中で揃えてよい。人物が本文の中で言いまちがえているものは残す。

## 順序

**執筆順に書き直す。**（二〇二六年十月五日、作者が決めた）

　書いた順に、規則と声が育ってきた。**同じ順で書き直すと、どの篇で何が変わったのかを追える。**
　順は git の履歴で確かめた（各篇の第一章が最初に入った日時）。

　**時系列で前にある篇の事実を、あとから書き直す篇が動かさないように気をつける。**
　執筆順だと、時系列で前の篇を、あとで書き直すことがある（作品05 は作品03・04 より前の年の話で、
　書き直すのは三篇目より後になる）。**書き直す篇に出る事実は、時系列で前の篇の本文で確かめる**（§0）。

### 前の数から分かること

- **違反は三種類しかない。**短い章（五十三章）、ダッシュ（三百二十六か所）、読点（一章）。
  忌避表現・算用数字・三点リーダー・語り手の表記は、**全篇で守られていた**
- **ダッシュの違反は、ほぼ幕間08 以降に集まっている。**場面の頭に「——」を置く書き方が定着してからである
- **短い章は八篇。**うち作品05・幕間10・14・15 の四篇は、`設定.md` に短く取る理由が書いてある。
  **書き直しでは理由を読み直す。**理由が今も立っていれば残し、立っていなければ三千字にする
- **作品01〜作品16 はほとんど違反がない。**書き直しの中心は機械では見えないところになる——
  §0 の事実の確かめ、§5 の人物、§6 の封印。**点検の数が〇でも、書き直す篇は書き直す**
- 「文体」の — は、`設定.md` に「文体の目標」が置かれていない篇。**書き直す前に置く**（§9 手順三）
