# 一人のとき

誰にも見られていない時間に、何をしているか。
**本編は、この時間をほとんど書いていない。**
書いているのは作品13 だけで、あれも一回ぶんである。

ここに書くのは、**毎回やっていること**のほうである。

---

## 餃子会の六人

| | 何時から | していること | 音 |
|---|---|---|---|
| 宮地 あんず | 二十三時十分すぎ | **数が合った日は、そのまま上がる。**合わなかった日だけ厨房に座る。ノートの後ろの見開きを使う | 冷蔵庫。上の階で父が歩く音 |
| 日下部 なつ | 二十一時 | 寝る。**寝られない日は、翌日の粉の量を先に量っておく。**量ると寝られる | なし。**耳栓をする。三時に起きるため** |
| 黒江 いと | 二十二時ごろ | **筆を洗う。**その日使っていない筆も洗う。十五分かかる。洗いながら、次の看板の字を指で書く | 水。ラジオはつけない |
| 蓮見 すず | 二十時 | 紙見本を並べ替える。**並べ替えたあと、元に戻す日がある。**戻した理由は自分でも分からない | 換気扇 |
| 矢部 さえ | 二十三時 | **湯を落としたあとの浴室に、五分だけ入る。**誰もいない湯船の縁に座る。湯は張らない | 配管。冷めるときに鳴る |
| 山根 とも | 二十二時 | 彫る。四時まで。**途中で一度だけ、印面を光にかざして、彫っていないほうの面を見る** | ルーペを置く音。それ以外は自分の手の音 |

## 眠れない日にすること

| | すること |
|---|---|
| 宮地 あんず | 冷蔵庫の紙を一枚ずつ読み直す。**九枚あるので、九枚読む** |
| 日下部 なつ | 起きる。**寝られない時間を、起きている時間に付け替える** |
| 黒江 いと | 天井を見る。**天井の合板の木目を、字として読もうとする癖がある** |
| 蓮見 すず | 何もしない。**目を開けたまま四十分待つと、だいたい寝る** |
| 矢部 さえ | 数える。**湯の温度ではなく、その日通った客の順番を思い出す** |
| 山根 とも | 起きているので、この欄がない |
| 沖田 ちさと | 喋る。**誰にも送らないものを録って、朝に消す** |
| 沢渡 ふゆ | 読む。**眠れない日のほうが、進む** |

## 覚え書き

- **六人のうち五人が、一人の時間に手を動かしている。**
  洗う、量る、並べ替える、彫る、座る。
  **手を止めて考える人が、この六人にいない。**
- **宮地あんずの欄だけ、条件がついている。**「数が合わなかった日だけ」。
  合った日は何も起きないことになっている。**合わない日にしか、自分の時間がない。**
- **沖田ちさとと沢渡ふゆは、同じことをしている。**
  声に出す仕事と、声に出さないと読めない体である。
  二人は会ったことがない。**会わせる予定も、いまのところない。**
- **誰も、泣いている欄がない。** 書かなかったのではなく、置かなかった。
  この連作は十八作と七つの幕間で、**泣いた場面を一度も書いていない。**
