# 作品18『七十二冊』設定

連作の十八作目。柏尾銀天街編。共通の土台は `../商店街連作設定.md`。
**完成済みの作品03・作品12の本文は一字も改稿しない。**

| 項目 | 内容 |
|---|---|
| 分量 | **全十章。各章三千四百字（±10%）。総計三万四千字前後** |
| 時代 | **二〇三五年九月 — 二〇三六年三月三十一日** |
| 主舞台 | 柏尾銀天街 五番地・古書店 文林堂／備陽新報 柏尾支局 |
| 視点 | **奇数章＝沢渡ふゆ、偶数章＝藤木かなえ。どちらも一人称「わたし」** |
| 表のテーマ | 棚を一本ぶん埋める |
| 裏のテーマ | **書けるものを、書かないこと** |

## 0. 主題

　**古書店の店番は、八年で七十二冊しか読んでいない。**
　読めないのではない。方法ができただけで、方法は時間がかかる。
　声に出すと進む。夜に三十分。それを八年やって、七十二冊である。

　**その七十二冊を、入口の棚に一本ぶん並べることになる。**
　棚には二百冊入る。七十二冊しか入れない。**残りは空けたままにする。**

　**新聞記者は、それが何の棚かを、見て分かる。**
　四年前、この人は十四軒歩いて、書けるものを全部書いた。
　今度は、書けるものを書かない。

## 1. 原則6の例外について（共有設定に記録済み）

連作は「前の作品の主人公を次の作品の主役にしない」と決めてある。
**本作はその例外である。一度だけ作る。** 条件は三つで、三つとも守る。

1. **八年と四年が空いていること**（作品03は二〇二七年度、作品12は二〇三一年）
2. **二人が一度も同じ作品に出ていないこと**（幕間07 で初めて同じ部屋にいた）
3. **前作の問題を持ち越さないこと**
   - **ふゆが本を読めるようになる話にしない。**八年たっても方法は同じで、速くなっていない
   - **かなえが良い記者になる話にしない。**支局は閉まる。最後の記事は二段で、署名がない
   - **宇田ときを出さない。**名前も出さない。**あの家のことは一行も書かない**

## 2. 人物

### 沢渡 ふゆ　二十八歳　語り手（奇数章）

- 文林堂の店番。**九年目。**週六日、十二時から七時。水曜が休み。
- 二〇二八年二月に退学届を出した。**復学届は、本棚の一冊のあいだに挟んだままである。**
- **字が滑る。** 一行が入ってこない。医者には行っていない。
  **声に出すと進む。**アパートで夜に三十分。八年やって七十二冊
- **題を見ない。** 本は、背の高さと厚みと、布か紙かで見分ける。
  客が戻してきた本の**開き方**で、どこまで読まれたかが分かる
- 二階の滝沢篤子には、**九年で一度も会っていない。**やりとりは戸の下の紙だけ
- 癖：ページのいちばん下まで目で追ってから栞を挟む。本の角を親指で押さえる

### 藤木 かなえ　三十一歳　語り手（偶数章）

- 備陽新報 柏尾支局の記者。**八年目。**福山の生まれ。柏尾の人間ではない。
- 二〇三一年の連載『まちを動かす女たち』全四回。**第二回は店名を一字も書けなかった。**
- **人の言葉を頭の中で鉤括弧に入れる癖。**見出しの形で考える
- **四年前に頼んだ判を、取りに行っていない。**八千円。山根印房。まだ払っていない
- 幕間07（二〇三五年八月二十二日）で、**手帳を出さずに餃子を包んだ**

### 久保田 光代　五十八歳　柏尾支局長

- 入社三十六年目。支局長になって八年目。
- **原稿に赤を入れるとき、理由を書かない。**字が読めるように一本引くだけ
- 褒めない。振り返らない。**作品12 で言ったのは一言だけだった。本作でも一言だけにする**
- 本社の再雇用の話を断る。**理由は言わない**

### 滝沢 篤子　二階

- **姿を見せない。理由は本作でも書かない。**（共有設定の「答えを用意しない」空白）
- 紙に書く字は短い。用件だけ。**ごくまれに二行目がある**

## 3. 書き分けの軸（一つだけ。二つ以上使わない）

**軸＝断定するかどうか。**
連作はすでに方言（とも×ちさと）、文の長さ（いと×すず）、敬語（さえ×るり）を使っている。
**本作は四つ目の軸を立てる。**

| | |
|---|---|
| **沢渡ふゆ** | 言い切らない。「たぶん」「〜だと思う」「よく分からない」が**地の文にも出る**。数は言えるが、意味は言わない |
| **藤木かなえ** | 言い切る。「〜である」「〜だ」。**見出しの形で考える癖**があるので、地の文が短く決まる |

**最後に入れ替える。**
第九章でふゆが一度だけ言い切る（「右端には理由が要る。これは、たぶん、ではない」）。
第十章でかなえが崩れる。**一度崩れたあと、そのまま二度続けて出る。**
崩れる前の八年ぶんは、第十章の地の文が自分で説明する。
**それ以外の場所では崩さない。**

## 4. 動かさない数

| | |
|---|---|
| 棚 | 入口から一本目。幅九十センチ、六段。**入るのは二百冊くらい** |
| 入れる数 | **七十二冊。**八年で読み終えたぶんである |
| 支局の蔵書 | 二百三十冊。ほかに**縮刷版が四十八冊**（四年ぶん、月一冊） |
| 図書館が引き取る | **三冊だけ。**二〇三一年十一月の巻は入っていない |
| 判 | 八千円。二〇三一年十二月三日に取りに行くはずだった。**四年三か月、店に置いてある** |
| 支局の閉鎖 | **二〇三六年三月三十一日。**福山本社へ統合 |
| ふゆの夜 | 一日三十分。**速くなっていない** |

## 5. 走らせるもの（同じ形を三度使わない）

1. **戸の下の紙。** 九年ぶんある。本作で三枚だけ出す。三枚目に二行目が付く
2. **開き方で分かる。** 客が戻した本がどこで開くか。読まれた本は読まれたところで開く
3. **かなえが鉤括弧に入れる。** 章に二、三回。**第七章で一度だけ、入れられない言葉が出る**
4. **久保田の赤。** 理由を書かない。本作では一枚だけ返す
5. **数が合ってしまう。** 七十二という数は、狙って出したものではない

## 6. やらないこと

- **本が人を救う、で締めない。**（作品03の方針をそのまま継ぐ）
- **かなえがふゆのことを記事にする展開を、最後まで作らない。**書かない理由も説明させない
- ふゆと二階を会わせない
- **誰も泣かない。誰も打ち明け直さない。**ふゆが自分のことを言うのは第七章の二行だけ
- 恋愛として書かない。**関係に呼び方をつけない**

## 7. 終わり方

　第十章。支局の鍵を返した日に、かなえが文林堂へ寄る。
　棚は七十二冊ぶんだけ埋まっていて、残りは空けてある。
　**右端の一冊だけ、値札も店の印もない。**九年前から棚にある、店のものではない一冊である。
　かなえはそれが何かを見て分かる。**書かない。**

　閉じるのは物である。**棚が埋まったのでブックエンドが要らなくなり、ふゆがそれを外す。**
　外したあとの埃の跡が、棚板にコの字で残る。
