# 学級新聞をつくる

先生の手間は「思いついたことを散文で送る」だけにする。肉付けと紙面づくりはこちらでやる。

紙面は英字新聞ふうの横書き（飾り文字の英語の題字、段組み、罫線）がふつう。
先生が「たて書き」「和風」と言ったときだけ、たて書きの版（`--tate`）で組む。

## ながれ

1. **設定を読む**：`shinbun/settings.json`（新聞の名前、英語の題字、学年、発行者、次の号数、コラム名）。
   英語の題字 `title_en` は、新聞の名前をローマ字や英語にしたもの（例「なかよし新聞」→「The Nakayoshi Times」）。
   学年が分からない・設定が見本のままのときは、最初の1回だけ先生に聞いて書きかえる。
2. **散文を3つに分ける**：①学校のこと ②世の中のニュース ③その他（コラム・予定・クイズなど）。
   どれかが無ければ次のとおりにする。
   - ① 学校のこと が無い → 先生に聞く（ここは作り話にできない）。
   - ② 世の中のニュース が無い → WebSearch で、その日前後の子ども向けの話題（季節・科学・スポーツ・行事など、こわくない話）を1つ選び、選んだことを先生に伝える。
   - ③ コラム が無い → 季節や①②につながるテーマで、担任の語り口のコラムを書く。
3. **肉付けする**（下の「書き方のきまり」を守る）。
4. **JSON を書く**：`shinbun/issues/YYYY-MM-DD.json`（同じ日に2号目なら `-2` をつける）。形は下の「JSON の形」。
5. **組む**：`node shinbun/build.mjs shinbun/issues/YYYY-MM-DD.json`
   - `⚠ あふれ` が出たら、その記事の文を短くして組み直す。
   - 文字が 10pt より小さくなった記事も、読みにくいので少し短くする。
   - できた `.png` を1回だけ見て、見出しの折れ方などおかしなところがあれば直す。
6. **わたす**：`.pdf` を SendUserFile で送る（印刷はこれを使ってもらう）。
   チャットには、肉付けで足したこと・世の中のニュースの出典・先生に確かめてほしい点を短く書く。
7. **記録**：`settings.json` の `next_issue` を1つ増やし、JSON・HTML・PDF をコミットしてプッシュする（`.png` は確認用なのでコミットしない）。

先生から「ここを直して」と言われたら、JSON を直して 5〜7 をやり直す。

## 書き方のきまり

**事実を足さない。ことばを足す。**
- ① 学校のこと：先生が書いていない出来事・人数・記録・子どものせりふを作らない。
  足してよいのは、様子がうかぶ言いかえ、なぜ大事かの説明、読み手への問いかけ・よびかけ。
  子どものせりふを入れたいときは、先生の散文にあるものだけ使う。
- ② 世の中のニュース：先生が話題を書いてきたときも、日付・数字・固有名詞は WebSearch で確かめる。確かめられないことは書かない。
  `source` に出典を短く書き（例「（気象庁の発表より）」）、チャットにはリンクも出す。
  事件・事故・災害・戦争など、子どもがこわがる話題は先生から明示されたときだけ、落ち着いた書き方で扱う。
- ③ コラム：担任の一人称（「先生は〜」でもよい）で、最後は読み手へのよびかけや問いで終える。
- 子どもの名前はフルネームで書かない。先生の散文にあっても「〇〇さん」までにするか、「ある人」「〇班」にする。
- 文体は「です・ます」。一文を短く（40字くらいまで）。
- 学年に合わせる：その学年でまだ習わない漢字は、ひらがなにするか `{漢字|かんじ}` でふりがなをつける。
  1・2年生向けはひらがなを多めにし、全体を短めにする。
- 大事なところは `**ことば**` で傍点（点々）をつける。1記事に1〜2か所まで。

**分量のめやす**（A4 1枚、4年生向けで文字が 12pt 前後になる量）

| 場所 | 分量 |
|---|---|
| 学校：見出し | 15字以内（長いと2行に折れる） |
| 学校：本文 | 350〜450字、段落3つくらい |
| 学校：引用（quote） | 25字以内。先生の散文にある子どもの言葉だけ。なければ省く |
| 世の中：見出し | 12字以内 |
| 世の中：本文 | 300〜380字 |
| ことばメモ | 50字くらい |
| コラム：本文 | 200〜260字 |
| きょうのひとこと | 30字以内 |
| 囲み（予定・クイズ） | 2〜3つ。予定は3〜4行 |

低学年向けで文字を大きくしたいときは、どれも2〜3割へらす。

## JSON の形

```json
{
  "title": "なかよし新聞",              // settings.json から
  "title_en": "The Nakayoshi Times",   // 英語の題字（settings.json から）
  "subtitle": "4年1組 学級新聞",
  "issue": 2,                           // settings.json の next_issue
  "date": "2026年9月25日（金）",
  "publisher": "4年1組 担任",
  "note": { "label": "きょうのひとこと", "text": "30字以内" },
  "school": {
    "kicker": "学校のできごと",
    "headline": "見出し（**傍点**可）",
    "subhead": "小見出し（なくてもよい）",
    "body": ["段落1", "段落2", "段落3"],
    "emoji": "🏃",                      // 記事に合う絵文字1つ。写真のかわり
    "caption": "絵の説明（25字くらい）",
    "quote": "記事の中の印象的な言葉（大きく引用される。なくてもよい）"
  },
  "world": {
    "kicker": "世の中のニュース",
    "headline": "見出し",
    "subhead": "小見出し",
    "body": ["段落1", "段落2"],
    "memo": { "label": "ことばメモ", "body": ["むずかしいことばの説明"] },
    "source": "（〇〇の発表より）"
  },
  "column": {
    "name": "先生のまど",               // settings.json の column_name
    "headline": "コラムの題",
    "body": ["段落1", "段落2"],
    "byline": "（担任より）"
  },
  "boxes": [
    { "title": "来週の予定", "items": ["9/28（月）｜全校朝会"] },   // ｜ の左が日付、右が内容
    { "title": "きょうのクイズ", "body": "問題", "answer": "こたえ（紙面ではさかさまに出る）" }
  ]
}
```

- 実際のファイルには `//` のコメントを書かない（JSON なので）。
- 本文の数字は半角で書く。2けたまでは自動でたて中横に、3けた以上は全角になる。
- 見本：`shinbun/issues/2026-09-25-mihon.json`

## 用紙

- ふつうは A4。先生が B4 で刷りたいと言ったら `--b4` をつけて組む（紙面をそのまま拡大）。
- たて書きの和風レイアウトにしたいときは `--tate`（JSON に `"layout": "tate"` と書いてもよい）。たて書き版では `title_en` と `quote` は使われない。
- 画面の HTML には「ふりがな あり／なし」の切りかえがある。ふりがな無しの PDF がほしいと言われたら、その号だけ `{漢字|よみ}` を外した JSON で組む。
