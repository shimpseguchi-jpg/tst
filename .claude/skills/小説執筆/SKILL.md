# 小説執筆　第三版

商店街連作（`商店街連作設定.md`）の中編小説を、一章ずつ書くための工程。
**既刊を書き直すときも、この工程を通る**（§9）。

**書くことに関する規則の正は、このファイルである。**
`CLAUDE.md` には要点だけを置いて、ここを指す。二か所に同じことを書くと、片方だけ古くなる。
——第二版までは二か所に書いていて、ダッシュの規則が本文とも道具とも食い違っていた。

| | どこ |
|---|---|
| 書き方の規則 | **このファイル** |
| 世界の事実（年表・人物・番地・定休日・言葉） | `商店街連作設定.md` |
| その篇だけの決まり（文体の目標・視点・禁止） | 各篇の `設定.md`。**このファイルより優先する** |
| 既刊を直した履歴 | `資料/直した記録.md` |
| 書き直しの進み具合 | `資料/書き直し台帳.md` |
| 機械で確かめられる規則 | `tools/点検.py`（§8） |

## 0. 書く前に、既刊で確かめる

**この連作でいちばん多い事故は、文体ではなく事実である。**

　第二版のあいだに、こちらが取りちがえたものが七つあった。全部、書く前に本文を開けば避けられた。

| 取りちがえ | 本当は | どこで確かめたか |
|---|---|---|
| 宮地あんずを広島弁で喋らせた | **外では訛らない。家の中では訛る** | 作品04 第十章、作品07 第十一章、作品11 第二章 |
| ↑を直して「家でも訛らない」とした | 弟には「知っとる」と言っている | 作品11 第二章 |
| 二番地を十九年閉まった空き店舗にした | **川本青果。営業している** | 共有設定の並び表、作品12 |
| 食べ歩きの日に餃子パンが売り切れた | **八十六個のうち十六個残った** | 作品04 第十章 |
| レシートはあんずの缶から出た | **なつの、イベント用の財布から出た** | 作品07 第十一章 |
| 月曜の夕方に理容室で塚本律子を出しかけた | **理容室つかもとは月曜休み** | 共有設定の定休日の表 |
| 一章三千字の規則を、幕間では知らずに下げた | **作品も幕間も三千字** | 作品01・04 の プロット.md |

**書き出す前に、出す人・出す場所・出す日ごとに、次の五つを本文で確かめる。**
共有設定の要約ではなく、**その人が出てくる既刊の本文**を開く。要約は書いた人の解釈である。

1. **言葉**——その人は、その相手に、どの言葉で喋るか（方言／標準語／敬語）。
   **相手と場所で変わる人がいる**（共有設定「軸ではないが、固定されている言葉」）
2. **場所**——その番地に何があるか。その年に開いているか、閉めたあとか
3. **日**——その曜日、その店は開いているか（共有設定の定休日の表）。
   その日に既刊で何が起きているか（年表）
4. **出来事**——既刊が書いた場面の続きや裏を書くなら、**その場面の本文を最後まで読む。**
   誰が何を持っていて、誰が何を言ったか
5. **年齢と呼び方**——その年に何歳か。相手をどう呼ぶか（`資料/呼び方.md`）

**確かめたことは、その篇の `設定.md` に「既刊から動かせないもの」として書く。**
書いておけば、次に読む人が同じ本文を開かなくて済む（幕間15 の 設定.md が見本）。

## 1. 分量

**一章は三千字前後。作品も幕間も同じである。**

| | |
|---|---|
| 守る幅 | **二千七百〜三千四百字** |
| 下げてよいとき | `設定.md` に**なぜ下げるかを書いたとき**だけ（作品05 の二千八百字が見本） |
| 上げてよいとき | 同じ。作品08・18 は三千四百字で、理由が書いてある |

**この規則は、十篇かけて破られた。**

```
幕間01 3,340 → 幕間06 3,241 → 幕間11 2,382 → 幕間13 2,106 → 幕間14 1,540
```

　新しい篇の `設定.md` に分量を書くたび、**前の篇より少しずつ低く置いた。**
　一篇ずつ測るとどれも目標の内側なので、道具は何も言わなかった。
　**篇をまたいで見ないと分からない。**

**新しい篇の分量を決める前に、`python3 tools/点検.py` で全篇の一章あたりを見る。**

- **一発目から目標字数で書く。**短く書いて後から加筆しない。
  加筆で足した文は、密度と呼吸が本文と合わない。書き出す前に章を場面に割り、
  各場面におよその字数を配っておく
- 当該章のプロットから始め、前章末尾の動作を受ける
- 一度描写した設定・人物・場所を、以後の章で再説明しない。連作では他作品の既出も含む
- 設定に無いディテールは判断で補ってよい。**補ったものは `設定.md` に追記する**
- 予測可能な展開を避ける。ただしプロットの骨は動かさない。
  裏切るのは章内のディテール（誰が何を言うか、どの動作で閉じるか）であって、構造ではない

## 2. 速さを、数で置く

**この連作は、作品ごとに速さが違う。速さは好みではなく、その作品の中身である。**

**書き出す前に、`設定.md` の「文体の目標」を見る。無ければ先に置く。**
速さを決めずに書きはじめると、その章は**直前に書いた作品の速さ**で出てくる。

```
python3 tools/文体.py 作品04_餃子パン          # 一篇まとめて
python3 tools/文体.py 作品04_餃子パン/02章.md  # 一章だけ
```

十二の数が出る。`設定.md` に「文体の目標」の表があれば、外れた行に ← がつく。

### 行で数えない。字で数える

　台詞の行は十字前後、地の文の行は二十五字前後ある。**行の数は量を表さない。**
　作品04『餃子パン』の会話行は 55 %だが、**字で数えると 33 %で、三分の二は地の文である。**

**文の長さも、地の文だけで測る。**台詞を混ぜると短く出る（作品04 は混みで十字、地の文だけなら十四字）。

### 二つの端

| | 作品04『餃子パン』 | 作品13『重ならない』 |
|---|---|---|
| | **いちばん速い** | **いちばん遅い** |
| 地の文の文 | 14 字 | 17 字 |
| 一行の文数 | 1.8 文 | 1.2 文 |
| **会話字** | **33 %** | **6 %** |
| **地の連（字）** | **72 字** | **371 字** |
| 地の一行 | 26.4 字 | 21.9 字 |
| 読点 | 29.7 字に一つ | 24.6 字に一つ |

**どちらが正しいということはない。**
『餃子パン』は二人が喋りつづける話で、『重ならない』は六人が別々の休みにいる話である。

### 速い篇は、つないで作る。ただし一文ずつは短くしない

**速い篇でも、本文の三分の二は地の文である。**減らすのではない。**切り方が違う。**

　一行に文を二つ近く入れる。そのつないだ行を二つか三つ重ねて、百字前後。**そこで必ず誰かが喋る。**

　作品04 の弱点は一つだけで、**つなげている一文ずつが短い**（十四字）。これから書く速い篇はこうする。

| | 作品04 | **これから書く速い篇** |
|---|---|---|
| 地の文の文 | 14 字 | **16–19 字** |
| 一行の文数 | 1.8 文 | **1.8–2.3 文** |
| 地の一行 | 26.4 字 | **32–42 字** |
| 地の連（字） | 72 字 | **90–140 字** |

**どこを長くするか。**

| 何をしている文か | どうするか |
|---|---|
| 説明・描写 | **つなげる。**句点で切っていたものを `〜て、` `〜で、` `〜が、` でつなぐ |
| 落とす・突っ込む | **短いまま。**「使わないと死ぬ。」は七字で、そこが芸である |

- 四十字を超える文は**二％まで**。十四字を十八字にするのであって、三十字にはしない
- **つなげたぶん、読点を足さない。**つなぐときは、まず読点なしで書いてみる

### 遅い篇

- 地の文を三百字続けてよい。一行はむしろ短くする（一行一文に寄せる）
- **続かないと、一人でいることにならない**（作品13 第五章は三千三百字まで一度も声が返らない）

**「地の文が多い」と「遅い」は別である。**多いまま速くできる。

### 一人の章は、速い篇の中でも地の連が伸びる

　割って入る人がいないからで、**速さが落ちたからではない。**
　幕間15 は二人の章が地の連百二十字で、一人の第三章だけ約二百五十字になった。
　**一人の章に、幅を合わせるための台詞を入れない。**段落を切り刻まない。
　篇ぜんたいの目標を少し広く取って、**理由を `設定.md` に書く。**

### 新しい作品には、書く前に置く

`設定.md` にこの形で書く。**数は決め打ちせず、近い既刊を `tools/文体.py` で測って決める。**

```
## 文体の目標

| | 目標 |
|---|---|
| 地の文の文 | 16–19 字 |
| 長文 | 2 %以下（四十字を超える文） |
| 一行の文数 | 1.8–2.3 文 |
| 地の一行 | 32–42 字 |
| 地の連（字） | 90–140 字 |
| 地の連（行） | 4 行以下 |
| 会話字 | 18–30 % |
| 会話行 | 40–60 % |
| 会話一行 | 8–13 字 |
| 会話の連（行） | 2.5 行以上 |
| 読点 | 26 字以上あける |
| 場面 | 5–8 ／章 |
```

**目標と本文が食い違ったら、どちらが古いかを考える。**本文のほうが良ければ、直すのは `設定.md` である。

**一章では外れてよい。篇でそろえる。**導入の章は遅く、山の章は速い。これは事故ではなく作りである。

## 3. 表記

| | 書き方 | 例外 |
|---|---|---|
| **ダッシュ** | **「――」**（U+2015 を二つ） | なし。**「——」（U+2014）は使わない** |
| 三点リーダー | 「……」（二つ組） | なし。「…」「・・・」「...」は使わない |
| **数字** | 漢数字 | **規格名・型番**（A4、B5、6AR5）／**作中の書類・メモ・札の写し**（行頭が「・」の取材メモ、『』の中に書かれた字） |
| **時刻（地の文）** | **二十四時間制。**十五時に焼き上がる。二十一時に布団へ入る | 午前は〇時〜十二時のまま |
| **時刻（台詞）** | **その人が言うとおり。**「三時に焼き上がるけえ」 | ——人は「十五時」とは言わない |

　**ダッシュは、第二版のあいだに三百二十六か所「——」で書いていた。**規則は「――」で、
　道具（`文体.py`）は「——」で場面を数えていた。三つが別々のことを言っていた。
　**第三版から「――」に揃える。**`文体.py` はどちらでも場面を数える。既刊は書き直しで揃える（§9）。

　地の文と台詞で時刻が食い違って見えるが、食い違っていない。**地の文は測る側で、台詞は喋る側である。**

## 4. 書きながら守る形式

### 語り手を、章題の末尾に

**章ごとに語り手が替わる篇では、章題の末尾に（名前）を入れる。本文には書かない。**

```
# 第三章　十二月十九日　火曜の夜（宮地あんず）
```

　この連作は一人称が多く、「わたし」が重なる。**誰が喋っているのかを読者に探させない。**
　語り手が一人の篇（一人称一人、三人称一元、外から書く篇）は要らない。

### 台詞と地の文

**いま目の前で交わされている会話は、独立行に置く。地の文に畳み込まない。**

- ×　森岡は「失礼します」と言って切った。（**いまの場面の一言**）
- ○　「失礼します」／　そう言って、森岡は切った。

**畳み込んでよいのは、次の三つだけ。**

| | 例 |
|---|---|
| **回想・伝聞**（いまここで交わされていない） | 中学のとき、隣の子に「粉ふいてる」と言われた |
| **仮定**（まだ起きていない） | 聞いて、櫛を置いて、それから「そうねえ」と言う。そこで終わる |
| **看板・書類・単語の引用** | 第一希望の欄に「映画」と書いた |

　——第二版は「同一行に混在させない」とだけ書いていた。**広すぎた。**
　作品04 に十七か所、作品13 に三十六か所あり、多くは回想と仮定だった。**それは技術である。**
　禁じるのは、**会話を並べるのを面倒がって地の文に押しこむこと**だけである。

- セリフでは助詞・接続詞を省略しない。**ただし方言と口語の自然さが優先される**
- 複数の人物を扱うとき、人物ごとのセクション分けをしない。ひと続きの描写に統合する
- 体型・外見に触れるときは、全年齢向けとしてふさわしい自然な語を使う。
  性的な強調をしない。連作は女性どうしの関係を書くので、ここは明示的に守る
- **章の終わりは、感慨ではなく物か動作で閉じる**

### 読点

**読点は放っておくと増える。**一作目から九作目で、密度が三割上がった。

**二十字を切ったら多い。全作共通の下限である。**目標そのものは `設定.md` が決める。

増える原因は、ほぼ一つ。**「〜は、」である。**

- ×　森岡は、そこで足を止めた。　○　森岡はそこで足を止めた。

**主語が短く、述部も短く、対比もないとき、この読点は要らない。**残してよいのは、主語が長い／間を置きたい（一章に数回まで）／対比がある、の三つ。主語は固有名詞とはかぎらない——**短い語＋は／が**の形で見る。

**動作をつなぐだけの `〜て、` は落とせる。**ただし次の四つは落とさない——三つ以上の列挙／理由・条件の節／逆接／後ろに別の主語が立つとき。落としたあと、読点なしで三十八字を超える文ができたら、一つ戻す。

## 5. 人物を芸にしない

**この連作がいちばん壊れやすいのは、人物が一芸に縮むところである。**

### 三つの禁止

1. **一篇につき、一人の癖は一回まで。**二回目からは別の面を出す。出す面がないなら `資料/まだ書いていない面.md` から取り、使ったら表から消して新しい面を足す
2. **地の文で性格を説明しない。**「この人は〜する人だ」「十年、そうしとる」は書かない。**感情の直接説明と同じ扱いにする。**行動だけ書いて、説明を足さない
3. **字数・温度・秒数を、地の文が申告しない。**本人にも他人にも数えさせない。**限界は、守られているときがいちばん効く**

### 軸は組に付ける。人に付けない

**軸（方言・文の長さ・敬語・断定）は、同じ部屋にいる二人の声を割る道具である。性質ではない。**

- **同じ人が、二つの組で同じ軸を使わない。**組を新しく作るときは、軸も新しく作る
- **一人につき、軸の振れている側に立つ組が最低一つ要る。**どの組でも振られる側なら、それは役である
- **三人以上の場面では軸を立てない。**誰が喋ったかは、言い方ではなく**何に口を出したか**で分かるように書く。何に口を出すかは毎回決める。固定した瞬間、それが新しい軸になる
- **一人の場面には軸がない。**そこがその人の素の声の出る唯一の場所である

**軸と、変わらない言葉を混ぜない。**宮地あんずと日下部なつは言葉が割れているが、軸は「前を言うか次を言うか」である。言葉の割れは相手で決まる属性で、**組の物差しには使えない**（共有設定「軸ではないが、固定されている言葉」）。

### 役割を剥がす

**人を店で呼ぶのはやめない。やめるのは、その人の用事を店の用事にすることである。**

1. **定休日で人を選ばない。**動く理由は店の外から——病院、役所、家族、金、約束、乗りもの、天気
2. **一篇につき一人、店にいないところで出す。**`資料/一人のとき.md` から一つ取り、使ったら印をつける。説明しない。全員ぶん並べない
3. **職は奪わない。**それは二次創作『学園』で一度やった

### 休ませる

| 癖 | 状態 |
|---|---|
| 矢部さえの温度 | 直近五本で連続。**三篇は出さない** |
| 蓮見すず・黒江いとの字数申告 | **当面やらない。**短く答えさせるだけ |
| 「この人は〜する人だ」型 | **禁止** |
| 定休日で人を選ぶ | 四篇続けた。**次の三篇は使わない**（幕間15 で一篇。あと二篇） |
| 三人以上の場面で全員に軸を立てる | **禁止** |

## 6. 封じるものは、一つに絞る

**この連作は説明しない。だから、説明しないことが癖になる。**

> **隙間は、読者が埋める。別の話で埋める。**

　幕間14 で、祖母が四時に通りへ出た理由も、**四時が何の時刻かも**書かなかった。
　読んだ人は「中華屋とパン屋が昔は近くて、どちらかが転居した話」を組み立てた。**そんな設定はない。**
　封じたものは効くが、**書き忘れたものは、別の話になって返ってくる。**

| | |
|---|---|
| **出来事** | **書く。**誰が、どこで、何をしたか |
| **その出来事の意味する事実** | **書く。**「四時は、祖父が窯に火を入れていた時刻である」 |
| **その人の気持ち・理由** | **書かない。**ここだけが封印である |

**点検**——その章だけを、外を知らない人が読んだつもりで一度読む。起きたことを言い直せないなら足りない。足すのは**事実であって、気持ちではない。**「あとで分かる」で先送りしない。

## 7. 使わない言葉

生成段階で選ばない。**言い換えた痕跡を本文に残さない。**

| | 禁じる | 禁じない |
|---|---|---|
| 口癖 | `めっちゃ` `ヤバい` `ぶっちゃけ` `てゆうか` `何！？` | |
| 「的な」 | 仮名のあとの口癖（`ゆるい的な`） | 合理的な、一般的な、目的なので |
| 「まるで」 | `まるで〜のような` の直喩 | まるで気持ちが入っていない（＝全然） |
| 「〜すぎる」 | 強調の口癖（`かわいすぎる`） | 言いすぎる、重くなりすぎる（量を言う） |
| 感情の既製品 | `ドキッとした` `胸が締めつけられた` `涙が溢れた` | |
| 擬音 | `ドキドキ` `ワクワク` `ゾクッ` の多用 | |
| 言い直し | `〜かもしれない、いや、〜だ` | |
| 直接説明 | `彼女は悲しかった` | |

　——第二版は「的な」「まるで」「すぎる」を語として禁じていた。全篇で数えたら、
　**二十一件すべて正しい日本語だった。**禁じたいのは用法であって、語ではない。

## 8. 点検

### 機械で数える

```
python3 tools/点検.py                    # 本編の一覧
python3 tools/点検.py 作品04_餃子パン    # 一篇の詳細（どの章の何行目か）
python3 tools/文体.py 作品04_餃子パン    # 速さ（§2）
```

`点検.py` は二種類を出す。

| | 中身 | どうするか |
|---|---|---|
| **違反** | 章の字数／語り手／ダッシュ／三点リーダー／算用数字／忌避表現／読点の下限 | **〇にする** |
| **要確認** | いまの会話の畳み込み／性格の説明／数の申告／地の文の十二時間制 | **読んで決める。**〇にしなくてよい |

**要確認を全部消そうとしない。**「この人は二階にいる」は性格の説明ではない。
候補の多い篇は、読むときにそこを気にする、というだけの数である。

### 反復を見る

前章までと照らして——同じ文型の連鎖、同じ比喩・同じ語彙の再使用（`あらすじ記録.md` を検索）、セリフの受け方と間の取り方の反復。**`設定.md` が「反復モチーフ」に指定したものは除く。**

### 目で見る

- 三人以上の場面で、全員に軸が立っていないか
- 一人の場面で、軸が鳴っていないか
- この篇で、店にいないところを一つ書いたか
- §0 の五つを、出した人と場所と日について確かめたか

### 読者ペルソナ（初稿は出力しない）

書き上げたら、必ず四人に読ませてから最終稿にする。修正はレビューの痕跡を残さず、文全体を調整して行う。

| | 好むもの | 嫌うもの |
|---|---|---|
| **A**（作者） | 文法の正確さ | パターン化した展開、前章との重複、設定の急な変更 |
| **B**（連作の読者） | 抑制、行動から察すること、長い静かな場面 | 説明、泣かせ |
| **C**（この篇から読む人） | その場で分かる固有名詞、一篇で完結すること | 前作を知らないと分からない書き方 |
| **D**（速さで読む人） | 台詞の応酬、笑うところ | 続く地の文、同じ調子が三場面 |

**BとDは正面から対立する。**どちらを重く見るかは `設定.md` の「文体の目標」が決める——遅い篇はB、速い篇はD。作品04 は、**Bの指摘だけで直すと壊れる。**

**設定.md の禁止事項と衝突する指摘は採らない。**それ以外は反映し、強みは伸ばす。

## 9. 既刊を書き直すとき

**この連作は、最終的に全篇を第三版で書き直す。**進み具合は `資料/書き直し台帳.md`。

### 書き直すもの、動かさないもの

| 書き直す（書き方） | **動かさない（事実）** |
|---|---|
| 文の切り方・つなぎ方・読点 | **年表の出来事、日付、曜日、時刻** |
| 一章の長さ（足りなければ足す） | **人物の名前・年齢・関係・言葉** |
| 表記（ダッシュ、時刻の二十四時間制） | **数字**（八十六個、七百八十円、三分十二秒） |
| 地の文の性格説明、数の申告 | **台詞の中身**（言い方は整えてよい。言ったことは変えない） |
| 畳み込まれたいまの会話 | **封印**（書かなかった気持ち・理由は、書き直しでも書かない） |
| 足りない事実（§6） | **結末と、最後の一行** |

**書き直しで足りない事実が見つかったら、足してよい。**ただし**別の篇が同じ事実を書いていないか**を先に確かめる（§0）。足したものは `設定.md` に書く。

### 矛盾を見つけたら、直す

**書き直しは、矛盾を見つけるいちばんの機会である。**一篇ずつ本文を最後まで読み、前の篇と突き合わせるからである。

| | どうするか |
|---|---|
| **大きな矛盾**（筋・人物・言葉・番地・日付・数が、二つの本文で食い違う） | **直す。**多数派に合わせる。直す前に `資料/直した記録.md` に一件書く |
| 小さな揺れ（言い回し、呼び方の一回だけのぶれ） | 書き直しの中で揃える。台帳には書かなくてよい |
| 人物が言いまちがえている（本文の中で本人の記憶ちがいとして書いてある） | **残す。**——人がまちがえたのなら残す。こちらが取りちがえたのなら直す |

**直すのは、いま書き直している篇とはかぎらない。**前の篇が少数派なら、前の篇を直す。
書き直しと矛盾の修正は**同じコミットに入れてよいが、台帳は別々に書く**（書き直し台帳と、直した記録）。
混ぜて書くと、あとで何を動かしたかが追えなくなる。

### 手順（一篇ずつ）

1. **前を測る。**`python3 tools/点検.py --前後 <篇>` の一行を台帳に貼る
2. **既刊で確かめる。**§0 の五つ。その篇に出る全員・全番地・全日付について
3. **`設定.md` に「文体の目標」が無ければ置く。**その篇の今の数を測って、そこを起点に第三版の幅へ寄せる。**速さは変えない**——遅い篇は遅いまま、速い篇は速いまま書き直す
4. **一章ずつ書き直す。**§1〜§7 で。一章ごとに `文体.py` を見る
5. **後を測る。**`--前後` の一行をもう一度貼る。**違反が〇になったこと、文体の外れが増えていないことを見る**
6. `あらすじ記録.md`・`資料/一言.md` を合わせる。既刊表の字数を実測に合わせる
7. 台帳に印をつけて、コミットする。**一篇につき一コミット**

### 対象

- **本編の三十一篇。**作品と幕間の両方
- **番外編と二次創作は書き直さない。**壊してあることが中身である。第三版の規則で整えると、壊した意味がなくなる

---

## 10. 章を書き終えたら

1. 字数（`tools/字数.py`）。二千七百〜三千四百字
2. 速さ（`tools/文体.py`）。← がついた行を見る
3. 点検（`tools/点検.py <篇>`）。違反を〇に
4. `あらすじ記録.md` に二百字の要約を足す
5. 補ったディテールを `設定.md` に足す
6. コミットする
