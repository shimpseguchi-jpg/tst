# 小説執筆

商店街連作（`商店街連作設定.md`）の中編小説を、一章ずつ書くための工程。

## 0. 執筆前に必ず読む

1. `商店街連作設定.md`（共有世界・年表・往来する人物）
2. 当該作品の `設定.md`（人物・文体・表記・禁止事項）
3. 当該作品の `プロット.md`（当該章の項）
4. 当該作品の `あらすじ記録.md`（前章までの要約と、既出の表現）

**設定.md の記述がこのファイルと矛盾する場合、設定.md を優先する。**
作品ごとの文体は作品が決める。このファイルは工程だけを決める。

**書き出す前に、設定.md の「文体の目標」を見る。**無ければ、先に置く（§1-2）。
**速さを決めずに書きはじめると、その章は直前に書いた作品の速さで出てくる。**
これがこの連作でいちばんよく起きる事故である。

## 1. 初稿の書き方

- **一発目から目標字数で書く。** 短く書いて後から加筆しない。
  加筆で足した文は、密度と呼吸が本文と合わない。書き出す前に、章を場面に割り、
  各場面におよその字数を配っておく。**出力全体でペース配分を均一にする。**
- 当該章のプロットから始め、前章末尾の動作を受ける。
- 一度描写した設定・人物・場所を、以後の章で再説明しない。連作では他作品の既出も含む。
- 設定に無いディテールは判断で補ってよい。ただし**補ったものは設定.md に追記**して整合を保つ。
- 予測可能な展開を避ける。ただしプロットの骨は動かさない。
  裏切るのは章内のディテール（誰が何を言うか、どの動作で閉じるか）であって、構造ではない。

## 1-2. 文体の目標を、数で置く

**この連作は、作品ごとに速さが違う。速さは好みではなく、その作品の中身である。**

```
python3 tools/文体.py 作品04_餃子パン          # 一篇まとめて
python3 tools/文体.py 作品04_餃子パン/02章.md  # 一章だけ
```

十二の数が出る。設定.md に「文体の目標」の表があれば、外れた行に ← がつく。

### 行で数えない。字で数える

**これで一度間違えた。**

　台詞の行は十字前後、地の文の行は二十五字前後ある。
　**行の数は量を表さない。**作品04『餃子パン』の会話行は 55 %だが、
　**字で数えると 33 %で、三分の二は地の文である。**

　読む人が感じるのは字のほうである。迷ったら「会話字」を見る。

**文の長さも同じ罠がある。地の文だけで測る。**
　台詞を混ぜると短く出る。作品04 の文は、混みで数えると十字だが、
　**地の文だけなら十四字である。**`文体.py` の「地の文の文」はそちらを出している。

### 二つの端

| | 作品04『餃子パン』 | 作品13『重ならない』 |
|---|---|---|
| | **連作でいちばん速い** | **連作でいちばん遅い** |
| 地の文の文 | 14 字 | 17 字 |
| 一行の文数 | 1.8 文 | 1.2 文 |
| **会話字** | **33 %** | **6 %** |
| 会話行 | 55 % | 11 % |
| **地の連（字）** | **72 字** | **371 字** |
| 地の一行 | 26.4 字 | 21.9 字 |
| 読点 | 29.7 字に一つ | 24.6 字に一つ |

**どちらが正しいということはない。**
『餃子パン』は二人が喋りつづける話で、『重ならない』は六人が別々の休みにいる話である。
——声が返ってこない時間の長さが、そのまま中身になっている。

### 速い篇の地の文は、つないで作る

**速い篇でも、本文の三分の二は地の文である。**減らすのではない。**切り方が違う。**

| | 作品04 | 作品13 | 連作の中どころ |
|---|---|---|---|
| 地の文が続く長さ | **72 字** | 371 字 | 220 字前後 |
| 一行の文数 | **1.8 文** | 1.2 文 | 1.5 文前後 |
| 地の一行 | 26.4 字 | 21.9 字 | 25 字前後 |

　**一行に文を二つ近く入れる。**そのつないだ行を二つか三つ重ねて、七十字。
　**そこで必ず誰かが喋る。**

> 　急である。急というか、これは梯子ではないかと思う角度だ。手すりがあるので、手すりを使う。使わないと死ぬ。

### つなげる。ただし一文ずつは短くしない

**ここが作品04 のただ一つの弱点である。**

　つなげ方は正しい。**つなげている一文ずつが短い。**
　作品04 の地の文の文は十四字で、連作では短いほうである（十三〜十八字の幅の、下から二番目）。

| | 作品04 | **これから書く速い篇** |
|---|---|---|
| 地の文の文 | 14 字 | **16–19 字** |
| 一行の文数 | 1.8 文 | **1.8–2.3 文** |
| 地の一行 | 26.4 字 | **32–42 字** |
| 地の連（字） | 72 字 | **90–140 字** |

**この組み合わせは、既刊にまだない。**
　いちばん近いのは作品01『灯を消さない家』で、一行の文数 2.2、地の一行 37.1 字。
　ただし地の文の文は十五字で、まだ短い。
　——**長い文をつなげた行は、連作でまだ書かれていない。**そこを書く。

**どこを長くするか。短い文を全部伸ばすのではない。**

　作品04 の短い文には二種類ある。

> 　急である。急というか、これは梯子ではないかと思う角度だ。手すりがあるので、手すりを使う。**使わないと死ぬ。**

　——**落とす文は、短いままでいい。**「使わないと死ぬ。」は七字で、そこが芸である。

> 　スチールの机が三つ。そのうち二つには誰も座っていない。段ボールが積んである。

　——**説明している文が短い。**九字、十六字、十字。ここが直すところである。
　「スチールの机が三つあって、そのうち二つには誰も座っていない。」と書けば二十八字になる。

| 何をしている文か | どうするか |
|---|---|
| 説明・描写 | **つなげる。**句点で切っていたものを `〜て、` `〜で、` `〜が、` でつなぐ |
| 落とす・突っ込む | **短いまま。**伸ばすと芸にならない |

- ただし**四十字を超える文は二％まで**。十四字を十八字にするのであって、三十字にはしない
- つないだ結果、地の文が百四十字を超えたら切る。**切り方は変えない**

**つなげたぶん、読点を足さない。**
　これをやると読点が増えて、下限（二十字）を割る。
　地の文の文が十八字で読点が二十七字に一つなら、**読点は三文に二つまで**である。
　`〜て、` は落とせることが多い（§3-2）。**つなぐときは、まず読点なしで書いてみる。**

### 速い篇と遅い篇

- **速い篇**——地の文は九十〜百四十字で切る。一行は詰める。
  **短い台詞を三つ四つ続けて置き、あいだに地の文を入れない。**
  帰属（「〜と言った」）は、誰が喋ったか分からないときだけ書く
- **遅い篇**——地の文を三百字続けてよい。一行はむしろ短くする（一行一文に寄せる）。
  **続かないと、一人でいることにならない**
  （作品13 第五章は三千三百字まで一度も声が返らない）

**「地の文が多い」と「遅い」は別である。**多いまま速くできる。

### 新しい作品には、書く前に置く

設定.md にこの形で書く。**数は決め打ちせず、近い既刊を `tools/文体.py` で測って決める。**

```
## 文体の目標

| | 目標 |
|---|---|
| 地の文の文 | 16–19 字 |
| 長文 | 2 %以下（四十字を超える文） |
| 一行の文数 | 1.8–2.3 文 |
| 地の一行 | 32–42 字 |
| 地の連（字） | 90–140 字 |
| 地の連（行） | 4 行以下 |
| 会話字 | 28–38 % |
| 会話行 | 45–65 % |
| 会話一行 | 8–13 字 |
| 会話の連（行） | 3 行以上 |
| 読点 | 27 字以上あける |
| 場面 | 6–9 ／章 |
```

**目標と本文が食い違ったら、どちらが古いかを考える。**
本文のほうが良ければ、直すのは設定.md である。

### 一章では外れてよい。篇でそろえる

**導入の章は遅く、山の章は速い。**これは事故ではなく、作りである。

　『餃子パン』の会話行は、篇ぜんたいで五十五％だが、
　第一章だけなら二十九％、第八章なら六十九％である。
　——第一章は七年前の夏祭りを置く章なので、遅くてよい。

**一章だけ測って直しにいかない。**篇ごと測って、それでも外れていたら直す。

## 2. 書きながら守る形式

- **地の文の時刻は二十四時間制で書く。**
  この連作は時刻でできているので、**午前と午後が混ざると出来事の順が追えなくなる。**
  十五時に焼き上がる。十四時に閉める。二十一時に布団へ入る。二時四十分に目が覚める。

  **台詞は変えない。**人は「十五時」とは言わない。
  「三時に焼き上がるけえ」と喋らせて、地の文は「十五時に焼き上がる」と書く。
  **食い違って見えるが、食い違っていない。**地の文は測る側で、台詞は喋る側である。
- **語り手を、章の頭に必ず出す。**
  章ごとに語り手が替わる篇では、**誰が喋っているのかを読者に探させない。**
  この連作は一人称が多く、**十二篇で語り手が章ごとに替わる。**
  しかも「わたし」が重なる（作品18 は二人とも「わたし」、幕間14 も二人とも「わたし」）。
  **章題の末尾に（名前）を足す。**番外編と二次創作は、節題で前からこれをやっている。

  ```
  # 第三章　十二月十九日　火曜の夜（宮地あんず）
  ```

  **本文には書かない。**章題だけで足りる。字数にも入らない。
- **セリフと叙述文を同一行に混在させない。**
  会話は独立行に置く。`結局、わたしは「そうですか」と言った。` のような畳み込みをしない。
  例外：看板・書類・単語の引用（`第一希望の欄に「映画」と書いた`）はこの限りでない。
- セリフでは助詞・接続詞を省略しない。**ただし方言と口語の自然さが優先**され、
  その人物が実際にそう喋る場合は省略してよい（「なんも」「もういいろ」など）。
- **地の文を何字続けてよいかは、作品が決めている**（§1-2）。
  速い篇は百字前後、遅い篇は三百字。**行ではなく字で数える**——行の長さは倍ちがう。
  超えそうになったら、**場面を切るか、誰かに喋らせる。**
- **一行に文を二つ入れる篇と、一行一文の篇がある。**これも作品が決めている。
  つなげる篇でも、**つなげる一文ずつを短くしない**（§1-2）
- 複数の人物を扱うとき、人物ごとのセクション分けをしない。ひと続きの描写に統合する。
- 体型・外見に触れるときは、全年齢向けとしてふさわしい自然な語を使う。
  性的な強調をしない。連作は女性どうしの関係を書くので、ここは明示的に守る。
- 章の終わりは、感慨ではなく物か動作で閉じる。

## 3. 反復の点検（書き終えたら）

前章までと照らして、次を潰す。

- 同じ文型の反復（「〜した。〜した。〜した。」の連鎖、同じ長さの文の連続）
- 同じ比喩・同じ語彙の再使用（あらすじ記録.md を検索して確認する）
- セリフの構造の反復（同じ受け answering 方、同じ間の取り方）
- **ただし、設定.md が「反復モチーフ」として指定したものは除く。**
  意図した反復と、癖による反復を混同しない。

## 3-2. 呼吸の点検（数える）

書き終えたら、二つ測る。

```
python3 tools/文体.py <章>.md     # 十二の数。設定.md の目標と突き合わせる
python3 tools/読点.py <章>.md     # 読点だけを細かく見る
```

**まず `文体.py` を見る。** ← がついた行があれば、そこだけ直す。
全部そろっている必要はない。**外れるなら、外れる理由が言えればよい。**
**一章だけの ← は、たいてい直さなくていい**（§1-2）。

### 読点

**読点は放っておくと増える。** 一作目から九作目で、密度が三割上がった。

**二十字を切ったら多い。これは全作共通の下限である。**
目標そのものは作品が決める——抑制された篇で二十四字前後、
速い篇はもっとあける（作品04『餃子パン』は二十九・七字に一つで、それでいい）。
下限だけ守って、あとは設定.md の「文体の目標」に合わせる。

増える原因は、ほぼ一つに絞られている。**「〜は、」である。**
固有名詞や代名詞の主語のあとに、反射で読点を打っている。

- ×　森岡は、そこで足を止めた。
- ○　森岡はそこで足を止めた。
- ×　わたしは、答えられなかった。
- ○　わたしは答えられなかった。

**主語が短く、述部も短く、対比もないとき、この読点は要らない。**

残してよいのは次の場合だけ。

- 主語が長い（`バツをつけるのは、事務員の仕事だった。`）
- 間を置きたい（`森岡は、見なかった。` ——ためが意味を持つ場面）
- 対比がある（`あんずは速い。わたしは、遅い。`）

**「間を置きたい」は、一章に数回までにする。** 全部の文でためると、ためにならない。

**主語は固有名詞とはかぎらない。** 「その人は、」「奥さんは、」「この店は、」「蓮見さんが、」も同じである。
数えるときに名前の一覧で拾おうとすると、取りこぼす。**短い語＋は／が**の形で見る。

### `〜て、` は、落とせるものと落とせないものがある

動作をつなぐだけの `〜て、` は、読点なしで足りることが多い。

- ×　森岡は頭を下げて、店を出た。
- ○　森岡は頭を下げて店を出た。

ただし、**次の四つは落とさない。**

- 三つ以上つながっているとき（`印刷して、折って、封筒に入れて、宛名を貼る。`）
  ——列挙の拍子そのものが意味になっている。
- 理由・条件の節（`屋根がないので、直接当たる。` `補助を出すには、領収書が要る。`）
- 逆接（`整うが、これより良くはならない。`）
- 後ろに**別の主語**が立つとき（`戸が一枚あって、その向こうが事務所だった。`）

落としたあと、**読点なしで三十八字を超える文ができていないか**を見る。
できていたら、どこか一つ戻す。

## 3-3. 人物を芸にしない（いちばん壊れやすいところ）

**この連作の失敗は、いつも同じ形で起きる。人物が一芸に縮む。**

書き分けの軸（方言／文の長さ／敬語／断定するかどうか）は、
**同じ部屋にいる二人の声を割るための道具**であって、人物の名札ではない。
名札に使うと、誰が出てきても同じ反応をする装置になる。

### 軸は組に付ける。人に付けない

**軸がその人の性質になると、誰と話しても同じ声が出る。**そこがテンプレの出どころである。

- **同じ人が、二つの組で同じ軸を使わない。**
  組を新しく作るときは、**軸も新しく作る。**既にある軸を流用しない
- **一人につき、軸の振れている側に立つ組が最低一つ要る。**
  どの組でも振られる側なら、それは軸ではなく**役**である
- **三人以上の場面では、軸を立てない。**
  六人に六つの軸を立てると、六つの芸をする場面になる。**餃子会がいちばん危ない。**
  誰が喋ったかは、言い方ではなく**何に口を出したか**で分かるように書く。
  **何に口を出すかは毎回決める。固定した瞬間、それが新しい軸になる**
- **一人の場面には、軸がない。**
  一人称で一人でいる章は、**その人の素の声が出る唯一の場所**である。鳴らさない

　組と軸の一覧は `商店街連作設定.md`「書き分けの軸」にある。

### 役割を剥がす

**人を店で呼ぶのはやめない。**それは連作の土台である。
やめるのは、**その人が動く理由を、いつも店から取ること**である。

1. **定休日で人を選ばない。**
   作品13・幕間11・幕間12・幕間13 と四篇続けて「誰が行けるかを定休日が決める」をやった。
   **人の違いではなく、営業時間の違いが話を動かしている。**
   **次の三篇では使わない。**動く理由は店の外から——病院、役所、家族、金、約束、乗りもの、天気。
2. **一篇につき一人、店にいないところで出す。**
   `資料/一人のとき.md` から一つ取る。**説明しない。やっているところだけ書く。**
   全員ぶん並べない。**並べると、それが新しい役になる。**
   使ったら、その行に印をつける。
3. **職は奪わない。**全員から職を剥がす話は二次創作『学園』で一度やった。
   本編でやるのは、**店にいない時間を書くこと**である。

### 三つの禁止

1. **一篇につき、一人の軸は一回まで。**
   二回目からは、その人の別の面を出す。出す面がないなら、
   `資料/まだ書いていない面.md` から取る。

2. **地の文で性格を説明しない。**
   次の型は書かない。**感情の直接説明と同じ扱いにする。**

   - ×　この人は、聞かれたことにだけ答える人である
   - ×　この人は決めるのが速い。決めてから考える
   - ×　十年、そうしとる／五年、そうです
   - ○　行動だけ書いて、説明を足さない

   **一度説明した癖を、次の作品でもう一度説明しない。**連作なので、既出は既出である。

3. **数を、地の文が申告しない。**
   字数・温度・秒数を、本人にも他人にも数えさせない。

   - ×　「そうです」／十字です
   - ×　四十二字を超えました
   - ×　「三十六度五分です」（連続して使わない）
   - ○　短く答えさせる。読者が気づけばいい

   **限界は、守られているときがいちばん効く。申告した瞬間に芸になる。**

### 点検のしかた

書き終えたら数える。

```
grep -c "字です\|字じゃ\|字でした" <章>.md    # 〇 が望ましい
grep -c "度です" <章>.md                        # 一篇に一回まで
grep -c "人である\|人じゃ\|人です" <章>.md    # 性格の説明が混じっていないか見る
grep -c "定休\|休みが重なら\|平日の昼" <章>.md  # 定休日で人を選んでいないか
```

目で見るほうは三つ。

- **三人以上の場面で、全員に軸が立っていないか。**立っていたら、二人ぶんまで落とす
- **一人の場面で、軸が鳴っていないか。**鳴っていたら、そこは素の声に戻す
- **この篇で、店にいないところを一つ書いたか。**書いていなければ、一つ入れる

### 休ませる

**使いすぎた癖は、数篇休ませる。**

| 癖 | 状態 |
|---|---|
| 矢部さえの温度 | **直近五本で連続。三篇は出さない** |
| 蓮見すずの字数申告 | **当面やらない。**短く答えさせるだけにする |
| 黒江いとの字数申告 | 同上 |
| 「この人は〜する人だ」型 | **禁止** |
| 定休日で人を選ぶ | **四篇続けた。次の三篇は使わない** |
| 三人以上の場面で全員に軸を立てる | **禁止** |

## 3-4. 封じるものは、一つに絞る

**この連作は説明しない。だから、説明しないことが癖になる。**

　幕間14 で、祖母が四時に通りへ出た。何をしに出たのかを書かなかった。
　出た理由だけでなく、**四時が何の時刻かも書かなかった。**
　読んだ人は、**まったく別の筋を組み立てた**——
　「中華屋とパン屋が昔は近くて、どちらかが転居した話」。**そんな設定はない。**

> **隙間は、読者が埋める。別の話で埋める。**

　読者が勝手に埋めるのは、こちらが**封じたつもりで、ただ書き忘れている**ときである。
　封じたものは効くが、**忘れたものは、別の話になって返ってくる。**

### 三つに分けて、二つは書く

| | |
|---|---|
| **出来事** | **書く。**誰が、どこで、何をしたか |
| **その出来事の意味する事実** | **書く。**「四時は、祖父が窯に火を入れていた時刻である」 |
| **その人の気持ち・理由** | **書かない。**ここだけが封印である |

　幕間14 は三つとも書かなかった。直して、上の二つを本文に入れた。
　——**祖母が何を思って出たのかは、いまも書いていない。**それでいい。

### 点検

書き終えたら、**その章だけを人に読ませたつもりで一度読む。**

- **この章の外を知らない人が、起きたことを言い直せるか。**言い直せないなら足りない
- 足りないときに足すのは、**事実であって、気持ちではない**
- 「あとで分かる」で先送りしない。**先送りしたものは、別の話になって戻ってくる**

## 4. 忌避表現の事前フィルタ

以下は生成段階で使わない。書いてから直すのではなく、最初から選ばない。
**言い換えた痕跡を本文に残さない。**

`めっちゃ` `何！？` `ヤバい` `〜すぎる` `ぶっちゃけ` `的な` `てゆうか`
`〜かもしれない、いや、〜だ` の自問自答型の言い直し
`まるで〜のような` で始まる手垢のついた直喩
`ドキッとした` `胸が締めつけられた` `涙が溢れた` など感情の既製品
擬音の多用（`ドキドキ` `ワクワク` `ゾクッ`）
`彼女は悲しかった` のような感情の直接説明

## 5. 読者ペルソナによる内部レビュー（初稿は出力しない）

書き上げたら、必ず四人に読ませてから最終稿にする。
**初稿をそのまま書き出さない。** 修正はレビューの痕跡を残さず、文全体を調整して行う。

**読者A（作者の視点）**
文法の正確さにこだわる。パターン化した展開を嫌う。前の章と内容が被るのを嫌う。
一方で、設定が急に変わることも嫌う。

**読者B（この連作の読者）**
抑制された文体を好む。説明されると冷める。心理を書かれるより、行動から察したい。
泣かせにくる文章を見抜く。静かな場面が長いことを苦にしない。

**読者C（前作未読の読者）**
この作品から読みはじめた。前作の人物が出てきても、その場で分かるように書かれているか。
固有名詞に置いていかれないか。この一冊だけで完結して読めるか。

**読者D（速さで読む人）**
次の行を読みたくて読んでいる。地の文が続くと飛ばす。同じ調子が三場面続くと飽きる。
台詞の応酬が好きで、説明されるとそこで止まる。**笑うところがあるかを見ている。**

### どれを重く見るかは、作品が決める

**読者Bと読者Dは、正面から対立する。**
Bは「静かな場面が長いことを苦にしない」人で、Dは「地の文が続くと飛ばす」人である。
**両方を満足させようとすると、どちらでもないものになる。**

設定.md の「文体の目標」（§1-2）で決める。

| | 重く見る | 地の連（字） | 例 |
|---|---|---|---|
| **遅い篇** | **B** | 二百字以上 | 作品03・11・13・16 |
| **速い篇** | **D** | 百五十字以下 | 作品04・17、幕間04・07・13 |

　**どちらか分からないときは、`tools/文体.py` で近い既刊を測る。**見立てはよく外れる。

　——作品04『餃子パン』は、**Bの指摘だけで直すと壊れる。**
　あの一篇は「説明されると冷める」ではなく「止まると飽きる」で書いてある。

四人の指摘のうち、**設定.md の禁止事項と衝突するものは採らない**。
それ以外は反映し、強みは伸ばす。最終稿だけをファイルに書き出す。

## 6. 章を書き終えたら

1. 字数を確認する（`python3 tools/字数.py <章>.md`）。目標の±10%に収める。
2. 呼吸を確認する（`python3 tools/文体.py <章>.md`）。← がついた行を見る。
3. `あらすじ記録.md` に200字要約を追記する。
4. 補ったディテールがあれば `設定.md` に追記する。
5. コミットする。
