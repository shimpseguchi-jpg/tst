# 設定

短編『月水金』作業用の設定ファイル。
執筆中はこのファイルを毎章の冒頭で読み直し、記述の揺れを防ぐこと。

本作は**商店街連作**の一作で、**『のぼせる』（作品05）の対**にあたる。
同じ一年を、三隅るりの側から書く。共通の土台は `../商店街連作設定.md`。
工程は `小説執筆` スキルに従う。**作品01〜05の本文は改稿しない。**

> **作品05 設定.md 第7節の禁止事項は、本作にもそのまま適用される。**
> 視点が大人側に移っても、るりは恋愛的にも性的にも一切応えない。

---

## 1. 作品情報

| 項目 | 内容 |
|---|---|
| 仮題 | 月水金 |
| 形式 | 短編・**全5章**、各章3,400字（±10%）、総計17,000字以上 |
| 時代 | 二〇二七年四月二十五日（日）の一日。回想が二〇二六年四月〜二〇二七年三月に及ぶ |
| 舞台 | 尾道（現在軸）／柏尾銀天街・柏湯（回想軸） |
| 視点 | **三人称一元（三隅るり）**。連作で唯一、四作続いた一人称から戻す |
| 表のテーマ | 同じ一日が、片方にはデートで、片方には線を引きながら歩く七時間である |
| 裏のテーマ | 見られることで生き延びていた大人の、うしろめたさ |

### 主題（executive summary）

友達になってひと月後の日曜日、二人は電車で尾道へ行く。
さえはそれを「デート」と呼ぶ。**るりは一度もそう呼ばない。**

一日のあいだ、るりは何度も線を引き直す。どこに座るか、何を奢るか、どこで待つか、
何を答えて何を答えないか。**七時間ぶん、判断しつづける。**
さえには、それが楽しい一日にしか見えていない。それでいいとるりは思っている。

### るりの側の「意識」——本作の最大の反転

**さえは、自分だけが一方的に見ていたと思っている。実際は、逆に近かった。**

るりの側の意識は、**恋愛ではない。だが強度は恋愛に劣らない。**
種類が違うだけで、量はさえより多い。ここを取り違えない。

具体的には、以下がすべて事実である。作中で順に出す。

- **帰省の日程を、月水金に合わせていた。** 片付けは平日でも土日でもできた。
  実家には水道が生きていたし、コインシャワーも、市外の日帰り温泉もあった。
  それでも、あの子が番台にいる日を選んで戻っていた。**四月からずっと。**
- **さえの些細な変化を全部覚えている。** 参考書を裏返す速さ。桶の積み方が五月と七月で
  変わったこと。声が小さくなった時期。数えるときに唇が動くこと。
  **さえがるりの動作を覚えていたのと、同じ量だけ覚えている。**
- **大阪で、一日に何度も思い出していた。** 校正の仕事は目が疲れる。疲れると、
  柏尾のことを考える。考えるのは町ではなく、番台だった。
- **敬語にすると決めるまで、一か月かかった。** 十月五日に瓶を出されてから、
  十一月十三日まで。毎晩考えて、そのたびに先延ばしにした。
- **誰にも言っていない。** 大阪の友人にも、一度も。
  この一年でいちばん大きな出来事が、誰にも共有されていない。

**そして、るりも数えていた。**
九月に来られなかった月水金が六回あったことを、るりは正確に知っている。
数えるのはさえの癖のはずだった。**第五章で、それが漏れる。**
さえが「九月、来んかったですよね」と言い、るりが数えずに「六回」と答える。
これが本作でいちばん大きな一行である。**説明を足さない。一往復で通過させる。**

### るりの本当の理由（作品05では一度も示されていない）

**三月二十七日に戻ったのは、善意ではない。**

母が死に、家が売れ、柏尾に知り合いが一人もいなくなった。
三十一年生きてきた町で、自分のことを見ている人間が、あの番台の子だけになっていた。
**子どもの好意を、寂しさしのぎに使っている。** るりはそれを自分で知っている。
知っているから、線を引く。敬語にしたのも、百円玉を置いたのも、そのためだった。

**るりを聖人にしない。** 正しく振る舞ってはいるが、動機は綺麗ではない。
この欠点が、この短編の中心である。

そして、**敬語にすることは、るりにとって安全な判断ではなかった。**
それは、唯一自分を見ている人間との距離を、自分から広げる行為だった。
一か月かかったのは、迷っていたからではない。**手放すのが惜しかったからである。**
冷静な大人が線を引いたのではない。**溺れかけた人間が、掴んでいた手を自分で離した。**

### 明かすものと、明かさないもの

| 明かす | 明かさない |
|---|---|
| なぜ冷蔵庫を開けて閉めていたか（第二章） | **腰の痕の理由** |
| 百円玉の意味（第三章） | 母との関係の詳細 |
| なぜ敬語にしたか（第四章） | 大阪での私生活、交際相手の有無 |
| なぜ三月二十七日に戻ったか（第四章） | さえへの評価の言語化 |
| 仕事が何か（第五章・さえに答える） | 今後どうするつもりか |

**『のぼせる』が残した謎を、全部は回収しない。** 腰の痕は、るりの視点でも触れさせない。
彼女が自分について考えないことにしているものが、一つ残る。

## 2. 人物

### 三隅 るり（みすみ るり）31歳・視点人物

- タレ目。笑っていなくても笑って見える。**本人はそれを不便だと思っている。**
  誤解されるのに慣れていて、いちいち訂正しない。訂正しないことが、今回は罪になった。
- 大阪で働いている。**印刷会社の校正**。地味で、目が疲れる仕事。
  さえには最後まで聞かれなかった。第五章で初めて聞かれ、答える。
- 人に用事のない話をしない。自分からは始めない。愛想がない自覚はある。
- 母は去年の春に死んだ。家は売れた。柏尾に残っているものは何もない。
- 大阪に友人はいる。多くはない。**誰にもこの話をしていない。**
- 癖：迷うと、指で自分の手首を握る。

### 矢部 さえ（やべ さえ）16歳・柏尾南高校一年

- **るりの目から見たさえを書く。** 作品05のさえと同じ人物だが、見え方が違う。
  よく数える子。声が小さい。こちらが黙ると不安そうにする。制服でないと少し幼い。
- るりは、さえの気持ちに四月の時点で気づいていた。**さえより先に気づいていた。**
- そして、**気づいたうえで通いつづけた。** 三か月、何も言わずに通った。
  そこがこの人のいちばん悪いところで、るりはそれを自覚している。
- 悪い子ではない。むしろ、手のかからない子だった。それがよけいに始末が悪い。

### 矢部 靖子（やすこ）45歳／矢部 タカ（たか）77歳

- 回想にのみ。るりから見ると、靖子は「何も聞かない人」、タカは「母を覚えている人」。

### 三隅 ミヨ子（みよこ）享年68・るりの母

- 回想の中にだけいる。柏湯に四十年通った。**るりとの関係は詳しく書かない。**
  仲が悪かったとも良かったとも書かない。片付けの描写だけで示す。

## 3. 場所と時間

### 現在軸——二〇二七年四月二十五日（日）

- 日曜。**柏湯は月水金なので休み。** だから出かけられる。
- 柏尾駅から在来線で尾道へ。乗り換え一回、片道およそ一時間。
- 尾道：坂の町。海と、山と、そのあいだに家が積み上がっている。
  商店街のアーケードがある。猫がいる。寺が多い。ロープウェイがある。
- 昼は商店街の食堂。夕方の電車で戻る。往復で七時間ほど。

### 目的地の銭湯

- 尾道の、古い銭湯。さえが行きたいと言った場所。
- **るりは入らない。** 休憩所で待つ。さえは一人で入る。
  理由をさえには言わない。読者には分かるように書く。

### 反復モチーフ

1. **坂**：上る、下る、息が切れる、途中で待つ。
2. **距離**：並んで歩くときの間隔。何センチか。るりが調整しつづけている。
3. **奢る／奢らない**：切符、昼飯、入浴料、アイス。その都度、判断している。
4. **月水金**：るりの一年が、他人の営業日でできていたこと。

## 4. 文体ルール

- **三人称一元（るり）。過去形。** 四作続いた一人称から戻す。連作内での手触りの差。
- **るりの内面は書く。ただし、感情語で名指ししない。** 判断と計算を書く。
  この人は一日じゅう、考えている。考えていることの中身を、そのまま出す。
- さえの内面は書かない。**るりから見えるものだけ。** 作品05を読んだ読者が補完する。
- 地の文は標準語。**会話だけ、るりは関西寄り。** 柏尾の人には備後が混じる。
- 一文は原則六十字以内。判断の場面だけ、短く切る。
- 比喩は坂、海、電車、光から。一章に三つまで。
- 回想は地の文に溶かす。合図を使わない。**現在軸と回想の切り替えは、章の中で一度だけ。**
- 章の終わりは、物か動作で閉じる。
- 泣かせにいかない。**るりに泣く資格はない、という前提で書く。**

### 会話のルール

- るり：短い。説明しない。関西のイントネーション（〜やね、〜やろ、〜してる、〜せん）。
- さえ：敬語。ときどき外れる。るりの前では、よく喋る（作品05より喋る）。
- セリフと叙述文を同一行に混在させない。引用語は例外。

---

## 5. 表記ルール

- 数字は漢数字（四百七十円、七時間、月水金）。
- 三点リーダーは「……」、ダッシュは「――」。
- 会話は「」、貼り紙・値段・引用は『』。
- 段落冒頭は全角一字下げ。会話行は下げない。
- 章見出しの形式：`# 第一章　八時十五分の電車`
- 場面転換は空行二行。
- 本文ファイルには見出し以外のメタ情報を書かない。

## 6. ファイル運用

```
作品06_月水金/
  設定.md / プロット.md / あらすじ記録.md / 01章.md 〜 05章.md
```

**目標を一章3,400字に設定する。**
実測では計画した場面量の七割程度に落ち着くため、**各章四千六百字ぶんの場面を積んでから書く。**
場面は一章に**九つから十一**。水増しで伸ばさず、場面そのものを増やして厚みを出す。
会話の往復を増やし、るりの観察と判断を一つずつ具体で書くこと。

## 7. 禁止事項

- **るりは恋愛的にも性的にも一切応えない。** 作品05から一貫させる。
  揺れも、迷いも、「もし自分が若ければ」も書かない。
- **「デート」という語は、さえの側からしか出さない。** るりは一度も使わない。
- **二人きりの密室を作らない。** 電車、坂道、商店街、食堂、銭湯の休憩所。すべて公共の場。
- **接触を書かない。** 手が触れる、肩が当たる、といった描写に意味を持たせない。
- **るりを聖人にしない。** 正しく振る舞うが、動機はうしろめたい。そこを隠さない。
- **るりの「意識」を恋愛として書かない。** 強度は恋愛に劣らないが、種類が違う。
  見られたい、忘れられたくない、自分がまだ誰かの一日に含まれていたい——そこで止める。
  身体への関心、独占欲、嫉妬、触れたいという欲を、一行も書かない。
- **るりに泣かせない。自己憐憫を書かない。** この人に泣く資格はない、という前提を守る。
- **腰の痕の理由を明かさない。** るりの視点でも、そこには触れさせない。
- **さえの内面を書かない。** るりが見て、推測するところまで。
- **将来の約束をさせない。** 次にいつ会うかを決めさせない。月水金があるだけにする。
- 作品05の文章を引き写さない。同じ場面に触れるときは、必ず別の角度から書く。
