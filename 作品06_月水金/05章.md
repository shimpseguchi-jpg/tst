# 第五章　六回

　帰りの電車は、十六時四十分だった。
　行きより、人が多かった。日曜の夕方なので、ボックス席はどれも埋まっていた。
　二人掛けの席が一つ空いていた。
　るりは、そこに座った。
　座るしかなかった。立っていてもよかったが、一時間立っているのは不自然だった。不自然なことをすると、それ自体が意味になる。
　さえが窓側に座って、るりが通路側に座った。
　朝から七時間、るりは真向かいにも隣にも座らずに来た。
　最後にそれが崩れた。
　肩と肩のあいだは、たぶん十五センチくらいだった。電車が揺れると、その距離が縮んだり戻ったりした。
　るりは、鞄を膝の上に置いた。
　置いてから、それが何のためかを考えて、考えるのをやめた。


　日が傾いていた。
　窓の外が、金色になっていた。田んぼに水が入りはじめている時期で、水面が全部光っていた。
　その光が、十分くらいで消えた。消えると、あとは青くなって、すぐに暗くなった。
　さえは、窓のほうを見ていた。
　喋らなかった。
　朝は、あれだけ喋っていた。クラスのことも、坂のことも、煙突のことも喋った。帰りは静かだった。
　疲れたのかもしれない。坂を上って、湯に入った。それだけで十分に疲れる。
　るりは、それを、そういうことにしておいた。


　二十分くらいして、さえが窓のほうを向いたまま言った。
「今日、楽しかったです」
「そう」
「るりさんは」
　そこで切れた。
　るりは待った。続きが来なかった。
　るりさんは楽しかったですか、と聞こうとして、やめたのだと思う。聞いて、もし短い答えが返ってきたら、一日が終わってしまう。この子はそういう計算をする。
　るりは、自分から続きを言わなかった。
　楽しかった、と言えばよかった。言えば済んだ。嘘でもなかった。
　言わなかったのは、言えば、次もあることになるからだった。


　三十分くらい経ったところで、さえが言った。
「るりさん」
「うん」
「去年の九月、来んかったですよね」
　窓のほうを見たままだった。
　るりは、答えた。
「六回」
　言ってから、止まった。
　数えていなかった。
　数えて答えたのではない。口が先に動いた。頭の中に、最初からその数字があった。
　九月に柏湯が開いたのは、月水金で、六回だった。その六回、るりは行っていない。
　それを、るりは知っている。
　去年の九月から、ずっと知っている。
　さえが、窓から顔を戻した。
　るりを見た。
　るりは、前を見ていた。前の席の背もたれを見ていた。
　説明しなかった。
　取り繕わなかった。数えとったんよ、とも、たまたま覚えとっただけ、とも言わなかった。
　言えば、嘘になるか、もっと言うことになるかの、どちらかだった。
　さえは、何も言わなかった。
　二秒か、三秒か、もっと長かったかもしれない。
　それから、窓のほうへ向き直った。
　耳が赤くなっていた。
　湯上がりの赤さとは違った。あれは三時間前で、もう引いている。
　るりは、それを、視界の端で見ていた。


　乗り換え駅に着いた。
　ホームに下りた。
　十一分待つことになっていた。行きと同じホームで、行きと同じベンチがあった。
　るりは座らなかった。さえも座らなかった。
　朝と同じだった。朝と違うのは、どちらも喋らなかったことだった。
　自動販売機の音がしていた。誰かが買って、取り出し口が鳴って、それきりになった。
　ホームの照明がついた。まだ明るいのに、時刻でついたらしい。
　るりは、何か言うべきかを考えた。
　考えて、何も言わないほうがましだと判断した。
　いま何か言えば、それはさっきの数字の説明になる。説明しないと決めたものを、間を埋めるために説明することになる。
　電車が来た。


　次の電車は、空いていた。
　四人掛けのボックスが空いていたが、さえが二人掛けのほうに座った。
　るりも座った。
　さえが、少し喋りはじめた。
　尾道のアイスの話だった。白と抹茶のどっちがよかったかを、もう一度言っていた。
　声が、さっきまでと違っていた。
　高くなっていた。喋るのが少し速かった。
　るりは、相槌を打った。
「るりさん」
「うん」
　さえが、膝の上の鞄の持ち手を握っていた。
「聞いてええですか」
「なに」
「るりさんて、何の仕事しとるんですか」
　るりは、窓のほうを見た。
　一年だった。
　去年の四月から、この子と何十回も顔を合わせている。四百七十円を受け取って、ありがとうございましたと言われて、たまに二言三言話した。誘われて、今日一日いっしょに歩いた。
　その一年で、これを聞かれたのは、初めてだった。
「校正」
「こうせい」
「印刷会社の。刷る前の原稿を読んで、間違いを探す仕事」
　さえが、るりのほうを向いた。
「間違い」
「誤字とか、日付が合うとらんとか、去年の数字が残っとるとか」
「ずっと字を見とるんですか」
「ずっと見とる。一日じゅう」
「目、疲れませんか」
「疲れる」
　るりは、自分が何を答えているのかを、そこで少し考えた。
　この子は、るりの仕事を聞いた。聞かれたから答えた。それだけのことだった。
　それだけのことが、一年かかった。
　聞かれなかったのは、聞けなかったからだと思う。聞けば、答えが返ってくる。答えが返ってくると、その人が具体的になる。具体的になった人を、この子は持ちきれないと思っていたのかもしれない。
　あるいは、聞くことを取っておいたのかもしれない。
　どちらでもよかった。
　るりが渡せるものは、これしかなかった。
　恋の代わりではない。代わりになるものはない。
　ただ、知られる、ということだけは渡せた。


「面白いですか」
「面白ない」
「そうなんですか」
「地味やし、目が疲れるし、間違いを見つけても誰も褒めん。見つけんかったときだけ怒られる」
「うわ」
「そういう仕事」
　さえが笑った。
　声を出して笑った。この日、初めてだった。
「るりさんに合っとる気がします」
「なんでよ」
「よう見とるけえ」
　るりは、答えなかった。
　答えられなかった。
　さえは、それ以上言わなかった。窓のほうを見て、外が暗くなっているのを見ていた。


　柏尾駅に着いたのは、十七時五十分だった。
　改札を出た。駅前のロータリーに、タクシーが二台停まっていた。この町にタクシーは二台しかない。
　改札で、るりは切符を回収箱に入れた。
　さえは、入れなかった。
　駅員に何か言って、判子を押してもらっていた。無効の判子だ。押してもらうと、切符を持って帰れる。
　るりは、それを見ていた。
　自分の切符は、もう箱の中だった。
　さえが切符を財布にしまうのを、るりは見た。朝、券売機で買ったときと同じ、丁寧なしまい方だった。
「今日、ありがとうございました」
　さえが言って、頭を下げた。
　下げ方が、番台で客を送るときと同じだった。
「こっちこそ」
　るりはそう言った。
　次にいつ会うか、という話は、どちらも出さなかった。
　るりは出さなかった。出せば約束になる。約束をすると、それまでの日が待つ日になる。
　さえも出さなかった。
　出さなかった理由は、るりには分からない。分からないままにしておいた。
「気ぃつけて」
「はい」
　さえが、自転車置き場のほうへ歩いていった。
　途中で一度、振り返った。
　るりは、手を上げなかった。頭を少し下げた。
　さえも下げて、それから、行った。


　次の大阪行きまで、三十分あった。
　るりは、駅前に立っていた。
　銀天街のほうを見た。
　アーケードの入口が見える。照明が点いていた。半分は切れている。あれはずっと切れたままだ。
　その先に、煙突がある。
　柏湯の煙突は、丸い。鉄だ。今日そう教わった。
　日曜なので、煙は出ていなかった。
　るりは、しばらくそれを見ていた。
　明日は、月曜である。
　携帯を出して、時刻表を見た。柏尾を出る電車の時刻ではない。大阪から柏尾へ来る電車の時刻だった。
　朝いちばんに出れば、昼前に着く。
　るりは画面を消して、携帯を鞄に入れた。
