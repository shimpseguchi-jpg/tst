本作は**商店街連作**の一作（柏尾銀天街編・二作目）。共通の土台は `../商店街連作設定.md`。

## 1. 作品情報

| 項目 | 内容 |
|---|---|
| 仮題 | 読まない人 |
| ジャンル | 現代文芸／青春小説 |
| 分量 | 全10章、各章3,000字（±10%）、総計30,000字以上 |
| 時代 | 二〇二七年九月〜二〇二八年三月 |
| 主舞台 | 柏尾銀天街の古書店「文林堂」 |
| 表のテーマ | 読めなくなった人と、持ち帰れない人 |
| 裏のテーマ | 聞かないことが親切である関係 |

### 主題（executive summary）

古書店の店番は、本に囲まれていて、本が読めない。
毎週来る高校生は、本を読むが、家に置いておけない。

**題名は二人の両方にかかる。** 一方は読めない人であり、もう一方は読んだことを残せない人である。
二人は半年のあいだ、互いの事情を一度も聞かない。聞かないことが、この二人のあいだでは親切である。

### 作品02との接続（改稿は不要）

『銀星座の二本立て』第三章で、まひるは文林堂の店番をこう見ている。

> 文庫本を読んでいて、わたしが本を置いても顔を上げなかった。
> ページのいちばん下まで目で追ってから、栞を挟んで、それから本を見た。

**これは読めていない人の仕草である。** ページの下まで目で追う。読むのではなく、追う。
作品02は一字も直さずに、この一文が本作の伏線になる。本作でも、この仕草を説明しない。

### 結末の方針

- ふゆは復学しない。**退学届を出す。** ただし敗北としても勝利としても書かない。
- ふゆは最後に、一冊だけ読み通す。それが再起であり、進路の答えではない。
- **ときの事情は解決しない。** 家は変わらない。母も変わらない。
  変わるのは、店に本を置ける場所ができることだけ。
- 「本が人を救う」で締めない。救わない。置き場所ができるだけである。

## 2. 人物

### 沢渡 ふゆ（さわたり ふゆ）20歳・語り手

- 文林堂の店番。週六日、十二時から七時まで。時給は最低賃金より少し上。
- 市外の大学の文学部に在籍。二年生の春から休学し、いまは休学二年目。
- **本が読めない。** 課題として読むうちに、字が滑るようになった。
  一行が入ってこない。同じ行を三度読んで、三度とも内容が残らない。医者には行っていない。
  誰にも言っていない。店では読むふりをしている。
- 断定を避ける。「たぶん」「〜だと思う」「よく分からない」が口癖で、地の文にも出る。
- 曜日で時間を数える。日付の感覚が薄い。
- 癖：ページのいちばん下まで目で追ってから栞を挟む。本の角を親指で押さえる。
- 客に袋もカバーもつけない。店主がそう決めたのか、自分が決めたのか覚えていない。

### 宇田 とき（うだ とき）16歳・高校一年

- 柏尾南高校一年。芦原まひるの二学年下にあたるが、面識はない。
- 毎週木曜の閉店前に来る。文庫を一冊買い、翌週それを売りに来る。
- **買った本を家に置いておけない。** 理由は作中で一度も語らせない。
  （作者用の設定：母が、ときの持ち物をすべて見る。鞄も、机の引き出しも、購買の領収書も。
  悪意ではなく心配として。だから自分だけのものを家に置けない。
  これは虐待とまでは言えず、だからこそ誰にも言えない。**本文には一行も書かない。**）
- 本の話はする。自分の話はしない。その線引きが正確で、迷いがない。
- 敬語。ふゆに対して最後まで敬語のまま。
- 癖：本を受け取るとき、必ず両手で受ける。レジ袋を断る。

### 滝沢 篤子（たきざわ あつこ）68歳・文林堂店主

- 二階に住んでいる。**ふゆは一度も会ったことがない。**
- やりとりは、朝レジに置いてあるメモと、夕方にふゆが書き足すメモだけ。
- 姿を見せない理由を、ふゆは知らない。聞いたこともない。
  **本作でも明かさない。**（連作の空白として温存する）
- メモの字は大きく、角ばっていて、用件しか書かない。ごくたまに一行だけ関係のないことが混じる。

### 塚本 律子（つかもと りつこ）63歳・理容室つかもと店主

- 連作の定点。本作では二度登場する。説教をしない。事実だけ言って黙る。
- 文林堂の常連ではないが、滝沢篤子を昔から知っている。知っていることは言わない。

### 芦原 まひる（あしはら まひる）18歳

- 作品02の語り手。本作では高校三年。**一度だけ、映画の本を探しに来る。**
- ふゆ視点では「前にも来た子」。名前は出さない。銀星座がまだやっていることに一行だけ触れる。
- 読者が作品02を未読でも引っかからないように書く。

### 宇田 ときの母

- **登場させない。** 声も、姿も、台詞も出さない。
  ときの口からも語らせない。存在を推測させる描写も置かない。

## 3. 場所と物

### 文林堂

- 柏尾銀天街の、マルミ商会の二軒手前。作品02第三章に既出。
- 狭い。棚が天井まであり、通路は一人ぶん。奥に行くほど暗い。
- 電球が三つ切れている。店主のメモに「電球」とだけ書かれた日があり、まだ替えていない。
- レジは入口のすぐ横。ふゆはそこに座って外を見ている。
- 映画の本は、いちばん奥の下の段に二十冊ほど。
- **二階へ上がる階段は、店の奥の暖簾の向こう。** ふゆは上がったことがない。
- 閉店は七時。シャッターは手で下ろす。

### 『灯台守の一年』

- 海外の古い小説の邦訳。文庫。絶版。訳は旧字旧かなではないが、読点が多い。
- **文林堂に三冊ある。** 棚の別々の場所にあり、ふゆは長いあいだ気づいていなかった。
- ときが毎週買うのはこの本。同じ本を、三回買って三回売った。
- **本の内容は要約しない。引用もしない。** 作中で一行も中身を書かない。

### 反復モチーフ（各章に最低ひとつ）

1. **手**：本を受け取る手、栞を挟む手、シャッターを下ろす手。
2. **曜日**：ふゆは日付ではなく曜日で数える。木曜が動く。
3. **値段**：買値と売値。二百円、四百円、百円。金額が関係の温度を示す。
4. **暗さ**：奥へ行くほど暗い棚。切れた電球。閉店後の照明の落とし方。
5. **メモ**：二階とのやりとり。読まれることを前提にした短い文。

## 4. 文体ルール

- **一人称（沢渡ふゆ）**。前作『銀星座の二本立て』も一人称だが、**声を明確に変える。**

  | | 芦原まひる（作品02） | 沢渡ふゆ（本作） |
  |---|---|---|
  | 文 | 短い。言い切る | 読点が多い。途中で向きを変える |
  | 断定 | する。してから訂正する | 避ける。「たぶん」「気がする」 |
  | 時間 | 日付で数える | 曜日で数える |
  | 速度 | 早口 | 遅い。間が空く |

- 「たぶん」「〜だと思う」「よく分からない」は**一章に五回まで**。それ以上は語りが弱くなる。
- 基本時制は過去形。回想枠は作らない。
- 一文は原則六十字以内。ただしふゆの語りは、一文の中で一度だけ方向が変わってよい。
- **説明しない。** とくに、ときの事情について推測を書かない。ふゆは推測しない人物である。
- 比喩は一章に三つまで。店にあるもの（紙、棚、電球、硬貨、シャッター）から取る。
- **本の内容を語らない。** 書名は出してよいが、あらすじも引用も感想の具体も書かない。
- 章の終わりは、感慨ではなく物か動作で閉じる。
- 泣かせにいかない。痛い場面ほど文を短くする。

### 会話のルール

- とき：敬語。最後まで崩さない。本の話は具体的、自分の話は一言もしない。
- 律子：備後の方言を薄く。語尾中心。
- ふゆ：標準語。言葉が出てくるのが遅い。沈黙を地の文で埋めない。
- 会話文は一往復ごとに改行。三往復以上続けたら、地の文の動作を挟む。
- **セリフと叙述文を同一行に混在させない。** 引用語（書名、メモの文面、値段）は例外。

---

## 5. 表記ルール

- 数字は漢数字（二百円、木曜日、三冊）。
- 三点リーダーは「……」、ダッシュは「――」。単独では使わない。
- 会話は「」、書名・メモの文面・引用は『』。
- 段落冒頭は全角一字下げ。会話行は下げない。
- 感嘆符・疑問符のあとは全角一字空け（行末は除く）。
- 章見出しの形式：`# 第一章　木曜日の閉店前`
- 場面転換は記号を使わず、空行二行で示す。
- 本文ファイルには見出し以外のメタ情報を書かない。

## 7. 禁止事項（この作品では使わない）

- **ときの事情を説明しないこと。** 本人に語らせない。ふゆに推測させない。
  読者に答えを渡さない。最終章でも明かさない。
- **「本が人を救う」で締めないこと。** 誰も救われない。置き場所ができるだけである。
- **ふゆの退学を、敗北としても解放としても書かないこと。** 手続きとして書く。
- **滝沢篤子の正体・不在の理由を明かさないこと。** 連作の空白として温存する。
- **恋愛に回収しないこと。** ただし関係の強度は恋愛に劣らないものとして書く。
- 商店街を人情で塗らないこと。文林堂の経営は苦しいが、誰も助けに来ない。
- 前二作の反復を持ち込まないこと（灯り、フィルム、解体、閉館、親の介護）。
- 説明的な回想、独白による主題の要約、最終章での教訓。
